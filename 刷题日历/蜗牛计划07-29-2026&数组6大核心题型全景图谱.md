# 🗺️ LeetCode 数组（Array）6 大核心题型全景图谱

## 1. 🪟 滑动窗口流 (Sliding Window)
* **物理直觉**：当题目要求我们在一个连续区间（子数组 / 子字符串）内寻找**满足某种条件的最长/最短/特定子区间**时，如果用暴力双循环，时间复杂度会飙到 $O(N^2)$。滑动窗口通过维护一个大小可变的“窗口”（用左右指针 `left` 和 `right`），像毛毛虫一样向前蠕动，将复杂度硬生生压成线性的 $O(N)$。
* **经典母题**：
  * LeetCode 3. 无重复字符的最长子串 (Longest Substring Without Repeating Characters)
  * LeetCode 209. 长度最小的子数组 (Minimum Size Subarray Sum)
* **核心破局点**：区分“固定窗口”还是“可变窗口”。可变窗口的精髓在于：`right` 负责不断扩充、寻找可行解；当违反条件时，`left` 开始追赶、收缩窗口。

---

## 2. 🔀 双指针夹逼与快慢流 (Two Pointers & Fast-Slow Pointers)
* **物理直觉**：数组如果是**有序的**，或者需要我们**在原地（In-place）对元素进行搬运、去重、筛选**，单指针往往捉襟见肘。这时候就要祭出双指针：
  * **对撞指针（左右夹逼）**：从两端向中间靠拢（典型如两数之和、盛最多水)。
  * **快慢指针**：一个在前探路，一个在后清理（典型如原地移除元素、移动零）。
* **经典母题**：
  * LeetCode 11. 盛最多水 (Container With Most Water)
  * LeetCode 27. 移除元素 (Remove Element)
* **核心破局点**：利用数组的有序性或特定规则，通过指针的单向或相向移动，跳过无数次无用的无效遍历。

## 3. ➕ 前缀和与差分数组流 (Prefix Sum & Difference Array)
* **物理直觉**：
  * **前缀和**：如果一个数组需要**频繁、多次查询某一个闭区间 `[i, j]` 的元素总和**，如果每次都用 `for` 循环去加，单次查询是 $O(N)$，总查询代价巨大。通过提前“打表”算出前缀和数组，可以将区间求和降维到 $O(1)$！
  * **差分数组**：反过来，如果题目要求**频繁对某一个区间整体加上或减去某个值**，差分数组能在 $O(1)$ 时间内搞定打标，最后统一做一次前缀和还原。
* **经典母题**：
  * LeetCode 560. 和为 K 的子数组 (Subarray Sum Equals K)
  * LeetCode 303. 区域和检索 - 数组不可变 (Range Sum Query - Immutable)
* **核心破局点**：
  * 前缀和的核心公式：`Sum(i, j) = Prefix[j+1] - Prefix[i]`。
  * 遇到“连续子数组和等于 K”的题目，立刻条件反射想到：**前缀和 + 哈希表优化**。

## 4. 📈 贪心与单调队列/单调栈流 (Greedy & Monotonic Stack/Queue)
* **物理直觉**：处理数组中的**极值问题**（如：接雨水、求每个滑动窗口的最大值、买卖股票的最佳时机）。这类题目通常要求我们在线性时间内做出最优决策，或者借助一个“单调递减/递增”的容器把无用的小不点提前淘汰。
* **经典母题**：
  * LeetCode 42. 接雨水 (Trapping Rain Water)
  * LeetCode 239. 滑动窗口最大值 (Sliding Window Maximum)
* **核心破局点**：单调栈/队列里存的往往不是元素本身，而是**元素的下标（Index）**，通过维持队列的单调性，实现每个元素进出栈均摊 $O(1)$。

---

## 5. 🔄 矩阵与空间降维流 (Matrix & In-place Simulation)
* **物理直觉**：二维数组（矩阵）的题目。核心难点不在于算法多难，而在于**坐标映射、边界控制、以及空间复杂度能否压到 $O(1)$ 的原地旋转/修改**。
* **经典母题**：
  * LeetCode 48. 旋转图像 (Rotate Image)
  * LeetCode 54. 螺旋矩阵 (Spiral Matrix)
* **核心破局点**：寻找矩阵翻转的数学对称规律（如：先沿主对角线翻转，再左右翻转），或者严格控制四个边界指针（`top`, `bottom`, `left`, `right`）。

---

## 6. 🏛️ 原地哈希与置换流 (In-place Hashing / Cyclic Sort)
* **物理直觉**：当题目明确要求：**“必须在 $O(N)$ 时间内完成，且空间复杂度必须是 $O(1)$（不能开辟额外的哈希表或布尔数组）”**时，这就是原地哈希的主战场。
* **经典母题**：
  * LeetCode 41. 缺失的第一个正数 (First Missing Positive)
  * LeetCode 448. 找到所有数组中消失的数字 (Find All Numbers Disappeared in an Array)
* **核心破局点**：利用数组自身的索引作为哈希桶，通过不断的“乾坤大挪移”（交换元素），把数字 `x` 强行赶到它理应呆的索引位置（如数值 `x` 放到下标 `x-1` 处）。
