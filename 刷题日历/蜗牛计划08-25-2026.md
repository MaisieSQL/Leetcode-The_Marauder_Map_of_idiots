## LeetCode 297. 二叉树的序列化与反序列化 (Serialize and Deserialize Binary Tree)

### 1. 题目大意（通俗解释）
这道题要求我们实现两个核心方法：
* **`serialize(root)`（序列化）**：把一棵内存里的二叉树**“拍扁”**，变成一个字符串，方便传输或保存。
* **`deserialize(data)`（反序列化）**：把这个字符串**“还原”**，重新拼成一棵结构一模一样的二叉树。

> **核心难点**：为什么不能只用普通的遍历？因为光靠数字确定不了一棵树的结构（比如缺少空节点信息）。我们**必须把空节点（`None` / `null`）也记录进字符串里**，才能在还原时完美对齐左右子树。

297 题的题目描述确实看起来非常抽象——它既不让你算数，也不让你找路径，而是上来就扔给你两个听起来很玄乎的词：“序列化”和“反序列化”。

其实，这道题翻译成大白话，讲的就是“怎么把一棵长在内存里的树，变成一封信寄出去；以及别人收到信后，怎么把它原封不动地拼回来”。

我们抛开所有术语，用生活中绝对能秒懂的例子来拆解它：

### 1. 什么是“序列化”（Serialize）？
想象一下：
* 你的电脑内存里有一棵漂亮的二叉树（比如根节点是 `1`，左边是 `2`，右边是 `3`）。
* 现在你要把这棵树通过微信发给远在远程服务器的面试官。
* **但是，微信只能发“文字（字符串）”，发不了活生生的“树”！**
* 怎么办？你必须要把这棵树**“拍扁”**，变成一串文字。这个“把树拍扁变成字符串”的过程，就叫**序列化**。

**怎么拍扁？**
你从根节点 `1` 开始，拿着一个小本本，按照“自己 $\rightarrow$ 左边 $\rightarrow$ 右边”的顺序走路并念出来：
1. 看到 `1`，在纸上写下：`1`
2. 走到左边看到 `2`，在纸上写下：`2`
3. `2` 的左边和右边都是空的（`None`），为了让别人知道这里是空的，你也得写下来：写两个 `None`
4. 走到右边看到 `3`，写下：`3`
5. `3` 的两边也是空的，写下两个 `None`

最后，你的纸上串起来变成了一句话：`"1,2,None,None,3,None,None"`。
这就是**序列化**——**把一棵树变成一串带逗号的文字。**

### 2. 什么是“反序列化”（Deserialize）？
面试官在手机那头收到了你发来的这串文字：`"1,2,None,None,3,None,None"`。
但他要的是一棵真正的、能在内存里做运算的二叉树对象啊！
怎么办？他必须看着这串文字，像搭积木一样，把这棵树重新**“拼”**出来。这个“把字符串还原成树”的过程，就叫**反序列化**。

**怎么拼？**
面试官拿着这串文字，从左到右一张一张卡片地抽：
1. 先抽到 `1`：好，造一个根节点 `1`。
2. 接下来要造 `1` 的左儿子，抽一张卡片是 `2`：好，造一个节点 `2` 接在 `1` 的左边。
3. 接下来要造 `2` 的左儿子，抽到 `None`：哦，是个空，那不管它。
4. 接下来要造 `2` 的右儿子，抽到 `None`：也是空。
5. `2` 的左右都造完了，回到 `1`，开始造 `1` 的右儿子，抽到 `3`：好，造一个节点 `3` 接在 `1` 的右边。
……
一路造完，内存里一模一样的二叉树就复活了！
这就是**反序列化**——**把文字重新还原成树。**

### 3. 为什么力扣（LeetCode）的代码长那样？
力扣的意思是：“我给你一个类 `Codec`，里面有两个空方法：
* 第一个方法 `serialize(root)`：你帮我把传进来的树 `root` 变成一个字符串交出来。
* 第二个方法 `deserialize(data)`：我把刚才那个字符串 `data` 传给你，你帮我拼成一棵树，把根节点返回给我。”

现在回过头去看题目，是不是就豁然开朗了？
* **序列化** = 树 $\rightarrow$ 字符串（怎么遍历并记录包括 `None` 在内的所有节点）。
* **反序列化** = 字符串 $\rightarrow$ 树（怎么按顺序把字符串切开，递归把树拼回来）。

### 2. 解题思路：前序遍历 (Preorder / DFS)

我们可以利用二叉树的**前序遍历（根 $\rightarrow$ 左 $\rightarrow$ 右）**来完成这个过程：

* **序列化过程（写日记）**：
  1. 从根节点开始，递归遍历整棵树。
  2. 如果当前节点是空（`None`），向列表中写入一个特殊标记（如 `"None"`）。
  3. 如果当前节点有值，写入当前节点的数值（如 `str(node.val)`）。
  4. 依次递归处理左子树和右子树，最后用逗号 `,` 把所有元素拼接成一个大字符串。

* **反序列化过程（照着拼积木）**：
  1. 把字符串按逗号 `,` 切割成一个列表，并用一个迭代器（`iter()`）包裹起来，方便我们按顺序“抽卡片”。
  2. 写一个递归函数 `dfs()`：
     * 从迭代器中拿出一个元素。
     * 如果拿到的元素是 `"None"`，说明这里是个空节点，直接返回 `None`。
     * 如果拿到的元素是数字，就创建一个新的树节点。
     * 接着**先递归构建它的左子树**，**再递归构建它的右子树**（因为前序遍历的顺序就是根-左-右）。
     * 最后返回当前节点。

### 3. Python 完整代码实现

```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, x):
#         self.val = x
#         self.left = None
#         self.right = None

class Codec:

    def serialize(self, root):
        """将二叉树序列化为字符串"""
        res = []
        
        def dfs(node):
            # 递归基：如果是空节点，记录 "None"
            if not node:
                res.append("None")
                return
            
            # 记录当前节点值
            res.append(str(node.val))
            # 递归遍历左子树
            dfs(node.left)
            # 递归遍历右子树
            dfs(node.right)
            
        dfs(root)
        # 用逗号将所有节点连接成一个字符串
        return ",".join(res)

    def deserialize(self, data):
        """将字符串反序列化为二叉树"""
        # 将字符串按逗号切分，并转换为迭代器，方便用 next() 按顺序获取
        values = iter(data.split(","))
        
        def dfs():
            val = next(values)
            # 如果当前卡片是 "None"，说明是空节点，直接返回
            if val == "None":
                return None
            
            # 1. 创建根节点
            node = TreeNode(int(val))
            # 2. 递归构建左子树
            node.left = dfs()
            # 3. 递归构建右子树
            node.right = dfs()
            
            return node
            
        return dfs()

```

### 4. 复杂度分析

* **时间复杂度**：$O(N)$
  * 无论是序列化还是反序列化，我们都需要对二叉树中的每一个节点（包括空节点 `None`）访问且仅访问一次。其中 $N$ 是二叉树中的节点总数。
* **空间复杂度**：$O(N)$
  * 序列化时，列表 `res` 需要存储所有节点和空节点的字符串，占用 $O(N)$ 空间。
  * 反序列化时，递归调用的栈深度以及 `values` 迭代器也取决于树的深度（最坏情况下链状树为 $O(N)$，平衡树为 $O(\log N)$），整体辅助空间复杂度为 $O(N)$。
