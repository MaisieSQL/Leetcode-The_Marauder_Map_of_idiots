### 169. Majority Element (多数元素)

* **难度**: 🟢 Easy
* **LeetCode 链接**: [Link](https://leetcode.com/problems/majority-element/)

### 💡 核心解法：Boyer-Moore 投票算法 (最优解)
由于题目说明“多数元素一定会存在且占据数组的一半以上（$> \lfloor n/2 \rfloor$）”，我们可以用计数抵消的思想：
1. **候选人 (`candidate`) 与 票数 (`count`)**：
   * 遍历数组，如果 `count == 0`，则将当前元素设为新的候选人。
   * 如果当前元素等于候选人，`count += 1`；如果不等于，`count -= 1`。
2. **原理**：由于多数元素的数量超过了一半，它最终留下的“投票”一定能胜过所有其他元素的抵消，成为最后的胜利者。

### 💻 Python 代码实现

```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        count = 0
        candidate = None
        
        for num in nums:
            if count == 0:
                candidate = num
            count += (1 if num == candidate else -1)
            
        return candidate
```

⏱ 复杂度分析
* **时间复杂度**: $O(N)$，只需对整个数组进行一次线性扫描。
* **空间复杂度**: $O(1)$，只需要常数级别的额外变量（`count` 和 `candidate`）来记录状态。
