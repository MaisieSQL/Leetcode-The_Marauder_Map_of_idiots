### LeetCode 2807. 在链表中插入最大公约数 (Insert Greatest Common Divisors in Linked List)

#### 📝 题目描述 (Description)
给你一个链表的头 `head`，每个结点包含一个整数值。

在相邻结点之间，请你插入一个新的结点，结点值为这两个相邻结点值的 **最大公约数（GCD）**。

请你返回插入之后的链表。

两个数的 **最大公约数** 是可以被两个数字整除的最大正整数。

**示例 1：**
* **输入：** `head = [18, 6, 10, 3]`
* **输出：** `[18, 6, 6, 2, 10, 1, 3]`
* **解释：**
  * 第一对相邻结点为 `18` 和 `6`，最大公约数为 `6`，插入两者之间。
  * 第二对相邻结点为 `6` 和 `10`，最大公约数为 `2`，插入两者之间。
  * 第三对相邻结点为 `10` 和 `3`，最大公约数为 `1`，插入两者之间。

**示例 2：**
* **输入：** `head = [7]`
* **输出：** `[7]`
* **解释：** 不存在相邻结点，直接返回原链表。

#### 🧠 一、 核心直觉与解题思路

##### 1. 辅助函数：欧几里得辗转相除法（求 GCD）
根据数论性质，两个正整数 $a$ 和 $b$ 的最大公约数等于其中较小的数与两数相除余数的最大公约数：
$$\gcd(a, b) = \gcd(b, a \bmod b)$$
* 不断用 `a, b = b, a % b` 迭代，直到余数 `b == 0` 时，此时的 `a` 即为最大公约数。
* **自动大小翻转特性**：即使初始时 `a < b`（如 `a = 6, b = 10`），第一轮 `6 % 10 = 6` 会自动将 `(a, b)` 交换为 `(10, 6)`，无需提前判断大小。

##### 2. 链表穿针引线（原地单次遍历）
使用指针 `curr` 从 `head` 开始遍历，只要 `curr` 和 `curr.next` 都存在，就执行以下 4 步标准动作：
1. **保存后继**：`nxt = curr.next`（防止插入新节点时丢失原链表后续节点）。
2. **创建新节点并连尾**：`gcd_node = ListNode(get_gcd(curr.val, nxt.val), nxt)`（新节点值设为最大公约数，且其 `next` 直接指向 `nxt`）。
3. **接入新节点**：`curr.next = gcd_node`。
4. **指针推进**：`curr = nxt`（跨过刚刚插入的 `gcd_node`，直接移动到下一个**原节点**，准备处理下一对相邻原节点）。

#### 💻 二、 Python 3 通关代码 (Solution)

##### 解法 1：手写辗转相除法（面试推荐）
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def insertGreatestCommonDivisors(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # 欧几里得辗转相除法求最大公约数
        def get_gcd(a: int, b: int) -> int:
            while b != 0:
                a, b = b, a % b
            return a

        curr = head
        # 只要当前节点和下一个节点都存在，就需要插入
        while curr and curr.next:
            nxt = curr.next
            # 创建新节点并指向 nxt
            gcd_node = ListNode(get_gcd(curr.val, nxt.val), nxt)
            # 当前节点指向新节点
            curr.next = gcd_node
            # 指针推进到下一个原节点（等效于跨越 2 步）
            curr = nxt

        return head
```

三、 复杂度分析 (Complexity Analysis)
- 时间复杂度：O(N * log(min(V)))。其中 N 为原链表节点数量，需遍历所有相邻节点对共 N - 1 次；每次计算两个数值（上限为 V）的最大公约数耗时 O(log(min(V)))。
- 空间复杂度：O(1)。除用于返回结果而新建的 N - 1 个链表节点外，算法本身只使用了常数个临时指针与变量，无额外辅助空间开销。

# LeetCode 50. Pow(x, n) 通关笔记

## 🎯 核心思路：为什么不用 DP，而用“快速幂”？
- **为什么不用 DP**：计算 $x^n$ 的过程中，只需要维护当前折半后的底数平方 `x * x` 和累计结果 `res`，不需要像传统 DP 那样保存整张状态表，直接用变量迭代即可省去额外数组空间。
- **什么是“折半”**：每次循环把指数 `n` 除以 2 缩小一半（`n //= 2`），同时让底数 `x` 自己和自己相乘平方（`x *= x`），把原本需要 $n$ 步的连乘压缩到对数级别。
- **负指数处理**：如果 `n < 0`，利用公式 $x^{-n} = (1/x)^n$，先将 `x = 1 / x`、`n = -n`，再统一走折半逻辑。

## 🧪 Dry Run 推演（以 `x = 2, n = 10` 为例）
- **初始状态**：`res = 1.0`, `x = 2`, `n = 10`
- **第 1 轮（`n = 10`，偶数）**：不乘入 `res`；底数平方 `x = 4`，指数折半 `n = 5`
- **第 2 轮（`n = 5`，奇数）**：`res = 1.0 * 4 = 4.0`；底数平方 `x = 16`，指数折半 `n = 2`
- **第 3 轮（`n = 2`，偶数）**：不乘入 `res`；底数平方 `x = 256`，指数折半 `n = 1`
- **第 4 轮（`n = 1`，奇数）**：`res = 4.0 * 256 = 1024.0`；底数平方 `x = 65536`，指数折半 `n = 0`
- **结束循环**：`n == 0`，返回 `1024.0`。

## 💻 Python3 代码实现

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1 / x
            n = -n

        res = 1.0
        while n > 0:
            if n % 2 == 1:
                res *= x
            x *= x
            n //= 2

        return res
```

复杂度分析
- 时间复杂度：O(log n)，每次循环指数折半，最多迭代约 log2(n) 次。
- 空间复杂度：O(1)，仅使用常数个辅助变量进行原地迭代。

除了我们刚才讲的迭代快速幂之外，LeetCode 50. Pow(x, n) 还有另外两种非常经典的解法，各自有不同的视角和适用场景：

### 1. 递归快速幂（分治折半）
和迭代思路完全一样，只是把“循环折半”改成了“函数自己调自己折半”：
- **核心逻辑**：
  - 如果 `n == 0`，返回 `1.0`。
  - 递归算一半：`half = self.myPow(x, n // 2)`。
  - 如果 `n` 是偶数，直接返回 `half * half`；如果 `n` 是奇数，多乘一个 `x`：`half * half * x`。
- **复杂度**：时间复杂度 `O(log n)`，但因为递归调用栈深度为 `O(log n)`，空间复杂度也是 `O(log n)`（不如迭代的 `O(1)` 省空间）。

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        def quick_mul(exponent: int) -> float:
            if exponent == 0:
                return 1.0
            half = quick_mul(exponent // 2)
            return half * half if exponent % 2 == 0 else half * half * x

        if n < 0:
            return 1.0 / quick_mul(-n)
        return quick_mul(n)
```

2. 位运算版快速幂（把 `n // 2` 和 `n % 2` 换成位操作）
其实它就是迭代快速幂的底层写法：
- `n & 1` 等价于判断 `n % 2 == 1`（看二进制最低位是不是 1）。
- `n >>= 1` 等价于 `n //= 2`（二进制右移一位，相当于除以 2）。
- 复杂度：时间 `O(log n)`，空间 `O(1)`，位运算在底层通常更快一点，逻辑和迭代完全一致。

```python
class Solution:
    def myPow(self, x: float, n: int) -> float:
        if n < 0:
            x = 1 / x
            n = -n

        res = 1.0
        while n > 0:
            if n & 1:
                res *= x
            x *= x
            n >>= 1

        return res
```
