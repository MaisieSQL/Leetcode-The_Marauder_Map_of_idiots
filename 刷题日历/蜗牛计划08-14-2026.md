# LeetCode 682. 棒球比赛 (Baseball Game)

## 🎯 一、 核心考点与物理直觉

- **题目大意**：
  你现在是一家棒球比赛的记分员。比赛以局为单位，记录员会按顺序收到一串操作字符串列表 `operations`。
  你需要根据以下规则实时计算并返回比赛结束时的总得分：
  - 整数 `x`：表示本局新获得分数 `x`。
  - `"+"`：表示本局得分是前两次有效得分的总和。
  - `"D"`：表示本局得分是前一次有效得分的两倍。
  - `"C"`：表示使前一次有效得分失效（从记录中移除）。
- **物理直觉**：
  - 这是一道典型的**“栈 (Stack) 模拟题”**。
  - 因为所有的得分规则（求前一次、前两次的总和，或者移除最近一次）全部具有极强的**“后进先出 (LIFO)”**特性。
  - 栈底到栈顶实时记录着当前有效的得分序列。每来一个操作符，我们只需要直接从栈顶弹出或窥探最近的元素进行计算，然后把新结果压入栈中即可。最后直接对栈内所有元素求和！

## 💻 二、 工业级 Python3 代码实现 (Solution)

```python
class Solution(object):
    def calPoints(self, operations):
        """:type operations: List[str]
        :rtype: int
        """
        stack = []
        
        for op in operations:
            if op == "+":
                # 本局得分是前两次有效得分的总和
                # stack[-1] 是前一次，stack[-2] 是前两次
                stack.append(stack[-1] + stack[-2])
            elif op == "D":
                # 本局得分是前一次有效得分的两倍
                stack.append(stack[-1] * 2)
            elif op == "C":
                # 移除前一次有效得分
                stack.pop()
            else:
                # 纯数字字符串，转化为整数后入栈
                stack.append(int(op))
                
        # 比赛结束，对栈内所有有效得分求和
        return sum(stack)
```

⏱️ 三、 复杂度核验 (Complexity Analysis)

- **时间复杂度**：O(N)
  - 其中 N 是操作列表 operations 的长度。我们只需要对整个操作数组进行一次从头到尾的线性扫描，栈的 append、pop 和最后的 sum 均摊下来都是单次常数开销。
- **空间复杂度**：O(N)
  - 最坏情况下（全部都是数字操作），栈需要完整存下所有的 N 个得分记录。
