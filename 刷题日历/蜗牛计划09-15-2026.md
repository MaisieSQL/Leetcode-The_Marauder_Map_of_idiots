# LeetCode 338. Counting Bits (比特位计数)

## 📌 题目描述
给你一个整数 $n$，计算从 $0$ 到 $n$ 的每个数字 $i$ 的二进制表示中 **$1$ 的个数**，返回一个长度为 $n + 1$ 的数组 `ans` 作为答案。

* **示例 1**:
  * **输入**: `n = 2`
  * **输出**: `[0, 1, 1]`
  * **解释**:
    * $0 \to 0$ (0 个 1)
    * $1 \to 1$ (1 个 1)
    * $2 \to 10$ (1 个 1)
* **示例 2**:
  * **输入**: `n = 5`
  * **输出**: `[0, 1, 1, 2, 1, 2]`
  * **解释**:
    * $0 \to 0$ (0)
    * $1 \to 1$ (1)
    * $2 \to 10$ (1)
    * $3 \to 11$ (2)
    * $4 \to 100$ (1)
    * $5 \to 101$ (2)
* **数据范围**:
  * $0 \le n \le 10^5$
* **进阶要求 (Follow-up)**:
  * 能否在 $O(n)$ 线性时间、单趟扫描内搞定，且不调用任何内置函数（如 `__builtin_popcount`）？

## 💡 核心考点与降维直觉

题目禁止使用库函数，若对每个数字独立调用一次 Brian Kernighan 算法（`x & (x - 1)`）统计 $1$ 的个数，单次耗时 $O(\log n)$，整体时间复杂度为 $O(n \log n)$。

要想突破至 **$O(n)$ 线性单趟**，必须借助 **动态规划（DP）**，利用二进制位操作从“已经算好的较小数值”直接递推得出：

### 核心观察（最低有效位转移）

任意一个正整数 i：
1. **i >> 1（等价于整除 2）**：在二进制形态下相当于**向右平移一位、丢弃最低位**。
2. **i & 1（等价于模 2）**：用来提取**最低位是否为 1**。
3. 因此：**i 中 1 的个数，等于 i >> 1 中 1 的个数加上最低位本身**。


### 递推公式
dp[i] = dp[i >> 1] + (i & 1)

* 举例：
  * 5 的二进制为 101[cite: 2]
  * 5 >> 1 = 2（二进制 10），此时已在前面算好 dp[2] = 1[cite: 2]
  * 5 & 1 = 1[cite: 2]
  * dp[5] = dp[2] + 1 = 1 + 1 = 2[cite: 2]

由于递推依赖的 $i >> 1 < i$，从小到大遍历即可保证每个子问题在被引用前已计算完毕。

## 💻 Python 3 工业级标准实现

```python
class Solution:
    def countBits(self, n: int) -> list[int]:
        # 开辟大小为 n + 1 的 dp 数组，初始全为 0
        dp = [0] * (n + 1)
        
        # 从 1 到 n 单趟递推
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)
            
        return dp
```

## ⏱️ 复杂度分析

* **时间复杂度**：$O(n)$。从 $1$ 到 $n$ 只进行单趟线性循环，每次状态转移仅包含一次位移和一次按位与操作（均为 $O(1)$ 常数时间）。
* **空间复杂度**：$O(1)$。除了用于返回结果所必须开辟的长度为 $n + 1$ 的数组外，没有分配任何额外辅助空间（若计入输出数组则为 $O(n)$）。

# 什么是 Brian Kernighan 算法？

Brian Kernighan 算法是一种用于在计算机底层统计一个整数二进制表示中 **1 的个数（汉明重量 Hamming Weight）** 的最优位运算技巧。

它的核心只有一句话：**每次执行 `n & (n - 1)`，可以在常数时间内精准抹掉二进制表示中最右侧的那个 1**。

### 1. 为什么 n & (n - 1) 能抹掉最右边的 1？

我们从二进制减法借位的原理来看：
* 当一个数减 1（即 `n - 1`）时，它最右侧的那个 1 会借位变成 0，而这个 1 右边所有的 0 都会变成 1。
* 这个 1 左边的高位则完全不受影响。
* 此时执行按位与 `n & (n - 1)`：
  * 最右边的 1 变成了 0，与原本的 1 相与结果为 0；
  * 右侧原本为 0 的位置与翻转后的 1 相与依然为 0；
  * 左边未变化的高位全部保留。

**实操演示（以数字 10 为例）**：
* 10 的二进制是 `1010`[cite: 1]
* 10 - 1 = 9，其二进制为 `1001`[cite: 1]
* 执行 `1010 & 1001`：得到 `1000`（最右边的那个 1 直接被精准消除）[cite: 1]

### 2. 标准代码实现 (Python 3)

只要 n > 0，每执行一次 `n = n & (n - 1)`，计数器就加 1，直到 n 变成 0 为止[cite: 1]：

```python
def count_ones(n: int) -> int:
    count = 0
    while n > 0:
        n &= (n - 1)  # 抹掉最右侧的一个 1
        count += 1
    return count
```

### 3. 它比普通逐位右移好在哪？

* **普通解法（逐位右移）**：用 `n >> 1` 配合 `n & 1` 检查每一位[cite: 1]。对于标准 32 位整型，无论里面有几个 1，循环必须死跑 **32 次**[cite: 1]。
* **Brian Kernighan 算法**：**二进制里有几个 1，循环就只跑几次**[cite: 1]。
  * 若输入为 8（二进制 `1000`，只有 1 个 1），循环只跑 1 次[cite: 1]；
  * 时间复杂度严格为 O(k)，其中 k 为数字中 1 的个数，效率远高于固定 32 次遍历[cite: 1]。

### 4. 经典高频衍生应用

除了在 LeetCode 191（位 1 的个数）中统计 1 的个数之外，它在大厂面试中最常见的变体是**判断一个数是不是 2 的幂次方**[cite: 1]：

* **原理**：如果一个数是 2 的幂次方（如 2、4、8、16），其二进制表示中**有且仅有 1 个 1**（例如 8 为 `1000`）[cite: 1]。
* **代码**：

```python
def is_power_of_two(n: int) -> bool:
    return n > 0 and (n & (n - 1)) == 0
```
