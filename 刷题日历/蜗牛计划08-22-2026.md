# LeetCode 1094: Car Pooling (拼车)

## 📌 题目描述

车上最初有 `capacity` 个空座位。车只能向一个方向行驶（即不能回头或改变方向）。

给定一个整数 `capacity` 和一个数组 `trips`，其中 `trips[i] = [numPassengers_i, from_i, to_i]` 表示第 `i` 次行程，有 `numPassengers_i` 位乘客在 `from_i` 位置上车，并在 `to_i` 位置下车。

如果可以在所有给定的行程中顺畅乘客且**不超载**，返回 `true`；否则，返回 `false`。

## 💡 核心思路：差分数组 (Difference Array)

### 为什么用差分数组？
对于每一个行程 `[passengers, start, end]`，这意味着在区间 **`[start, end - 1]`** 的每一段路上，车上都要增加 `passengers` 个乘客。
* 如果用**暴力模拟**：每次拿到行程都去遍历区间 `[start, end - 1]` 逐个加人数，整体时间复杂度会达到 $O(N \times \text{Distance})$，容易超时。
* 如果用**差分数组**：
  * 在 `start` 站：`diff[start] += passengers`（表示从这一站开始，车上增加了这么多乘客）。
  * 在 `end` 站：`diff[end] -= passengers`（表示在这一站乘客已经下车，车上减少了这么多乘客）。
  * 每次修改的时间复杂度仅为 **$O(1)$**。

处理完所有行程后，我们对差分数组求一次**前缀和（累加值）**，即可得到车在每一站的实际乘客数。只要过程中任何一站的乘客数超过 `capacity`，直接返回 `false`。

## 🐍 Python 3 完整代码

```python
class Solution:
    def carPooling(self, trips: list[list[int]], capacity: int) -> bool:
        # 根据题目数据范围，车站最大下标不超过 1000
        # 创建大小为 1001 的差分数组
        diff = [0] * 1001
        
        # 1. 记录每个行程的上下车变动
        for passengers, start, end in trips:
            diff[start] += passengers  # 上车
            diff[end] -= passengers    # 下车
            
        # 2. 前缀和还原每一站的实际人数
        current_passengers = 0
        for num in diff:
            current_passengers += num
            # 如果某一段路程的人数超过容量上限，返回 False
            if current_passengers > capacity:
                return False
                
        return True
```

### 复杂度分析

- **时间复杂度**：$O(N + M)$
  - $N$ 为 trips 的数量，遍历行程数组登记上下车变动需要 $O(N)$。
  - $M$ 为车站的最大范围（本题固定为 1001），扫描前缀和需要 $O(M)$。
  - 整体耗时极低，线性时间解决。
- **空间复杂度**：$O(M)$
  - 只需要一个固定大小的差分数组存储各个车站的人数变动，空间开销为常量级别 $O(1001) = O(1)$。
