# LeetCode 953. 验证外星语词典（Verifying an Alien Dictionary）题目解析

「验证外星语词典」（Verifying an Alien Dictionary）是 LeetCode 第 953 题，是一道关于字符串比较和哈希表映射的简单级别题目。

## 1. 题目描述

某种外星语也使用英文小写字母，但可能顺序不同。字母表的顺序（`order`）是一些小写字母的排列。

给定一组用外星语书写的单词 `words` 和其字母表的顺序 `order`，只有当给出的单词在这种外星语中按字典序排列时，返回 `true`；否则，返回 `false`。

## 2. 核心思路

题目要求判断单词数组是否按照外星字母表的顺序升序排列。这与常规字典序比较类似，区别在于字母的先后顺序由给定的 `order` 决定。

1. **建立索引映射**：
   使用哈希表（或固定大小的数组）记录 `order` 中每个字母的相对位置（索引从 `0` 到 `25`），这样可以在 $O(1)$ 时间内比较任意两个外星字母的大小。
2. **两两比较相邻单词**：
   遍历 `words` 数组，依次比较相邻的两个单词 `words[i]` 和 `words[i+1]`：
   * 从左到右逐个字符进行对比。
   * 如果找到第一个不同的字符，根据它们在 `order` 中的索引决定大小：
     * 若前一个单词的字符小于后一个单词的字符，说明这一对单词顺序正确，停止对比，检查下一对。
     * 若前一个单词的字符大于后一个单词的字符，说明顺序错误，直接返回 `false`。
   * 如果较短单词的所有字符都与较长单词的前缀完全相同，但较长单词排在前面（例如 `w1 = "apple", w2 = "app"`），则不符合字典序，返回 `false`。
3. **完成遍历**：如果所有相邻单词都满足条件，则返回 `true`。

## 3. 代码实现 (Python)

```python
class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        # 建立外星字母到索引的映射字典
        order_map = {c: i for i, c in enumerate(order)}
        
        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i+1]
            
            is_sorted = False
            # 逐个字符比较
            for c1, c2 in zip(w1, w2):
                if order_map[c1] < order_map[c2]:
                    is_sorted = True
                    break
                elif order_map[c1] > order_map[c2]:
                    return False
            
            # 如果没有找到不同字符，检查长度（例如 "apple" 和 "app"）
            if not is_sorted and len(w1) > len(w2):
                return False
                
        return True
```

## 4. 复杂度分析

* **时间复杂度**：$O(M)$，其中 $M$ 是 `words` 中所有字符串的总字符数。我们最多需要遍历所有单词的所有字符进行比较。
* **空间复杂度**：$O(1)$，因为外星字母表的大小固定为 26 个英文字母，哈希映射占用的空间是常数级别的。

# LeetCode 322. 零钱兑换（Coin Change）题目解析

「零钱兑换」（Coin Change）是 LeetCode 第 322 题，是一道经典的完全背包类型动态规划问题。

## 1. 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算可以凑成总金额所需的最少的硬币个数。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

## 2. 核心思路

这是一道标准的动态规划问题。我们可以通过自底向上的方式递推求出凑成每个金额所需的最少硬币数。

* **状态定义**：设 `dp[i]` 表示凑成总金额 `i` 所需的**最少硬币个数**。
* **状态初始化**：
  * `dp[0] = 0`，表示凑成金额为 0 需要 0 个硬币。
  * 为了方便后续取最小值，其余的 `dp` 值可以初始化为一个较大的数（例如 `amount + 1` 或 `float('inf')`）。
* **状态转移方程**：
  对于每一个金额 `i`（从 `1` 到 `amount`），遍历所有的硬币面额 `coin`：
  * 如果当前金额大于等于硬币面额（即 `i >= coin`），则可以用这枚硬币，状态转移方程为：
    $$\text{dp}[i] = \min(\text{dp}[i], \text{dp}[i - \text{coin}] + 1)$$
* **最终结果**：
  遍历结束后，如果 `dp[amount]` 仍然是初始的大值，说明无法凑出该金额，返回 `-1`；否则返回 `dp[amount]`。

## 3. 代码实现 (Python)

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        # 初始化 dp 数组，长度为 amount + 1，初始值为无穷大
        dp = [float('inf')] * (amount + 1)
        dp[0] = 0
        
        # 遍历从 1 到 amount 的所有金额
        for i in range(1, amount + 1):
            for coin in coins:
                if i - coin >= 0:
                    dp[i] = min(dp[i], dp[i - coin] + 1)
                    
        return dp[amount] if dp[amount] != float('inf') else -1
```

## 4. 复杂度分析

* **时间复杂度**：O(S * N)，其中 S 是金额 amount，N 是硬币种类数 coins 的长度。我们需要两层循环，外层循环执行 S 次，内层循环执行 N 次。
* **空间复杂度**：O(S)，需要创建一个大小为 amount + 1 的一维 dp 数组。

# LeetCode 416. 分割等和子集（Partition Equal Subset Sum）题目解析

「分割等和子集」（Partition Equal Subset Sum）是 LeetCode 第 416 题，是一道经典的 0-1 背包类型动态规划问题。

## 1. 题目描述

给你一个只包含正整数的非空数组 `nums`。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

## 2. 核心思路

这道题可以转化为经典的 **0-1 背包问题**。

1. **求和与奇偶判断**：
   先计算数组中所有元素的总和 `total_sum`。如果 `total_sum` 是奇数，那么无论如何也无法平分成两个相等的整数子集，直接返回 `false`。
2. **确定目标容量**：
   如果 `total_sum` 是偶数，设目标和 `target = total_sum // 2`。问题就变成了：**从数组中选择若干个元素，能否使它们的和恰好等于 `target`**。
3. **动态规划状态定义与转移**：
   * **状态定义**：设 `dp[j]` 为一个布尔值，表示是否可以从数组中选出一些元素，使得它们的和恰好为 `j`。
   * **状态初始化**：`dp[0] = true`（表示和为 0 的子集总是存在的，即什么都不选），其余均为 `false`。
   * **状态转移方程**：对于数组中的每一个数字 `num`，从 `target` 向下遍历到 `num`（逆序遍历是为了保证每个数字只被使用一次，符合 0-1 背包的特性）：
     `dp[j] = dp[j] or dp[j - num]`
4. **最终结果**：
   遍历结束后，返回 `dp[target]` 的值即可。

## 3. 代码实现 (Python)

```python
class Solution:
    def canPartition(self, nums: List[int]) -> bool:
        total_sum = sum(nums)
        # 如果总和为奇数，不可能平分
        if total_sum % 2 != 0:
            return False
            
        target = total_sum // 2
        # dp[j] 表示是否能凑出总和为 j 的子集
        dp = [False] * (target + 1)
        dp[0] = True
        
        for num in nums:
            # 逆序遍历，避免重复使用同一个元素
            for j in range(target, num - 1, -1):
                dp[j] = dp[j] or dp[j - num]
                
        return dp[target]
```

## 4. 复杂度分析

* **时间复杂度**：O(N * Target)，其中 N 是数组的长度，Target 是数组元素总和的一半。我们需要遍历整个数组，内层循环执行 Target 次。
* **空间复杂度**：O(Target)，需要创建一个长度为 Target + 1 的一维 dp 数组。
