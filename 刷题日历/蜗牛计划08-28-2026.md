# LeetCode 104. Maximum Depth of Binary Tree (二叉树的最大深度)

## 📝 题目描述 (Description)
给定一个二叉树的根节点 `root`，找出并返回其**最大深度**[cite: 4]。
二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数（叶子节点是指没有子节点的节点）[cite: 4]。

---

## 🛠️ 多种解法与代码实现 (Multiple Solutions)

### 方法一：递归流（自底向上 DFS / 甩手掌柜法）── 最经典、最优雅
#### 💡 核心直觉
把你自己当成大老板（根节点），你把左右副总叫来，让他们各自汇报左右子树的最大深度。你只需要挑出最大的一边，然后加上你自己的那一层（`+ 1`）即可[cite: 4]。

#### 💻 Python3 代码实现
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right


class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    # 1. 递归出口：空节点深度为 0
    if not root:
      return 0

    # 2. 递归获取左右子树的最大深度
    left_depth = self.maxDepth(root.left)
    right_depth = self.maxDepth(root.right)

    # 3. 左右取最大值，并加上当前根节点所在的这一层
    return max(left_depth, right_depth) + 1
```

### 方法二：广度优先搜索流（BFS / 层序遍历计数）── 工业级队列迭代
#### 💡 核心直觉
使用队列（Queue）进行层序遍历。每一层扫过去时，用 `step` 计数器记录层数。整棵树被剥完几层，最大深度就是几。

#### 💻 Python3 代码实现
```python
from collections import deque


class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    if not root:
      return 0

    queue = deque([root])
    depth = 0

    while queue:
      level_size = len(queue)
      for _ in range(level_size):
        node = queue.popleft()
        if node.left:
          queue.append(node.left)
        if node.right:
          queue.append(node.right)
      # 每一层处理完，深度 +1
      depth += 1

    return depth
```

### 方法三：前序遍历迭代流（DFS 显式栈 + 状态追踪）
#### 💡 核心直觉
用显式栈模拟递归过程，在栈里同时存储节点和它当前对应的深度。边往下走边用全局变量或比对刷新最大深度。

#### 💻 Python3 代码实现
```python
class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    if not root:
      return 0

    stack = [(root, 1)]
    max_d = 0

    while stack:
      node, depth = stack.pop()
      if node:
        max_d = max(max_d, depth)
        if node.left:
          stack.append((node.left, depth + 1))
        if node.right:
          stack.append((node.right, depth + 1))

    return max_d
```

复杂度核验 (Complexity Analysis)
- 时间复杂度：$O(N)$ —— 其中 $N$ 是二叉树的节点总数。每一个节点在遍历过程中都恰好被访问一次。
- 空间复杂度：$O(H)$ —— 其中 $H$ 是树的高度。主要消耗在递归调用栈（或 BFS 队列）上。在最坏情况下（链状树），空间复杂度为 $O(N)$；在平衡二叉树中，空间复杂度为 $O(\log N)$。

# LeetCode 17. Letter Combinations of a Phone Number (电话号码的字母组合)

## 📝 题目描述 (Description)
给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按**任意顺序**返回。
给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

- `2`: "abc"
- `3`: "def"
- `4`: "ghi"
- `5`: "jkl"
- `6`: "mno"
- `7`: "pqrs"
- `8`: "tuv"
- `9`: "wxyz"

### 💡 示例 1:
- **Input**: `digits = "23"`
- **Output**: `["ad","ae","af","bd","be","bf","cd","ce","cf"]`

## 🧠 一、 核心心法与物理直觉 (Backtracking Core)
1. **树形结构的诞生**：
   - 如果输入是 `"23"`，第一位是 `'2'`（对应 `'a', 'b', 'c'`），第二位是 `'3'`（对应 `'def'`）。
   - 这就像是一个多叉树：根节点向下分 3 条叉，每个子节点再向下分多条叉。我们要找的就是从根节点走到所有叶子节点的全路径。
2. **回溯三部曲（选择 $\rightarrow$ 递归 $\rightarrow$ 撤销）**：
   - **选择**：把当前候选字母加入临时路径（`path.append(letter)`）。
   - **递归**：带着新路径去处理下一个数字（`backtracking(index + 1, path)`）。
   - **撤销**：从深处返回后，立刻弹出刚才的字母（`path.pop()`），尝试同层的下一个候选分支。

## 💻 二、 满分通关代码 (Python 3)

```python
class Solution:

  def letterCombinations(self, digits: str) -> list[str]:
    # 边界防御：如果输入的数字串为空，直接返回空列表
    if not digits:
      return []

    res = []
    # 💡 键必须是字符串 str，因为 digits[index] 拿出来的是字符
    digitMap = {
        '2': 'abc',
        '3': 'def',
        '4': 'ghi',
        '5': 'jkl',
        '6': 'mno',
        '7': 'pqrs',
        '8': 'tuv',
        '9': 'wxyz',
    }

    def backtracking(index, path):
      # 递归出口：如果路径长度等于输入的数字长度，说明拼成了一个完整组合
      if index == len(digits):
        res.append(''.join(path))
        return

      curr_digit = digits[index]
      char = digitMap[curr_digit]

      for i in char:
        path.append(i)  # 1. 做选择
        backtracking(index + 1, path)  # 2. 递归处理下一层
        path.pop()  # 3. 撤销选择

    backtracking(0, [])
    return res
```

### 三、 复杂度核验 (Complexity Analysis)
- **时间复杂度**：$O(4^N * N)$ —— 其中 $N$ 是输入数字字符串 `digits` 的长度。在最坏情况下（比如数字全是 7 或 9，对应 4 个字母），每个数字有 4 种分支，总叶子节点数最多可达 $4^N$ 个，每次把路径拼成字符串需要 $O(N)$ 的时间。
- **空间复杂度**：$O(N)$ —— 主要消耗在递归调用栈的深度（最大深度为 $N$）以及临时存储路径的 `path` 空间上。
