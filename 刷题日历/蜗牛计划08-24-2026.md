# LeetCode 226. 翻转二叉树 (Invert Binary Tree)

## 题目描述
给你一棵二叉树的根节点 `root`，请你翻转这棵二叉树，并返回其根节点的指针。
翻转二叉树的定义是：对于树中的每一个节点，交换它的左子树和右子树。

## 解析与思路
翻转二叉树是一道非常经典的递归（DFS）题目。你可以用“分治”的思维来理解它：
* **边界条件（终止条件）**：如果当前节点 `root` 是空（`None`），说明已经走到了叶子节点的下方，直接返回 `None`。
* **递归处理子树**：
  * 递归调用函数去翻转左子树：`left = self.invertTree(root.left)`
  * 递归调用函数去翻转右子树：`right = self.invertTree(root.right)`
* **交换**：把当前节点的左指针指向刚才翻转好的右子树（`root.left = right`），把右指针指向翻转好的左子树（`root.right = left`）。
* **返回**：最后返回当前节点 `root`。

整棵树的每一个节点都会重复这个“交换左右孩子”的过程，当递归一层层退回根节点时，整棵树就已经被完美翻转了。

## 代码实现 (Python)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def invertTree(self, root: TreeNode | None) -> TreeNode | None:
        # 1. 递归的终止条件：如果节点为空，直接返回
        if not root:
            return None
        
        # 2. 递归翻转左子树和右子树
        root.left, root.right = self.invertTree(root.right), self.invertTree(root.left)
        
        # 3. 返回翻转后的根节点
        return root
```

### 复杂度分析

* **时间复杂度**：$O(N)$，其中 $N$ 是二叉树中的节点总数。每一个节点都会被访问并交换一次。
* **空间复杂度**：$O(H)$，其中 $H$ 是树的高度。空间主要消耗在递归调用的栈空间上。在最坏情况下（比如链状树），空间复杂度为 $O(N)$；在平衡二叉树下，空间复杂度为 $O(\log N)$。
