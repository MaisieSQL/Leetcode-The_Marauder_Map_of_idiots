# LeetCode 338. Counting Bits (比特位计数)

## 📌 题目描述
给你一个整数 $n$，计算从 $0$ 到 $n$ 的每个数字 $i$ 的二进制表示中 **$1$ 的个数**，返回一个长度为 $n + 1$ 的数组 `ans` 作为答案。

* **示例 1**:
  * **输入**: `n = 2`
  * **输出**: `[0, 1, 1]`
  * **解释**:
    * $0 \to 0$ (0 个 1)
    * $1 \to 1$ (1 个 1)
    * $2 \to 10$ (1 个 1)
* **示例 2**:
  * **输入**: `n = 5`
  * **输出**: `[0, 1, 1, 2, 1, 2]`
  * **解释**:
    * $0 \to 0$ (0)
    * $1 \to 1$ (1)
    * $2 \to 10$ (1)
    * $3 \to 11$ (2)
    * $4 \to 100$ (1)
    * $5 \to 101$ (2)
* **数据范围**:
  * $0 \le n \le 10^5$
* **进阶要求 (Follow-up)**:
  * 能否在 $O(n)$ 线性时间、单趟扫描内搞定，且不调用任何内置函数（如 `__builtin_popcount`）？

## 💡 核心考点与降维直觉

题目禁止使用库函数，若对每个数字独立调用一次 Brian Kernighan 算法（`x & (x - 1)`）统计 $1$ 的个数，单次耗时 $O(\log n)$，整体时间复杂度为 $O(n \log n)$。

要想突破至 **$O(n)$ 线性单趟**，必须借助 **动态规划（DP）**，利用二进制位操作从“已经算好的较小数值”直接递推得出：

### 核心观察（最低有效位转移）

任意一个正整数 i：
1. **i >> 1（等价于整除 2）**：在二进制形态下相当于**向右平移一位、丢弃最低位**。
2. **i & 1（等价于模 2）**：用来提取**最低位是否为 1**。
3. 因此：**i 中 1 的个数，等于 i >> 1 中 1 的个数加上最低位本身**。


### 递推公式
dp[i] = dp[i >> 1] + (i & 1)

* 举例：
  * 5 的二进制为 101[cite: 2]
  * 5 >> 1 = 2（二进制 10），此时已在前面算好 dp[2] = 1[cite: 2]
  * 5 & 1 = 1[cite: 2]
  * dp[5] = dp[2] + 1 = 1 + 1 = 2[cite: 2]

由于递推依赖的 $i >> 1 < i$，从小到大遍历即可保证每个子问题在被引用前已计算完毕。

## 💻 Python 3 工业级标准实现

```python
class Solution:
    def countBits(self, n: int) -> list[int]:
        # 开辟大小为 n + 1 的 dp 数组，初始全为 0
        dp = [0] * (n + 1)
        
        # 从 1 到 n 单趟递推
        for i in range(1, n + 1):
            dp[i] = dp[i >> 1] + (i & 1)
            
        return dp
```

## ⏱️ 复杂度分析

* **时间复杂度**：$O(n)$。从 $1$ 到 $n$ 只进行单趟线性循环，每次状态转移仅包含一次位移和一次按位与操作（均为 $O(1)$ 常数时间）。
* **空间复杂度**：$O(1)$。除了用于返回结果所必须开辟的长度为 $n + 1$ 的数组外，没有分配任何额外辅助空间（若计入输出数组则为 $O(n)$）。
