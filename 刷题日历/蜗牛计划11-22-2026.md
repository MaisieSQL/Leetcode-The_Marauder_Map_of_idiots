# LeetCode 2013. 检测正方形 (Detect Squares)

## 一、 题目描述
给你一个在 X-Y 平面上的点构成的数据流。设计一个满足下述要求的算法：
- **添加** 一个在数据流中的新点 `point = [x, y]`。允许存在多个值相同的点，即多个点可以与当前数据流中的其他点重叠。
- **统计** 满足下述条件的正方形个数：给定一个查询点 `point = [px, py]`，选择数据流中的三个点，使得这三个点和查询点组成一个面积大于 `0` 的正方形，且正方形的四条边都平行于 X 轴和 Y 轴。

## 二、 解题思路

### 1. 统计点的出现次数
因为允许重复添加相同的点，我们可以用一个哈希表（如 `defaultdict(int)`）记录每个点 `(x, y)` 出现的次数。当某个正方形的顶点出现多次时，根据乘法原理，不同重复点之间可以组合出多种方案，因此需要把对应顶点的出现次数相乘。

### 2. 枚举对角顶点
已知查询点为 `P = (px, py)`：
- 如果我们把数据流中已有的某个点 `Q = (x, y)` 当作与 `P` **相对的对角顶点**，那么正方形另外两个顶点的坐标就唯一确定了：
  - `A = (px, y)`（与 `P` 同 `x`，与 `Q` 同 `y`）
  - `B = (x, py)`（与 `Q` 同 `x`，与 `P` 同 `y`）
- 满足构成**面积大于 0 且边平行于坐标轴的正方形**的条件是：
  - 横向距离 `dx = abs(x - px)` 等于纵向距离 `dy = abs(y - py)`；
  - 且边长不能为 `0`（即 `dx != 0`）。

### 3. 计算方案数
对于满足上述条件的每个对角点 `(x, y)`：
- 检查 `(px, y)`、`(x, py)`、`(x, y)` 是否都在数据流中。
- 若都在，则该对角点贡献的正方形数量为：
  `count[(px, y)] * count[(x, py)] * count[(x, y)]`
- 将所有合法对角点的贡献累加即可。

## 三、 Python3 参考代码

```python
import math
from collections import defaultdict


class DetectSquares:

    def __init__(self):
        self.collector = defaultdict(int)

    def add(self, point: list[int]) -> None:
        self.collector[tuple(point)] += 1

    def count(self, point: list[int]) -> int:
        px, py = point
        res = 0
        for x, y in self.collector:
            if (dx := abs(x - px)) == (dy := abs(y - py)) != 0:
                points = ((px, y), (x, py), (x, y))
                if all(p in self.collector for p in points):
                    res += math.prod(self.collector[p] for p in points)
        return res
```

四、 复杂度分析
- add 时间复杂度：O(1)，哈希表插入与计数更新均为常数时间。
- count 时间复杂度：O(N)，其中 N 为当前数据流中不同点的数量；每次查询遍历已记录的点并做 O(1) 哈希查找。
- 空间复杂度：O(N)，用于存储各个点的出现次数。

# LeetCode 7. 整数反转 (Reverse Integer)

## 一、 题目描述
给你一个 32 位的有符号整数 `x`，返回将 `x` 中的数字部分反转后的结果。
如果反转后整数超过 32 位的有符号整数的范围 `[-2^31, 2^31 - 1]`，就返回 `0`。

- **假设环境不允许存储 64 位整数（有符号或无符号）。**

## 二、 解题思路

### 1. 逐位提取与拼接
将数字按十进制从右往左一位一位“抽”出来，倒着拼成新数字：
- 设当前待处理正数为 `num`，反转累计值为 `rev = 0`。
- 每次通过 `digit = num % 10` 取出最右边的数字，通过 `num //= 10` 去掉最右边的数字。
- 将 `rev` 进位并拼接：`rev = rev * 10 + digit`。

### 2. 正负号处理
- 先记录符号 `sign = -1 if x < 0 else 1`，再令 `num = abs(x)` 按正数统一反转，最后乘回 `sign` 得到带符号结果 `ans`。

### 3. 32 位有符号整数溢出边界检查
- 32 位有符号整数合法区间为 `[-2147483648, 2147483647]`（即 `[-2^31, 2^31 - 1]`）。
- 若反转后的结果超出该范围，返回 `0`。

## 三、 Python3 参考代码

```python
class Solution:
    def reverse(self, x: int) -> int:
        min_int = -(2**31)
        max_int = 2**31 - 1

        sign = -1 if x < 0 else 1
        num = abs(x)
        rev = 0

        while num != 0:
            digit = num % 10
            num //= 10
            rev = rev * 10 + digit

        ans = sign * rev
        if ans < min_int or ans > max_int:
            return 0
        return ans
```

四、 复杂度分析
- 时间复杂度：O(log|x|)，十进制位数决定循环次数（32 位整数最多 10 位）。
- 空间复杂度：O(1)，仅使用常数级别的额外变量。
