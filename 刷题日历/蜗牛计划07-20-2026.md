## 🎯 背向双指针（中心扩散）刷题清单：Easy ➔ Medium ➔ Hard

背向双指针的核心逻辑：**选定对称轴/中心点，向左右两侧扩散 (`left <- -> right`)，利用对称性校验结构。**

### 1. Easy 基础入门

### 📌 LeetCode 125. Valid Palindrome (验证回文串)
* **题目链接：** [LeetCode 125](https://leetcode.com/problems/valid-palindrome/)
* **解题思路：** 清理非字母数字字符后，找到字符串中心（奇数长取正中间，偶数长取中间两个），用背向双指针向两边扩散校验。
* **训练目标：** 熟悉中心点的定义与边界控制。

### 2. Medium 核心主力（必刷重点）

### 📌 LeetCode 5. Longest Palindromic Substring (最长回文子串)
* **题目链接：** [LeetCode 5](https://leetcode.com/problems/longest-palindromic-substring/)
* **解题思路：** 遍历所有可能中心，分别以 `(i, i)`（奇数长）和 `(i, i+1)`（偶数长）展开扩散，实时更新最长回文串的边界。
* **训练目标：** 熟练手写背向双指针标准模版。

### 📌 LeetCode 647. Palindromic Substrings (回文子串个数)
* **题目链接：** [LeetCode 647](https://leetcode.com/problems/palindromic-substrings/)
* **解题思路：** 遍历 $2n-1$ 个中心点，只要 `s[left] == s[right]`，计数器就 $+1$，遇到不匹配立即停止扩散（高效剪枝）。
* **训练目标：** 掌握中心扩散过程中的累加机制。

### 📌 LeetCode 1750. Minimum Length of String After Deleting Similar Ends
* **题目链接：** [LeetCode 1750](https://leetcode.com/problems/minimum-length-of-string-after-deleting-similar-ends/)
* **解题思路：** 寻找两端删除相同字符后剩下的最短长度。可以尝试结合相向与背向扩散的双向思维。
* **训练目标：** 加深对区间对称收缩/扩展逻辑的理解。

### 3. Hard 进阶挑战

### 📌 LeetCode 214. Shortest Palindrome (最短回文串)
* **题目链接：** [LeetCode 214](https://leetcode.com/problems/shortest-palindrome/)
* **解题思路：** 寻找**从索引 0 开始的最长回文前缀**。从中心靠左的位置向外扩散，找左边界能触碰到 `0` 的最长回文串。
* **训练目标：** 学习在带“固定端点/前缀”约束下灵活变通中心扩展。

### 📌 LeetCode 336. Palindrome Pairs (回文对)
* **题目链接：** [LeetCode 336](https://leetcode.com/problems/palindrome-pairs/)
* **解题思路：** 结合哈希表，把单词拆解后将“判断前缀/后缀是否为回文”作为子模块（使用中心扩展），在字典里快速匹配另一半。
* **训练目标：** 将背向双指针作为子函数，嵌入到更复杂的复合检索逻辑中。

### 💡 背向双指针 Python 标准通用模板

```python
def expandFromCenter(s: str, left: int, right: int) -> int:
    """
    从中心向两边扩散，返回合法回文子串的长度
    """
    while left >= 0 and right < len(s) and s[left] == s[right]:
        left -= 1
        right += 1
    # 退出循环时，left 和 right 已经各多走了一步（处于无效位置）
    # 合法长度为：(right - 1) - (left + 1) + 1 = right - left - 1
    return right - left - 1

# 在主函数中遍历所有可能的中心点：
# 1. 奇数长度中心：expandFromCenter(s, i, i)
# 2. 偶数长度中心：expandFromCenter(s, i, i + 1)
```

# 📌 LeetCode 125. Valid Palindrome (验证回文串)

## 题目描述
给定一个字符串 `s`，忽略字母大小写，并移除所有非字母数字字符（只保留字母和数字），判断它是否是一个**回文串**。

* **示例 1:**
  * **输入:** `s = "A man, a plan, a canal: Panama"`
  * **输出:** `true`
  * **解释:** 清理后为 `"amanaplanacanalpanama"`，是回文串。

---

## 方案一：相向双指针（两端向中间夹击 - 推荐）

### 💡 核心思路
1. 左右指针分别指向字符串的头部 `left = 0` 和尾部 `right = len(s) - 1`。
2. 移动指针时，跳过所有非字母数字字符。
3. 将字符统一转换为小写后比较：
   * 如果 `s[left] != s[right]`，直接返回 `False`；
   * 如果相等，`left` 右移，`right` 左移，直到相遇。

### 🐍 Python3 代码实现
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        left, right = 0, len(s) - 1
        
        while left < right:
            # 跳过左边的非字母数字字符
            while left < right and not s[left].isalnum():
                left += 1
            # 跳过右边的非字母数字字符
            while left < right and not s[right].isalnum():
                right -= 1
                
            # 统一转小写进行比较
            if s[left].lower() != s[right].lower():
                return False
                
            left += 1
            right -= 1
            
        return True
```

时间复杂度： $O(n)$，只需遍历一次字符串。
空间复杂度： $O(1)$，原地比较，无需额外空间。

### 方案二：背向双指针（中心向外扩展 - 专项练习）

#### 💡 核心思路
1. **预处理：** 先过滤掉非字母数字字符，并全部转为小写，得到纯净字符串 `cleaned`。
2. **寻找中心：**
   * 假设 `cleaned` 长度为 $n$；
   * 中心位置设置为 `left = (n - 1) // 2` 和 `right = n // 2`（如果 $n$ 为奇数，`left` 和 `right` 重合在最中间；如果 $n$ 为偶数，指向中间相邻的两个字符）。
3. **向外扩散：** 指针不断向两边移动（`left--`, `right++`），只要 `cleaned[left] == cleaned[right]` 就继续，直到越界。
4. 如果最终成功扩散到边缘（`left < 0`），说明整个字符串是完整的回文串。

#### 🐍 Python3 代码实现
```python
class Solution:
    def isPalindrome(self, s: str) -> bool:
        # 1. 预处理：只保留字母数字并转为小写
        cleaned = [ch.lower() for ch in s if ch.isalnum()]
        n = len(cleaned)
        if n <= 1:
            return True
            
        # 2. 定位中心点
        left = (n - 1) // 2
        right = n // 2
        
        # 3. 背向双指针：从中心向两边扩散
        while left >= 0 and right < n:
            if cleaned[left] != cleaned[right]:
                return False
            left -= 1
            right += 1
            
        return True
```

时间复杂度： $O(n)$，预处理与双指针扩散各遍历一次。
空间复杂度： $O(n)$，需要额外空间存储预处理后的字符数组。

# 📌 LeetCode 647. Palindromic Substrings (回文子串)

## 题目描述
给定一个字符串 `s`，请计算并返回这个字符串中 **回文子串的数目**。

具有不同开始位置或结束位置的子串，即使是由相同的字符组成，也会被计为不同的子串。

* **示例 1:**
  * **输入:** `s = "abc"`
  * **输出:** `3`
  * **解释:** 三个回文子串分别: `"a"`, `"b"`, `"c"`。

* **示例 2:**
  * **输入:** `s = "aaa"`
  * **输出:** `6`
  * **解释:** 六个回文子串分别: `"a"`, `"a"`, `"a"`, `"aa"`, `"aa"`, `"aaa"`。

## 方案：背向双指针（中心扩展法 - 最优解）

### 💡 核心思路
1. 长度为 $n$ 的字符串，一共有 $2n - 1$ 个可能的对称中心（$n$ 个字符中心，以及 $n - 1$ 个相邻字符间的空隙中心）。
2. 遍历每一个位置 `i`（从 $0$ 到 $n-1$）：
   * 以 `(i, i)` 为中心向两边扩散（寻找奇数长度的回文串，如 `"aba"` 的 `'b'`）。
   * 以 `(i, i + 1)` 为中心向两边扩散（寻找偶数长度的回文串，如 `"abba"` 的 `'bb'`）。
3. 只要 `s[left] == s[right]`，说明找到一个新的回文子串，计数器 $+1$，接着继续向外扩；一旦遇到不相等或越界，直接停止扩散（高效剪枝）。

## 🐍 Python3 代码实现

```python
class Solution:
    def countSubstrings(self, s: str) -> int:
        ans = 0
        n = len(s)
        
        for i in range(n):
            # 1. 以 s[i] 为中心的奇数长回文串
            ans += self.expandFromCenter(s, i, i, n)
            # 2. 以 s[i] 和 s[i+1] 为中心的偶数长回文串
            ans += self.expandFromCenter(s, i, i + 1, n)
            
        return ans

    def expandFromCenter(self, s: str, left: int, right: int, n: int) -> int:
        count = 0
        # 从中心向两边扩展，只要匹配就计数 +1
        while left >= 0 and right < n and s[left] == s[right]:
            count += 1
            left -= 1
            right += 1
        return count
```

## ⏱️ 复杂度分析

* **时间复杂度：** $O(n^2)$。一共 $2n - 1$ 个中心，每个中心最多向外扩展 $O(n)$ 次。在实际运行中，不匹配时会立刻跳出循环，运行速度远快于 DP。
* **空间复杂度：** $O(1)$。只使用了常数个指针变量。

## 💡 技巧小结

**与第 5 题（最长回文子串）对比：**

* **第 5 题：** 扩展时记录最长长度与起始索引，每次扩展结束更新全局最大值。
* **LeetCode 647（本题）：** 扩展时只要发现 `s[left] == s[right]`，就代表多发现了一个新的合法回文串，将 `count + 1` 累加即可。

# 📌 LeetCode 5. Longest Palindromic Substring (最长回文子串)

## 题目描述
给定一个字符串 `s`，找到 `s` 中最长的 **回文子串**。

* **示例 1:**
  * **输入:** `s = "babad"`
  * **输出:** `"bab"` （注意: `"aba"` 也是有效答案）

* **示例 2:**
  * **输入:** `s = "cbbd"`
  * **输出:** `"bb"`

## 方案：背向双指针（中心扩展法 - 最优解）

### 💡 核心思路
1. 遍历字符串中的每一个字符，把当前位置当作回文串的“中心”。
2. 每个位置作为中心时，需要考虑两种情况：
   * **奇数长度回文：** 以 `s[i]` 为中心，向两边扩展（`left = i, right = i`）。
   * **偶数长度回文：** 以 `s[i]` 和 `s[i+1]` 为中心，向两边扩展（`left = i, right = i + 1`）。
3. 扩展结束时，更新全局记录的最长回文子串起点 `start` 和最大长度 `max_len`。

## 🐍 Python3 代码实现

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""
        
        start, max_len = 0, 0
        n = len(s)
        
        for i in range(n):
            # 1. 奇数长回文：以 s[i] 为中心
            l1, r1 = self.expandAroundCenter(s, i, i, n)
            # 2. 偶数长回文：以 s[i] 和 s[i+1] 为中心
            l2, r2 = self.expandAroundCenter(s, i, i + 1, n)
            
            # 更新全局最长回文串的起始位置与长度
            if r1 - l1 + 1 > max_len:
                start, max_len = l1, r1 - l1 + 1
            if r2 - l2 + 1 > max_len:
                start, max_len = l2, r2 - l2 + 1
                
        return s[start:start + max_len]

    def expandAroundCenter(self, s: str, left: int, right: int, n: int) -> tuple[int, int]:
        # 从中心向两边扩展，直到不匹配或越界
        while left >= 0 and right < n and s[left] == s[right]:
            left -= 1
            right += 1
            
        # 退出循环时，left 和 right 各多走了一步（处于无效位置）
        # 合法回文串边界为 [left + 1, right - 1]
        return left + 1, right - 1
```

## ⏱️ 复杂度分析

* **时间复杂度：** $O(n^2)$。共有 $2n - 1$ 个中心，每个中心最多扩展 $O(n)$ 次。遇到不匹配字符时会立刻停止，非常高效。
* **空间复杂度：** $O(1)$。仅使用常数个指针变量维护边界（最后截取切片输出）。

## 💡 边界推导小贴士（防止踩坑）

在 `expandAroundCenter` 中，退出 `while` 循环时，`left` 和 `right` 已经**破坏了回文条件**（越界或字符不相等）。

* **有效起始索引：** `left + 1`
* **有效终止索引：** `right - 1`
* **有效回文长度：** `(right - 1) - (left + 1) + 1` = **`right - left - 1`**
* **Python 切片语法：** `s[left + 1 : right]` （因为 Python 切片是左闭右开 `[start:end)`，正好对应 `right - 1 + 1`）。

# 📌 LeetCode 1750. Minimum Length of String After Deleting Similar Ends

## 题目描述
给定一个只包含字符 `'a'`，`'b'`，和 `'c'` 的字符串 `s`。你可以执行以下操作任意次，直到无法继续：
1. 选择字符串 `s` 的一个**非空前缀**和**非空后缀**。
2. 它们不能相交。
3. 前缀和后缀中的所有字符都必须**相同**。
4. 将它们从字符串中删除。

返回执行完所有操作后，剩下字符串的**最小长度**。

* **示例 1:**
  * **输入:** `s = "ca"`
  * **输出:** `2`
  * **解释:** 你不能删除任何东西，因为两端字符不相同。

* **示例 2:**
  * **输入:** `s = "cabaabac"`
  * **输出:** `0`
  * **解释:** 
    1. 删除两端 `'c'` -> `"abaaba"`
    2. 删除两端 `'a'` -> `"baab"`
    3. 删除两端 `'b'` -> `"aa"`
    4. 删除两端 `'a'` -> `""` (长度为 0)

* **示例 3:**
  * **输入:** `s = "aabccabba"`
  * **输出:** `3`
  * **解释:** 
    1. 删除两端 `'a'` -> `"bccabb"`
    2. 删除两端 `'b'` -> `"ccab"` 
    （此时两端为 `'c'` 和 `'a'`，不相等，停止操作，剩余长度为 3）

## 方案：相向双指针（两端向中间收缩）

### 💡 核心思路
1. 定义两个指针 `left = 0` 和 `right = len(s) - 1`。
2. 只要 `left < right` 且 `s[left] == s[right]`，说明两端有可以消除的相同字符。
3. 记录当前两端的相同字符 `char = s[left]`。
4. **内部循环：** `left` 不断右移，跳过所有等于 `char` 的字符；`right` 不断左移，跳过所有等于 `char` 的字符。
5. 当两端字符不相同时，退出外部循环，剩余的有效区间长度就是 `right - left + 1`。

## 🐍 Python3 代码实现

```python
class Solution:
    def minimumLength(self, s: str) -> int:
        left, right = 0, len(s) - 1
        
        # 只要两端未相交且字符相等，就可以继续消除
        while left < right and s[left] == s[right]:
            char = s[left]  # 记录当前要消除的字符
            
            # 左指针不断向右，跳过连续相同的字符
            while left <= right and s[left] == char:
                left += 1
                
            # 右指针不断向左，跳过连续相同的字符
            while left <= right and s[right] == char:
                right -= 1
                
        # 计算剩下的长度
        return right - left + 1
```

## ⏱️ 复杂度分析

* **时间复杂度：** $O(n)$。看似有嵌套的 `while` 循环，但 `left` 和 `right` 指针一直都是单向移动（不回退），每个字符最多被访问一次。
* **空间复杂度：** $O(1)$。只需要常数个指针变量。

---

## 💡 边界推导小贴士（防止踩坑）

这道题有一个极其容易报错的陷阱：**字符串内所有字符完全相同的情况。**

* 比如：`s = "aaaa"`
* 外部 `while` 满足条件，记录 `char = 'a'`。
* 内部第一个 `while` 会让 `left` 一直右移，直到越界或者越过 `right`。
* **关键约束：** 内部循环必须加上 `left <= right` 的条件！如果没有这个条件，`left` 会一直加到字符串外面去引发 `IndexError`。
* 当所有字符消除完后，`left` 会跑到 `right` 的右边（即 `left > right`），此时返回值 `right - left + 1` 刚好等于 `0`，完美符合题意。

# 📌 LeetCode 269. Alien Dictionary (外星人字典)

## 题目描述
现有一种使用英语字母的异形语言，但字母顺序与标准的 26 个字母不同。

给你一个按**外星人字典序**排序好的单词列表 `words`，请根据这些单词的顺序，推导出这种新语言中**所有出现过的字母的相对顺序**。

* 如果无法推导出合理的顺序（存在逻辑矛盾/环），返回 `""`。
* 如果有多种合法的顺序，返回**任意一种**即可。

* **示例 1:**
  * **输入:** `words = ["wrt","wrf","er","ett","rftt"]`
  * **输出:** `"wertf"`

* **示例 2:**
  * **输入:** `words = ["z","x","z"]`
  * **输出:** `""`
  * **解释:** `"z"` 出现在 `"x"` 后面，又出现在 `"x"` 前面，循环依赖，不合法。

## 💡 问题的核心：如何转化为图论问题？

### 1. 怎么建图（找依赖关系）？
比较字典里**相邻**的两个单词 `w1` 和 `w2`：
* 逐个字符比对，找到**第一个不相同的字符** `ch1` 和 `ch2`。
* 因为 `w1` 排序在 `w2` 前面，说明 **`ch1` 的优先级必须高于 `ch2`**！
* 在图的语言里，这就是一条**有向边：`ch1 -> ch2`**（`ch1` 必须排在 `ch2` 前面）。
* 找到第一处不同后，后面的字符不再提供顺序信息，直接比对下一对单词。

### 2. 两个致命陷阱 ⚠️（面试必考点）
* **陷阱 1：无解的前缀非法**
  若 `w1 = "abc"`，`w2 = "ab"`，`w1` 长度大于 `w2` 且 `w2` 是 `w1` 的前缀。按照字典序，短的前缀必须在前，这里却反了！这是**非法输入**，直接返回 `""`。
* **陷阱 2：有向图中存在环**
  若推导出的依赖关系形成环（如 `a -> b -> c -> a`），说明逻辑矛盾，不存在合法拓扑序，返回 `""`。

## 方案一：BFS 拓扑排序（Kahn 算法 - 入度表）

这是最直观、最不容易写错的解法。

### 💡 核心步骤
1. **收集所有字母**：建立邻接表，并初始化所有出现过的字母入度（in-degree）为 0。
2. **建图与入度统计**：遍历相邻单词，找到第一处不同字符 `c1` 和 `c2`，建边 `c1 -> c2`，并给 `c2` 的入度 $+1$。
3. **BFS 队列**：将所有**入度为 0** 的字母推入队列。
4. **出队与拓扑构建**：出队字母加入结果集，并将其指向的所有邻接字母入度 $-1$。若某个邻接字母入度变为 0，压入队列。
5. **环检测**：若最终结果集中的字母总数等于所有不同的字母数量，说明没有环，返回结果；否则说明有环，返回 `""`。

### 🐍 Python3 代码实现 (BFS)

```python
from collections import deque, defaultdict

class Solution:
    def alienOrder(self, words: list[str]) -> str:
        # 1. 初始化邻接表和入度字典（只包含出现过的字母）
        adj = defaultdict(set)
        in_degree = {ch: 0 for word in words for ch in word}
        
        # 2. 比较相邻单词建图
        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i + 1]
            min_len = min(len(w1), len(w2))
            
            # 特殊情况判断：前缀非法，例如 "abc" 排在 "ab" 前面
            if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
                return ""
            
            for j in range(min_len):
                if w1[j] != w2[j]:
                    # 避免重复建边累加入度
                    if w2[j] not in adj[w1[j]]:
                        adj[w1[j]].add(w2[j])
                        in_degree[w2[j]] += 1
                    break  # 找到第一个不匹配字母后即可停止比对
                    
        # 3. 将入度为 0 的节点放入队列
        queue = deque([ch for ch in in_degree if in_degree[ch] == 0])
        res = []
        
        # 4. BFS 拓扑排序
        while queue:
            curr = queue.popleft()
            res.append(curr)
            for neighbor in adj[curr]:
                in_degree[neighbor] -= 1
                if in_degree[neighbor] == 0:
                    queue.append(neighbor)
                    
        # 5. 如果结果集字母数少于总独立字母数，说明图中存在环
        return "".join(res) if len(res) == len(in_degree) else ""
```

### 方案二：DFS 拓扑排序（三色标记法检测环）

DFS 的核心是通过**深度优先搜索回溯**来检测环，并将访问完毕的节点压栈。

#### 💡 核心步骤
定义三个状态：
* **`0`（未访问 Unvisited）：** 节点尚未被搜到。
* **`1`（正在访问 Visiting）：** 处于当前的 DFS 递归栈/路径中。
* **`2`（已访问 Visited）：** 该节点及其所有子节点已安全处理完成，没有环。

如果 DFS 在递归过程中遇到了状态为 `1` 的节点，说明出现了**环/回边**，直接判定非法。最后将所有处理完成（状态变为 `2`）的节点**逆序拼接**，即为合法的拓扑序列。

#### 🐍 Python3 代码实现 (DFS)

```python
class Solution:
    def alienOrder(self, words: list[str]) -> str:
        # 初始化所有出现过的字母的邻接表
        adj = {ch: set() for word in words for ch in word}
        
        # 1. 比较相邻单词建图
        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i + 1]
            min_len = min(len(w1), len(w2))
            
            # 特殊情况判断：前缀非法，例如 "abc" 排在 "ab" 前面
            if len(w1) > len(w2) and w1[:min_len] == w2[:min_len]:
                return ""
            
            for j in range(min_len):
                if w1[j] != w2[j]:
                    adj[w1[j]].add(w2[j])
                    break
                    
        # 2. DFS 状态标记：None=未访问(0), True=正在访问(1), False=已访问完成(2)
        visited = {}  # ch -> bool
        res = []
        
        def dfs(node):
            if node in visited:
                return visited[node]  # 如果是 True，说明遇到了状态 1（有环）；如果是 False，说明已安全处理
                
            visited[node] = True  # 标记为正在访问 (1)
            
            for neighbor in adj[node]:
                if dfs(neighbor):  # 子节点发现环
                    return True
                    
            visited[node] = False  # 标记为访问完成 (2)
            res.append(node)  # 后序收集节点
            return False

        # 3. 对所有出现的字母运行 DFS
        for ch in adj:
            if dfs(ch):
                return ""  # 存在环，返回空字符串
                
        # 拓扑排序需要将后序收集的结果反转
        return "".join(res[::-1])
```

## ⏱️ 复杂度分析

* **时间复杂度：** $O(C)$，其中 $C$ 为所有单词的字符总数。扫描单词建图耗时 $O(C)$，DFS 遍历图节点和边开销为 $O(V + E)$（字母数 $V \le 26$，边数 $E \le 26^2$），属于常数开销。
* **空间复杂度：** $O(1)$，递归栈深度、邻接表与状态表占用的辅助空间上限均为常数级 $O(26)$。
