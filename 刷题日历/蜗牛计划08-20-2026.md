# 35. Search Insert Position (搜索插入位置)
Easy

## 📝 Description
Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with $O(\log n)$ runtime complexity.

## 💡 Example 1:
* **Input:** `nums = [1,3,5,6]`, `target = 5`
* **Output:** `2`

## 💡 Example 2:
* **Input:** `nums = [1,3,5,6]`, `target = 2`
* **Output:** `1`

```python
class Solution(object):
    def searchInsert(self, nums, target):
        """
        :type nums: List[int]
        :type target: int
        :rtype: int
        """
        left, right = 0, len(nums) - 1
        
        while left <= right:
            mid = left + (right - left) // 2
            
            if nums[mid] == target:
                return mid
            elif nums[mid] < target:
                left = mid + 1      # 目标在右边，左指针右移
            else:
                right = mid - 1     # 目标在左边，右指针左移
                
        # 💡 为什么最后返回 left？
        return left
```

## 🔍 深度解析：为什么最后必须 `return left`？

这道题是二分查找最经典的“边界查找”变体。很多人疑惑为什么找不到时要返回 `left`，其实它是二分查找的一个物理必然结果：

### 1. 二分结束时的交错状态
当 `while left <= right:` 循环正常退出时，意味着 `left` 已经**大于** `right` 了（即 `left = right + 1`）。此时，两个指针形成了一种“大军合围”后的交叉状态。

### 2. `left` 停下的物理位置
* 在整个夹逼过程中，如果没找到 `target`，`right` 会一直往左收缩，`left` 会一直往右挺进。
* 当循环结束的那一瞬间，**`left` 刚好精准停在了“第一个大于 target 的元素”的位置上**。
* 如果 `target` 比数组里所有数都大，`left` 会一路向右跨过所有格子，最终停在 `len(nums)`（即数组的最末尾）。

### 3. 完美契合插入定义
这个刚好比 `target` 大的位置，或者说大军合围交错后的分界点，就是 `target` 按顺序理应插入的正确下标。所以最后无脑 `return left`，就能优雅通关。

### 📊 复杂度核验 (Complexity Analysis)
时间复杂度：$\mathcal{O}(\log n)$。二分查找每次将搜索空间对半砍，效率呈指数级上升。
空间复杂度：$\mathcal{O}(1)$。只用了常数个指针变量（left, right, mid），没有占用额外的动态内存。
