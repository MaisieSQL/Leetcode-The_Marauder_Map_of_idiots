# LeetCode 682. 棒球比赛 (Baseball Game)

## 🎯 一、 核心考点与物理直觉

- **题目大意**：
  你现在是一家棒球比赛的记分员。比赛以局为单位，记录员会按顺序收到一串操作字符串列表 `operations`。
  你需要根据以下规则实时计算并返回比赛结束时的总得分：
  - 整数 `x`：表示本局新获得分数 `x`。
  - `"+"`：表示本局得分是前两次有效得分的总和。
  - `"D"`：表示本局得分是前一次有效得分的两倍。
  - `"C"`：表示使前一次有效得分失效（从记录中移除）。
- **物理直觉**：
  - 这是一道典型的**“栈 (Stack) 模拟题”**。
  - 因为所有的得分规则（求前一次、前两次的总和，或者移除最近一次）全部具有极强的**“后进先出 (LIFO)”**特性。
  - 栈底到栈顶实时记录着当前有效的得分序列。每来一个操作符，我们只需要直接从栈顶弹出或窥探最近的元素进行计算，然后把新结果压入栈中即可。最后直接对栈内所有元素求和！

## 💻 二、 工业级 Python3 代码实现 (Solution)

```python
class Solution(object):
    def calPoints(self, operations):
        """:type operations: List[str]
        :rtype: int
        """
        stack = []
        
        for op in operations:
            if op == "+":
                # 本局得分是前两次有效得分的总和
                # stack[-1] 是前一次，stack[-2] 是前两次
                stack.append(stack[-1] + stack[-2])
            elif op == "D":
                # 本局得分是前一次有效得分的两倍
                stack.append(stack[-1] * 2)
            elif op == "C":
                # 移除前一次有效得分
                stack.pop()
            else:
                # 纯数字字符串，转化为整数后入栈
                stack.append(int(op))
                
        # 比赛结束，对栈内所有有效得分求和
        return sum(stack)
```

⏱️ 三、 复杂度核验 (Complexity Analysis)

- **时间复杂度**：O(N)
  - 其中 N 是操作列表 operations 的长度。我们只需要对整个操作数组进行一次从头到尾的线性扫描，栈的 append、pop 和最后的 sum 均摊下来都是单次常数开销。
- **空间复杂度**：O(N)
  - 最坏情况下（全部都是数字操作），栈需要完整存下所有的 N 个得分记录。

# LeetCode 102. 二叉树的层序遍历 (Binary Tree Level Order Traversal)

## 🎯 一、 核心考点与物理直觉
- **题目大意**：给你一个二叉树的根节点 `root`，返回其节点值的**层序遍历**（即逐层地，从左到右访问所有节点）。
- **物理直觉**：
  - 如果说 DFS（深度优先搜索）像是“一个人拿手电筒在迷宫里一条路走到黑”，那么 BFS（广度优先搜索）就像是“救援人员呈横向扩展的人墙，从上到下一层一层平推过去”。
  - **核心痛点**：我们必须准确分清“哪些节点属于第 1 层，哪些节点属于第 2 层”，不能让上下两层的节点混在一起。
  - **降维打击秘籍**：借助 **队列 (`deque`)** 的先进先出（FIFO）特性，并在进入每一层的瞬间**用 `level_size = len(queue)` 死死锁定当前层的节点总数**，做到层与层之间泾渭分明！

## 💻 二、 工业级 Python3 代码实现 (Solution)

```python
# Definition for a binary tree node.
# class TreeNode(object):
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

from collections import deque

class Solution(object):
    def levelOrder(self, root):
        """:type root: Optional[TreeNode]
        :rtype: List[List[int]]
        """
        if not root:
            return []
            
        res = []
        queue = deque([root])  # 初始化队列，将根节点放入
        
        while queue:
            level_size = len(queue)  # 🔑 灵魂微操：锁定当前层的节点总数
            current_level = []       # 收集当前层的节点值
            
            # 把当前层的节点全部出队，并把它们的左右孩子入队
            for _ in range(level_size):
                node = queue.popleft()
                current_level.append(node.val)
                
                if node.left:
                    queue.append(node.left)
                if node.right:
                    queue.append(node.right)
                    
            # 当前层大功告成，打包塞入最终结果集
            res.append(current_level)
            
        return res
```

## 三、 复杂度核验 (Complexity Analysis)

- **时间复杂度**：O(N)
  - 其中 $N$ 是二叉树的节点总数。每一个节点在整个 BFS 过程中都恰好被压入队列一次、弹出队列一次，做到了绝对高效的线性扫描。
- **空间复杂度**：O(N)
  - 空间开销主要由队列（Queue）消耗。在二叉树的最底层（满二叉树形态），叶子节点数量大约占总节点数的一半，因此队列在峰值时最多容纳 O(N) 个节点。
