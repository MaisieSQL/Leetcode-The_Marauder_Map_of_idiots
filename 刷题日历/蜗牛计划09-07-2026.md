# LeetCode 953. 验证外星语词典（Verifying an Alien Dictionary）题目解析

「验证外星语词典」（Verifying an Alien Dictionary）是 LeetCode 第 953 题，是一道关于字符串比较和哈希表映射的简单级别题目。

## 1. 题目描述

某种外星语也使用英文小写字母，但可能顺序不同。字母表的顺序（`order`）是一些小写字母的排列。

给定一组用外星语书写的单词 `words` 和其字母表的顺序 `order`，只有当给出的单词在这种外星语中按字典序排列时，返回 `true`；否则，返回 `false`。

## 2. 核心思路

题目要求判断单词数组是否按照外星字母表的顺序升序排列。这与常规字典序比较类似，区别在于字母的先后顺序由给定的 `order` 决定。

1. **建立索引映射**：
   使用哈希表（或固定大小的数组）记录 `order` 中每个字母的相对位置（索引从 `0` 到 `25`），这样可以在 $O(1)$ 时间内比较任意两个外星字母的大小。
2. **两两比较相邻单词**：
   遍历 `words` 数组，依次比较相邻的两个单词 `words[i]` 和 `words[i+1]`：
   * 从左到右逐个字符进行对比。
   * 如果找到第一个不同的字符，根据它们在 `order` 中的索引决定大小：
     * 若前一个单词的字符小于后一个单词的字符，说明这一对单词顺序正确，停止对比，检查下一对。
     * 若前一个单词的字符大于后一个单词的字符，说明顺序错误，直接返回 `false`。
   * 如果较短单词的所有字符都与较长单词的前缀完全相同，但较长单词排在前面（例如 `w1 = "apple", w2 = "app"`），则不符合字典序，返回 `false`。
3. **完成遍历**：如果所有相邻单词都满足条件，则返回 `true`。

## 3. 代码实现 (Python)

```python
class Solution:
    def isAlienSorted(self, words: List[str], order: str) -> bool:
        # 建立外星字母到索引的映射字典
        order_map = {c: i for i, c in enumerate(order)}
        
        for i in range(len(words) - 1):
            w1, w2 = words[i], words[i+1]
            
            is_sorted = False
            # 逐个字符比较
            for c1, c2 in zip(w1, w2):
                if order_map[c1] < order_map[c2]:
                    is_sorted = True
                    break
                elif order_map[c1] > order_map[c2]:
                    return False
            
            # 如果没有找到不同字符，检查长度（例如 "apple" 和 "app"）
            if not is_sorted and len(w1) > len(w2):
                return False
                
        return True
```

## 4. 复杂度分析

* **时间复杂度**：$O(M)$，其中 $M$ 是 `words` 中所有字符串的总字符数。我们最多需要遍历所有单词的所有字符进行比较。
* **空间复杂度**：$O(1)$，因为外星字母表的大小固定为 26 个英文字母，哈希映射占用的空间是常数级别的。
