🟢 LeetCode 1929. Concatenation of Array (数组串联) 专题通关卡片

## 🎯 一、 核心考点与物理直觉

- **题目大意**：给你一个长度为 $n$ 的整数数组 nums，请你构建一个长度为 $2n$ 的答案数组 ans，其中对于所有 $0 \le i < n$ 的下标，满足 ans[i] == nums[i] 且 ans[i + n] == nums[i]。
- **物理直觉**：
    - 这本质上就是把原数组复制两遍拼在一起。
    - 可以通过直接的数组拼接，或者利用循环通过索引映射 i + n = i 的方式将元素放到对应位置。

# LeetCode 49. 字母异位词分组 (Group Anagrams) 专题通关卡片

## 🎯 一、 核心考点与物理直觉

* **题目大意**：给你一个字符串数组 `strs`，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。
  * **什么是字母异位词**：字母相同、但排列不同的字符串（例如 `"eat"`、`"tea"`、`"ate"` 互为异位词）。
* **物理直觉**：
  * 如果我们能为每一个字符串找到一个**“唯一的身份证号（Key）”**，只要它们的身份证号一样，不管它们的字母顺序怎么乱，最后都把它们塞进同一个哈希表的列表里！
  * **身份证号的两种经典生成思路**：
    1. **排序法（Sort Key）**：把字符串内部的字母按字典序从小到大排序。比如 `"eat"` 排序后变成 `"aet"`，`"tea"` 排序后也是 `"aet"`。它们排序后的形态完全一致！
    2. **计数法（Count Key）**：统计每个字符串中 26 个英文字母各自出现的次数，用一个固定格式的元组（或字符串）来代表频率。比如 `"eat"` 的 `'a':1, 'e':1, 't':1`。这种方法连排序的 O(L log L) 都可以省掉！

## 💻 二、 Python 高效通关代码 (Solution)

### 解法一：排序指纹法（最直观、工业界最常用）
利用 `tuple(sorted(s))` 作为哈希表的 Key。

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        ans = defaultdict(list)
        for s in strs:
            key = tuple(sorted(s))
            ans[key].append(s)
        return list(ans.values())
```
❌ 错在哪？双 Bug 精准定位

1. 第一个 Bug：`key = sorted(i)` 导致 `TypeError: unhashable type: 'list'`
   - **原因**：在 Python 中，`sorted(s)` 返回的是一个列表（List）（例如 `['a', 'e', 't']`）。而在 Python 的字典（Dictionary）中，字典的键（Key）必须是“可哈希的（Hashable）”。
   - 列表是可变对象（Mutable），因此是不可哈希的。如果你直接把列表当成字典的 key，Python 会立刻报错：`TypeError: unhashable type: 'list'`。
   - **解法**：必须把排序后的列表用 `tuple()` 包装成元组（或者用 `"".join()` 拼回字符串），因为元组是不可变的、可哈希的！
   - 改为：`key = tuple(sorted(i))` 或者 `key = "".join(sorted(i))`。
  

### 解法二：26个字母计数指纹法（极致性能流）
通过统计词频生成不可变元组作为 Key。

```python
from collections import defaultdict
from typing import List

class Solution:
    def groupAnagrams(self, strs: List[str]) -> List[List[str]]:
        ans = defaultdict(list)
        for s in strs:
            count = [0] * 26
            for char in s:
                count[ord(char) - ord('a')] += 1
            key = tuple(count)
            ans[key].append(s)
        return list(ans.values())
```

📊 三、 复杂度核验 (Complexity Analysis)

- 时间复杂度：
  - 排序法：O(N * L log L)，其中 N 是字符串数组长度，L 是字符串的最大长度。
  - 计数法：O(N * L)，省去了排序的对数开销。
- 空间复杂度：O(N * L)，用于存储哈希表中的所有字符串。
