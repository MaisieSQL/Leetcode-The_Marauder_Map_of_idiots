# LeetCode 232. Implement Queue using Stacks (用栈实现队列)

## 📌 1. 核心设计思想
- **队列 (Queue)** 的特点是 **FIFO (First In, First Out)** —— 先进先出。
- **栈 (Stack)** 的特点是 **LIFO (Last In, First Out)** —— 后进先出。

要用栈来实现队列，核心挑战在于：**栈底（或后压入的元素）离出口太远，无法直接先进先出。**
我们可以通过**“双栈倒货流（输入栈 + 输出栈）”**来巧妙破解：
1. **`in_stack`（入队栈）**：专门负责接收所有新进来的元素（对应 `push` 操作）。
2. **`out_stack`（出队栈）**：专门负责弹出和查看队头元素（对应 `pop` 和 `peek` 操作）。
3. **倒货机制**：当 `out_stack` 为空时，把 `in_stack` 里的所有元素全部倒（`pop`）出来并压入（`push`）到 `out_stack` 中。这样一来，原本在底部的老元素就通过逆序来到了 `out_stack` 的栈顶，完美实现了先进先出（FIFO）的顺序！

## 💻 2. Python3 完整代码实现

```python
class MyQueue:

    def __init__(self):
        self.in_stack = []   # 负责 push 入队
        self.out_stack = []  # 负责 pop / peek 出队

    def push(self, x: int) -> None:
        # 新元素直接压入入队栈
        self.in_stack.append(x)

    def pop(self) -> int:
        # 如果出队栈为空，把入队栈的所有元素倒过来
        self.peek()
        # 从出队栈弹出栈顶（即最先进队的元素）
        return self.out_stack.pop()

    def peek(self) -> int:
        # 如果出队栈为空，将入队栈的元素全部倾倒进出队栈
        if not self.out_stack:
            while self.in_stack:
                self.out_stack.append(self.in_stack.pop())
        return self.out_stack[-1]

    def empty(self) -> bool:
        # 只有当两个栈都为空时，队列才为空
        return not self.in_stack and not self.out_stack
```

3. 复杂度分析
- 时间复杂度：
  - `push` 操作：O(1)，直接压入 `in_stack`。
  - `pop` 和 `peek` 操作：均摊 O(1)。虽然有时需要把 `in_stack` 的元素全部倒进 `out_stack`（单次耗时 O(N)），但每个元素在整个生命周期中总共只会被搬运一次，均摊下来每个操作的时间复杂度都是常数级别。
  - `empty` 操作：O(1)。
- 空间复杂度：O(N)，需要两个栈共同存储当前队列内的所有元素。

# LeetCode 232. Implement Queue using Stacks (用栈实现队列 - Push 倒腾流)

## 📌 1. 核心设计思想
- **队列 (Queue)** 的特点是 **FIFO (First In, First Out)** —— 先进先出。
- **栈 (Stack)** 的特点是 **LIFO (Last In, First Out)** —— 后进先出。

这种解法的核心思路是：**在压入新元素 (`push`) 的那一刻就把顺序颠倒好，确保主栈 `s1` 的栈顶永远是队头（最先进队的元素）。**

1. **`s1`（主栈）**：永远保持标准的队列出队顺序，栈顶即为队头元素。
2. **`s2`（辅助栈）**：用于在 `push` 新元素时作为临时中转容器。
3. **`push(x)` 倒腾机制**：
   - 先把 `s1` 里的所有老元素逐个弹出来，暂时压入辅助栈 `s2` 中。
   - 把新元素 `x` 压入此时为空的 `s1`（使其垫底）。
   - 再把 `s2` 里的所有老元素全部倒回 `s1`，压在新元素 `x` 的上面。
   - 这样一来，最先进来的元素依然留在 `s1` 的栈顶，而最新来的 `x` 则被压在了最底部。

## 💻 2. Python3 完整代码实现

```python
class MyQueue:

    def __init__(self):
        self.s1 = []  # 主栈：栈顶永远是队头（最先进队的元素）
        self.s2 = []  # 辅助栈：用于 push 时倒腾顺序

    def push(self, x: int) -> None:
        # 1. 把 s1 的老元素全部移到 s2
        while self.s1:
            self.s2.append(self.s1.pop())
        
        # 2. 把新元素 x 压入到底部（此时 s1 为空）
        self.s1.append(x)
        
        # 3. 把 s2 的老元素全部倒回 s1，压在新元素上面
        while self.s2:
            self.s1.append(self.s2.pop())

    def pop(self) -> int:
        # s1 的栈顶就是队头，直接弹出
        return self.s1.pop()

    def peek(self) -> int:
        # 查看 s1 的栈顶
        return self.s1[-1]

    def empty(self) -> bool:
        # 直接检查 s1 是否为空
        return not self.s1
```

# LeetCode 337. 打家劫舍 III (House Robber III)

## 🎯 一、 核心考点与物理直觉

- **题目大意**：在上次打劫完一条街道和环形小区之后，小偷又发现了一个排列成**二叉树**结构的新小区。两个直接相连的房子在同一天晚上不能同时报警（即：如果偷了某个节点，它的左右孩子就绝对不能偷）。计算在不触动警报的情况下，小偷一晚能够盗取的最高金额[cite: 1]。
- **核心矛盾**：
  - 如果选了“偷”爸爸，爸爸的左右孩子（直接子节点）绝对不能碰，但爸爸的孙子们是可以去偷的[cite: 1]。
  - 如果“不偷”爸爸，那左右孩子可以选择偷，也可以选择不偷（挑金额最大的一条路走）[cite: 1]。
- **树形 DP + 双状态上报流**：天然契合**后序遍历（自底向上）**，每个节点在递归时同时向父节点回报两个情报：`(偷当前节点的最大收益, 不偷当前节点的最大收益)`[cite: 1]。

## 🛠️ 二、 状态转移设计

对于二叉树中的任意一个节点 (`node`)：
1. **状态 1：偷当前节点 (`rob_this`)**[cite: 1]
   - 金额 = `node.val + 左孩子不偷时的收益 + 右孩子不偷时的收益`[cite: 1]。
2. **状态 2：不偷当前节点 (`not_rob_this`)**[cite: 1]
   - 金额 = `max(左孩子偷, 左孩子不偷) + max(右孩子偷, 右孩子不偷)`[cite: 1]。

## 💻 三、 Python3 完美通关代码 (Solution)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        
        # 定义递归函数：返回一个二元组 (偷当前节点的最大收益, 不偷当前节点的最大收益)
        def dfs(node: Optional[TreeNode]) -> tuple:
            if not node:
                return (0, 0) # 空节点，收益为 0[cite: 1]
            
            # 1. 递归获取左右子树的情报（后序遍历）[cite: 1]
            left_rob, left_not_rob = dfs(node.left)
            right_rob, right_not_rob = dfs(node.right)
            
            # 2. 如果偷当前节点，左右孩子绝对不能偷[cite: 1]
            rob_this = node.val + left_not_rob + right_not_rob
            
            # 3. 如果不偷当前节点，左右孩子可偷可不偷，各自取最大值[cite: 1]
            not_rob_this = max(left_rob, left_not_rob) + max(right_rob, right_not_rob)
            
            return (rob_this, not_rob_this)
            
        # 最终整棵树的根节点，取“偷”和“不偷”之间的最大胜者[cite: 1]
        return max(dfs(root))
```

四、 复杂度核验 (Complexity Analysis)
- 时间复杂度：O(N)，其中 N 是二叉树中节点的总数。每个节点在后序遍历中只被访问且计算了一次，时间效率达到极致[cite: 1]。
- 空间复杂度：O(H)，其中 H 是二叉树的高度。空间开销主要来自于系统递归调用栈的深度，最坏情况下（树退化成单链表）空间为 O(N)，平均平衡二叉树下为 O(log N)[cite: 1]。

# LeetCode 1325. 删除给定值的叶子节点 (Delete Leaves With a Given Value)

## 🎯 一、 核心考点与物理直觉

- **题目大意**：给你一棵以 `root` 为根的二叉树和一个整数 `target` ，请你删除所有值为 `target` 的**叶子节点**[cite: 4]。
- **物理直觉与连锁反应**：
  - 如果一个节点本身不是叶子，但由于它的左右孩子被你删光了，导致它**变成了新的叶子**，且它自己的值也等于 `target`，那么它在回溯时**也必须被连带删除**[cite: 4]。
  - 这种“自底向上”的连锁清剿，天然契合二叉树的 **后序遍历（Postorder Traversal）**[cite: 4]。

## 🛠️ 二、 解题三步走框架

1. **递归边界拦截**：
   - 如果当前节点为空（`not root`），直接返回 `None`。
2. **自底向上推进（后序遍历）**：
   - 先递归处理左子树：`root.left = self.removeLeafNodes(root.left, target)`
   - 再递归处理右子树：`root.right = self.removeLeafNodes(root.right, target)`
3. **回溯审判与切断指针**：
   - 在左右子树处理完毕后，检查当前节点：如果它变成了叶子（`not root.left and not root.right`）且其值等于目标值（`root.val == target`），则返回 `None`（相当于切断指针，将其从父节点中抹去）；否则保留并返回 `root`。

## 💻 三、 Python3 完美通关代码 (Solution)

```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def removeLeafNodes(self, root: Optional[TreeNode], target: int) -> Optional[TreeNode]:
        if not root:
            return None
        
        # 1. 递归处理左子树和右子树（自底向上）
        root.left = self.removeLeafNodes(root.left, target)
        root.right = self.removeLeafNodes(root.right, target)
        
        # 2. 检查当前节点是否变成了值为 target 的叶子节点
        if not root.left and not root.right and root.val == target:
            return None  # 返回 None 相当于切断指针，将其从父节点中抹去
            
        # 3. 不是目标叶子，安然无恙，把当前节点返回给上一层
        return root
```

⏱️ 四、 复杂度核验 (Complexity Analysis)
- 时间复杂度：$O(H)$，其中 $H$ 是树的高度。在最坏情况下（链状树），时间复杂度为 $O(N)$；在平衡 BST 中，时间复杂度为 $O(\log N)$。
- 空间复杂度：$O(1)$（迭代写法只用了常数级别的指针变量，极度优雅）。
