# LeetCode 67. Add Binary (二进制求和)

## 📌 题目描述
给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。


## 💡 解题思路：从后向前对齐进位模拟

你目前的代码已经抓住了这道题最核心的“从后往前、逢 2 进 1”思路，并且把之前最容易踩的几个坑（`return` 误放在循环内、误写 `"".join(res)` 导致整数拼接报错）都改过来了。

整体逻辑拆解如下：
1. **确定最大位数并预留进位空间**：
   - 设 `n = max(len(a), len(b))`，创建长度为 `n + 1` 的结果数组 `res = [0] * (n + 1)`。
   - 多出来的第 `0` 位专门用来承接最高位可能产生的进位，避免单独越界处理。
2. **逆序遍历每一位并计算偏移索引**：
   - 循环 `for i in range(n - 1, -1, -1):` 从最低位（最右侧）一路向左走到最高位（下标 `0`）。
   - 当 `a` 或 `b` 比 `n` 短时，用 `idx_a = i - (n - len(a))` 和 `idx_b = i - (n - len(b))` 做右对齐映射；若对应索引 `< 0`，说明该高位已没有字符，按 `0` 处理。
3. **累加当前位与已有进位**：
   - `total = a_int + b_int + res[i + 1]`，把当前 `a` 的位、`b` 的位以及右侧上一轮进过来的 `res[i + 1]` 一起算进来。
   - 当 `total >= 2`（可能是 `2` 或 `3`）时，当前位留下 `total - 2`（即 `2 -> 0`，`3 -> 1`），同时给左侧前一位 `res[i]` 加上 `1`；否则直接写入 `res[i + 1] = total`。
4. **拼接结果并处理前导零**：
   - 循环结束后，用 `"".join(map(str, res)).lstrip("0")` 把整数数组转成字符串并去掉左侧多余的 `"0"`。
   - 若结果为空（例如 `a = "0", b = "0"`），兜底返回 `"0"`。

## 💻 Python 3 参考代码

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        n = max(len(a), len(b))
        res = [0] * (n + 1)

        for i in range(n - 1, -1, -1):
            idx_a = i - (n - len(a))
            idx_b = i - (n - len(b))

            a_int = int(a[idx_a]) if idx_a >= 0 else 0
            b_int = int(b[idx_b]) if idx_b >= 0 else 0

            total = a_int + b_int + res[i + 1]
            if total >= 2:
                res[i + 1] = total - 2
                res[i] += 1
            else:
                res[i + 1] = total

        ans = "".join(map(str, res)).lstrip("0")
        return ans if ans else "0"
```

- 时间复杂度：O(max(m, n))，其中 m 和 n 分别为字符串 a 和 b 的长度。主循环执行 max(m, n) 次，最后拼接与去前导零也是线性时间。
- 空间复杂度：O(max(m, n))，需要开辟长度为 max(m, n) + 1 的列表 res 以及最终返回的字符串。

### 3. 更简洁的双指针写法（最推荐的工程/面试写法）
如果你不想算 `idx_a`、`idx_b` 也不想折腾前导零，用 `i`、`j` 两个指针从右往左走、`carry` 存进位会清爽很多：

```python
class Solution:
    def addBinary(self, a: str, b: str) -> str:
        i, j = len(a) - 1, len(b) - 1
        carry = 0
        out = []

        while i >= 0 or j >= 0 or carry:
            total = carry
            if i >= 0:
                total += int(a[i])
                i -= 1
            if j >= 0:
                total += int(b[j])
                j -= 1

            out.append(str(total % 2))
            carry = total // 2

        return "".join(reversed(out))
```

### 2. 常见替代解法对比

| 解法思路 | 时间复杂度 | 额外空间复杂度 | 特点与取舍 |
| :--- | :---: | :---: | :--- |
| **当前方案（下标对齐 + `res` 数组）** | $O(\max(m, n))$ | $O(\max(m, n))$ | 贴近手算竖式，但多了索引偏移和前导零清理步骤 |
| **双指针边扫边进位（推荐日常刷题）** | $O(\max(m, n))$ | $O(\max(m, n))$（存结果列表） | 不用算偏移、不用补零、不用 `lstrip("0")`，边界最干净 |
| **内置 `int(..., 2)` + `bin()`（Python 投机/快捷法）** | $O(m + n)$（大数乘法/进制转换） | $O(\max(m, n))$ | 代码极短，但面试中通常不建议只写这一行，且大整数转换有额外常数开销 |
| **原地/位运算视角** | $O(\max(m, n))$ | $O(\max(m, n))$ | 适合顺带复习二进制位与进位原理，但在 Python 字符串上不如双指针直观 |
