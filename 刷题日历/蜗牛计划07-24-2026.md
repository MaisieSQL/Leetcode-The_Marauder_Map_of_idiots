# 矩阵（Matrix）算法入门指南

## 一、 矩阵类题目的两大常见流派

### 1. 模拟与坐标变换流（如 Spiral Matrix 和 Rotate Matrix）
* **特点**：不需要复杂的数学推导，完全考验你**对二维数组坐标的控制能力**。
* **核心思维**：
  * **方向感**：上下左右怎么走？（通常用偏移量数组 `dx, dy` 或设边界指针 `top, bottom, left, right`）。
  * **原地修改**：如果不允许开辟新数组（In-place），往往需要通过**对角线翻转、上下颠倒**等矩阵自身的几何对称性来巧妙完成。

### 2. 网格搜索与动态规划流（如 岛屿数量、不同路径）
* **特点**：从左上角走到右下角，或者在网格里上下左右“深搜（DFS）”、“广搜（BFS）”。
* **核心思维**：把矩阵看成一个**隐式的图（Graph）**，每一个格子是一个节点，上下左右相邻的格子连一条边。

## 二、 攻克矩阵题的三个“基本功”

### 1. 如何遍历整个矩阵？（双层循环）

m, n = len(matrix), len(matrix[0])
for i in range(m):      # 遍历每一行

# LeetCode 253. 会议室 II (Meeting Rooms II) - 完整解析与代码

## 一、 题目描述
给你一个会议时间安排的数组 `intervals` ，其中 `intervals[i] = [start_i, end_i]` ，返回所需要的最少会议室数量。


## 二、 核心解题思路：起始时间排序 + 最小堆

这道题属于经典的**区间调度（资源分配型）**问题。

1. **为什么要排序？**
   * 我们必须先将所有会议按照**起始时间升序排序**。这样我们就能像现实生活中开会一样，按时间先后顺序逐个审查。
2. **为什么要用小顶堆（Min-Heap）？**
   * 我们用一个小顶堆来存储所有正在占用中的会议的**结束时间**。
   * **堆顶（`heap[0]`）**永远是所有正在开会的房间中**最早结束**的那一个。
3. **决策逻辑：**
   * 每来一个新会议，拿它的**开始时间**去和堆顶的**最早结束时间**比：
     * 如果 `新会议开始时间 >= 堆顶结束时间` $\rightarrow$ 说明有房间腾出来了！我们直接把旧的结束时间 `pop` 掉（复用房间）。
     * 否则 $\rightarrow$ 说明房间不够用，必须新开房间。
   * 不管合不合并，最后都要把当前新会议的结束时间 `push` 进堆。
4. **最终答案：**
   * 整个遍历结束后，**堆的大小（`len(min_heap)`）**就是我们最多同时需要的会议室数量。

## 三、 Python 代码实现

```python
import heapq

class Solution(object):
    def minMeetingRooms(self, intervals):
        """
        :type intervals: List[List[int]]
        :rtype: int
        """
        if not intervals:
            return 0

        # 1. 按照会议的起始时间升序排序
        intervals.sort(key=lambda x: x[0])

        # 2. 初始化一个小顶堆，用于存储当前正在占用中的会议的结束时间
        min_heap = []

        for interval in intervals:
            start, end = interval[0], interval[1]
            
            # 如果堆不为空，且最早结束的会议时间 <= 新会议的开始时间
            # 说明房间腾出来了，弹出旧的结束时间
            if min_heap and min_heap[0] <= start:
                heapq.heappop(min_heap)
            
            # 将当前会议的结束时间压入堆中
            heapq.heappush(min_heap, end)

        # 3. 堆中最终剩余的元素个数，即为最少需要的会议室数量
        return len(min_heap)
```

# LeetCode 48. Rotate Image (旋转图像)

## 📝 1. 题目描述 (Description)
给定一个 $n \times n$ 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

**注意：**
你必须在**原地**旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要**使用另一个矩阵来旋转图像。

## 🏛️ 2. 物理核心原理：矩阵的对称轴翻转

要想做到 **$O(1)$ 空间复杂度（原地旋转）**，我们不直接去硬算旋转后的新坐标，而是利用线性代数里的矩阵翻转规律：

> **顺时针旋转 90 度 = 先「主对角线翻转（Transpose）」 + 再「左右对称轴翻转（Reverse Rows）」**

### 步骤拆解示例 ($3 \times 3$ 矩阵)：

1. **原始矩阵**：
   $$\begin{bmatrix}     1 & 2 & 3 \\     4 & 5 & 6 \\     7 & 8 & 9     \end{bmatrix}$$

2. **第一步：主对角线翻转 (Transpose)**
   将所有的 `matrix[i][j]` 和 `matrix[j][i]` 互换（仅遍历上三角或下三角避免重复交换）：
   $$\begin{bmatrix}     1 & 4 & 7 \\     2 & 5 & 8 \\     3 & 6 & 9     \end{bmatrix}$$

3. **第二步：行内左右反转 (Reverse each row)**
   对矩阵的每一行进行左右颠倒（行内元素对调）：
   $$\begin{bmatrix}     7 & 4 & 1 \\     8 & 5 & 2 \\     9 & 6 & 3     \end{bmatrix}$$

## 💻 3. Python 3 工业级标准实现

```python
class Solution:

  def rotate(self, matrix: list[list[int]]) -> None:
    """Do not return anything, modify matrix in-place instead."""
    n = len(matrix)

    # 1. 沿主对角线翻转 (Transpose)
    for i in range(n):
      for j in range(i, n):
        matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]

    # 2. 沿垂直中轴线翻转 (Reverse each row)
    for i in range(n):
      matrix[i].reverse()
```
