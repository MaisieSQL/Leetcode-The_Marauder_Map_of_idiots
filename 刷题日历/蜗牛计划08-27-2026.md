# 145. Binary Tree Postorder Traversal (二叉树的后序遍历)

## 题目描述
给你一棵二叉树的根节点 `root` ，返回其节点值的 **后序遍历** 序列。

- **后序遍历顺序**：`左子树 -> 右子树 -> 根节点`（Left -> Right -> Root）

## 核心解法

### 方法一：递归法 (Recursion)

#### 1. 思路分析
递归是树结构遍历最直接的方式。按照后序遍历的定义，先递归访问左子树，再递归访问右子树，最后将当前节点的值存入结果列表。

#### 2. Python 3 代码实现
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        
        def dfs(node: Optional[TreeNode]):
            if not node:
                return
            dfs(node.left)    # 遍历左子树
            dfs(node.right)   # 遍历右子树
            res.append(node.val)  # 访问根节点
            
        dfs(root)
        return res
```

#### 3. 复杂度分析
- **时间复杂度**：$O(n)$，其中 $n$ 为二叉树的节点数，每个节点被访问一次。
- **空间复杂度**：$O(n)$，最坏情况下（树呈链状）递归栈深度为 $O(n)$；平均情况下树高为 $O(\log n)$。

### 方法二：前序遍历变形反转法 (Iterative - Reverse Preorder)

#### 1. 思路分析
- 标准前序遍历顺序为：`根 -> 左 -> 右`
- 如果我们将压栈/遍历顺序微调为：`根 -> 右 -> 左`
- 将得到的结果序列进行整体反转（Reverse），顺序变为：`左 -> 右 -> 根`，恰好对应**后序遍历**。

#### 2. Python 3 代码实现
```python
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        if not root:
            return []
        
        stack = [root]
        res = []
        
        while stack:
            node = stack.pop()
            res.append(node.val)
            # 先压左节点，再压右节点；弹栈时就是 右节点 先出
            if node.left:
                stack.append(node.left)
            if node.right:
                stack.append(node.right)
                
        # 将 [根 -> 右 -> 左] 反转为 [左 -> 右 -> 根]
        return res[::-1]
```

#### 3. 复杂度分析
- **时间复杂度**：$O(n)$，遍历所有节点耗时 $O(n)$，反转列表耗时 $O(n)$。
- **空间复杂度**：$O(n)$，显式栈保存节点的最大深度为 $O(n)$。

### 方法三：单栈通用迭代法（记录最近访问节点）

#### 1. 思路分析
如果不使用反转技巧，真正的后序遍历迭代需要保证：**只有当一个节点的左子树和右子树都已被访问处理后，该节点才能出栈并访问**。
- 维护指针 `curr` 沿左路一直向下压栈。
- 到达最左端后查看栈顶节点：
  - 如果栈顶节点的右子树存在且**未被访问过**，则将指针移到右子树继续处理。
  - 如果栈顶节点没有右子树，或者右子树**刚刚被访问过**（通过记录 `prev` 节点判断），则说明当前节点的子树已全部处理完毕，可以安全出栈并记录其值。

#### 2. Python 3 代码实现
```python
class Solution:
    def postorderTraversal(self, root: Optional[TreeNode]) -> List[int]:
        res = []
        stack = []
        curr = root
        prev = None  # 记录上一个被访问并记录的节点
        
        while curr or stack:
            # 一路向左压栈
            while curr:
                stack.append(curr)
                curr = curr.left
                
            node = stack[-1]
            # 如果右子树存在且未访问，转向右子树
            if node.right and node.right != prev:
                curr = node.right
            else:
                # 右子树为空或已被访问过，弹出当前节点并记录
                stack.pop()
                res.append(node.val)
                prev = node
                
        return res
```

#### 3. 复杂度分析
- **时间复杂度**：$O(n)$，每个节点最多进栈出栈两次。
- **空间复杂度**：$O(n)$，显式栈空间取决于树高。

## 方案对比

| 解法 | 优点 | 缺点 | 面试推荐度 |
| :--- | :--- | :--- | :---: |
| **递归法** | 代码极其精炼，易于书写与理解 | 树极深时存在调用栈溢出风险 | ⭐️⭐️⭐️⭐️ |
| **前序变形反转法** | 易于记忆，代码结构与前序迭代完全一致 | 并非严格的原生自底向上遍历 | ⭐️⭐️⭐️⭐️⭐️ |
| **单栈通用追踪法** | 严格按照真实后序顺序自底向上执行 | 边界与 `prev` 状态转移逻辑较多 | ⭐️⭐️⭐️⭐️ |

# 417. Pacific Atlantic Water Flow (太平洋大西洋水流问题)

## 题目描述
给定一个 $m \times n$ 的非负整数矩阵 `heights` 表示大陆各单元格的海拔高度。
- **太平洋 (Pacific Ocean)** 处于大陆的 **左边界** 和 **上边界**。
- **大西洋 (Atlantic Ocean)** 处于大陆的 **右边界** 和 **下边界**。

雨水只能向 **高度小于或等于** 当前单元格的相邻（上下左右）单元格流动。返回所有既可以流动到太平洋、又可以流动到大西洋的单元格坐标列表。

---

## 核心解题思路：逆向思维（由海向陆反向搜索）

### 为什么不推荐正向搜索？
如果遍历每个格子并尝试寻找它是否能流向两洋，许多路径会重复遍历，复杂度高达 $O((m \cdot n)^2)$，极易超时（TLE）。

### 逆向反推法（由低到高）
- **正向水流**：高 $\to$ 低（或等高）
- **逆向反推**：从海洋边界出发，**低 $\to$ 高（或等高）** 进行反向渗透。
1. 从所有**紧邻太平洋的边界单元格**出发做搜索（DFS 或 BFS），记录所有能够被太平洋水反向逆流到达的格子集合 `pacific_reachable`。
2. 从所有**紧邻大西洋的边界单元格**出发做搜索，记录所有能够被大西洋水反向逆流到达的格子集合 `atlantic_reachable`。
3. 两个集合的**交集**即为所求坐标。

## 代码实现

### 方法一：逆向深度优先搜索 (DFS)

```python
class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        if not heights or not heights[0]:
            return []
        
        m, n = len(heights), len(heights[0])
        pacific_reachable = set()
        atlantic_reachable = set()
        
        def dfs(r: int, c: int, reachable: set):
            reachable.add((r, c))
            for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                nr, nc = r + dr, c + dc
                # 检查越界
                if 0 <= nr < m and 0 <= nc < n:
                    # 逆流条件：目标高度 >= 当前高度，且未被访问过
                    if (nr, nc) not in reachable and heights[nr][nc] >= heights[r][c]:
                        dfs(nr, nc, reachable)
        
        # 1. 左右两列边界出发
        for i in range(m):
            dfs(i, 0, pacific_reachable)        # 左侧：太平洋
            dfs(i, n - 1, atlantic_reachable)   # 右侧：大西洋
            
        # 2. 上下两行边界出发
        for j in range(n):
            dfs(0, j, pacific_reachable)        # 上侧：太平洋
            dfs(m - 1, j, atlantic_reachable)   # 下侧：大西洋
            
        # 3. 求解交集
        return [[r, c] for (r, c) in (pacific_reachable & atlantic_reachable)]
```

### 方法二：逆向广度优先搜索 (BFS)

```python
from collections import deque

class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        if not heights or not heights[0]:
            return []
        
        m, n = len(heights), len(heights[0])
        
        def bfs(starts: list) -> set:
            queue = deque(starts)
            reachable = set(starts)
            
            while queue:
                r, c = queue.popleft()
                for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
                    nr, nc = r + dr, c + dc
                    if 0 <= nr < m and 0 <= nc < n:
                        if (nr, nc) not in reachable and heights[nr][nc] >= heights[r][c]:
                            reachable.add((nr, nc))
                            queue.append((nr, nc))
            return reachable
        
        # 收集太平洋和大西洋的初始边界点
        pacific_starts = [(i, 0) for i in range(m)] + [(0, j) for j in range(n)]
        atlantic_starts = [(i, n - 1) for i in range(m)] + [(m - 1, j) for j in range(n)]
        
        pacific_reachable = bfs(pacific_starts)
        atlantic_reachable = bfs(atlantic_starts)
        
        return [[r, c] for (r, c) in (pacific_reachable & atlantic_reachable)]
```

## 复杂度分析

- **时间复杂度**：$O(m \times n)$
  每个网格单元最多被访问常数次（太平洋遍历一次，大西洋遍历一次）。
- **空间复杂度**：$O(m \times n)$
  存储可达集合 `set` 以及递归调用栈/队列所需的空间在最坏情况下为 $O(m \times n)$。

## 核心考点与技巧总结

| 维度 | 关键点 |
| :--- | :--- |
| **思维模型** | **逆向扩散（Flood Fill 逆流）**：多源搜索从边界汇聚点反推更高效 |
| **避坑指南** | 逆流合法条件是 `heights[nr][nc] >= heights[r][c]`（只能往高处或等高走） |
| **集合操作** | 利用 Python 的 `set & set` 可以极快提取双洋交集 |
