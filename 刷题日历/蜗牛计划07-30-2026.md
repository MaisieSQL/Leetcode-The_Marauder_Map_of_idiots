# LeetCode 14. 最长公共前缀 (Longest Common Prefix) 专题通关卡片

## 🎯 一、 核心考点与物理直觉

* **题目大意**：
  编写一个函数来查找字符串数组中的最长公共前缀。如果不存在公共前缀，返回空字符串 `""`。

* **物理直觉与“纵向扫描法”**：
  * 想象一下，我们把字符串数组排成一列。如果要求所有字符串的**最长公共前缀**，最直观的做法是**纵向列扫描**：
    1. 我们以数组中的**第一个字符串 (`strs[0]`)** 为标杆，依次遍历它的每一个字符（从第 0 个字符开始）。
    2. 拿这个字符去和其他所有字符串（`strs[1]`, `strs[2]`...）在相同位置上的字符进行比对。
    3. 如果所有字符串在当前位置的字符都一样，说明这个字符是安全的公共前缀的一部分，继续比对下一列。
    4. **一旦遇到以下两种情况之一，比对立刻终止**：
       * 某个字符串的长度已经走到了尽头（超出了边界）。
       * 某个字符串在当前位置的字符和标杆字符对不上。
    此时，标杆字符串从开头到当前位置之前的切片，就是全场唯一的最长公共前缀！

## 💻 二、 Python3 高效通关代码 (Solution)

```python
from typing import List

class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        if not strs:
            return ""
        
        # 以第一个字符串为标杆，纵向遍历它的每一个字符
        for i in range(len(strs[0])):
            char = strs[0][i]
            
            # 拿这个字符去和其余所有字符串的第 i 个字符比对
            for j in range(1, len(strs)):
                # 边界条件：如果当前索引 i 已经超出了某个字符串的长度
                # 或者字符不匹配，说明公共前缀到此为止，直接截断返回
                if i == len(strs[j]) or strs[j][i] != char:
                    return strs[0][:i]
                    
        # 如果第一个字符串本身就是最短的且完全匹配，直接返回它自己
        return strs[0]
```

三、 复杂度核验 (Complexity Analysis)

- 时间复杂度：O(S)，其中 S 是所有字符串中字符数量的总和。在最坏情况下（比如所有字符串完全相同，或者前缀很长），我们需要把每个字符串的所有字符都扫描一遍。
- 空间复杂度：O(1)，因为我们在原地进行纵向扫描和指针比对，只需要常数级别的额外变量开销，没有开辟任何额外的大型辅助数据结构。

  - 第一列结果：所有字符串的第 0 个字符都是 `'f'`。安全通过，索引 `i` 递增，进入下一列！

- 【第二轮：外层循环 i = 1】

  - 第二列结果：全是 `'l'`。安全通过，索引 `i` 递增，进入下一列！
