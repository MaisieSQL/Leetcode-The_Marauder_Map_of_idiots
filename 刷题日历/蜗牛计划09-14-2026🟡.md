### LeetCode 1071. 字符串的最大公因子 (Greatest Common Divisor of Strings)

#### 📝 题目描述 (Description)
对于字符串 `s` 和 `t`，只有在 `s = t + t + t + ... + t`（即 `t` 自身连接 1 次或多次）时，我们才认定 **“`t` 能除尽 `s`”**。

给定两个字符串 `str1` 和 `str2`，返回 **最长字符串 `x`**，要求满足 `x` 能除尽 `str1` 且 `x` 能除尽 `str2`[cite: 1]。

**示例 1：**
* **输入：** `str1 = "ABCABC"`, `str2 = "ABC"`
* **输出：** `"ABC"`

**示例 2：**
* **输入：** `str1 = "ABABAB"`, `str2 = "ABAB"`
* **输出：** `"AB"`[cite: 1]

**示例 3：**
* **输入：** `str1 = "LEET"`, `str2 = "CODE"`
* **输出：** `""`[cite: 1]

#### 🧠 一、 核心直觉与解题思路

##### 💡 方法一：前缀长度倒序枚举（直观暴力法）
1. **寻找最大上限**：如果存在公共“基准积木” `x`，它能同时拼出 `str1` 和 `str2`，那么 `x` 的长度 `L` 绝对不可能超过较短的那个字符串（即 `min(len(str1), len(str2))`）。
2. **从大到小试探**：因为题目要求**最长**的公因子，我们让长度 `L` 从 `min(len1, len2)` 开始**倒序递减**到 `1`。
3. **整除与拼接验证**：
   * 只有当 `L` 能同时整除 `len(str1)` 和 `len(str2)` 时，才有可能拼齐。
   * 截取前缀 `candidate = str1[:L]`，验证 `candidate * (len1 // L) == str1` 且 `candidate * (len2 // L) == str2`。
   * **只要遇到第一个满足条件的长度，立刻返回**（倒序枚举保证了第一个命中即最大）。

##### ⚡ 方法二：数学降维规律（最优秒杀法）
1. **存在性检测（基因检测）**：如果 `str1` 和 `str2` 确实由同一块积木 `x` 重复拼接而成（设 `str1 = m个x`，`str2 = n个x`），那么无论谁拼在前面，结果都是 `(m + n)个x`[cite: 1]：
   $$\text{str1} + \text{str2} == \text{str2} + \text{str1}$$
   若不相等，说明根本不存在公共积木，直接返回 `""`[cite: 1]。
2. **长度锁定**：只要通过了上述检测，最长公共积木的长度在数学上严格等于两字符串长度的最大公约数[cite: 1]：
   $$\text{L} = \gcd(\text{len}(\text{str1}), \text{len}(\text{str2}))$$
   直接截取 `str1[:L]` 返回即可[cite: 1]。

#### 💻 二、 Python 3 通关代码 (Solution)

##### 解法 1：前缀倒序枚举（易理解）
```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        len1, len2 = len(str1), len(str2)
        
        # 从可能的最大长度开始，倒序暴力枚举
        for L in range(min(len1, len2), 0, -1):
            # 1. 长度必须能同时整除两个字符串
            if len1 % L == 0 and len2 % L == 0:
                candidate = str1[:L]
                # 2. 验证无缝拼接后是否等于原字符串
                if candidate * (len1 // L) == str1 and candidate * (len2 // L) == str2:
                    return candidate
                    
        return ""
```

### 三、 复杂度分析 (Complexity Analysis)

| 解法 | 时间复杂度 | 空间复杂度 | 说明 |
| :--- | :---: | :---: | :--- |
| **方法一：倒序枚举** | $O(\min(N, M) * (N + M))$ | $O(N + M)$ | 最坏遍历 $\min(N, M)$ 个长度，每次切片与拼接耗时 $O(N + M)$ |
| **方法二：数学 GCD** | $O(N + M)$ | $O(N + M)$ | 拼接对比字符串耗时 $O(N + M)$，欧几里得求 $\gcd$ 耗时 $O(\log(\min(N, M)))$ |
