## **LeetCode 261. Graph Valid Tree（以图判树）**！

这是一道极其经典的图论面试题，完美考察了我们对“树的数学定义”以及“并查集（Union-Find）判环与连通性”的掌握程度。

### 📝 1. 题目大意与核心考点
- **题目描述**：
  给定节点总数 `n`（编号从 `0` 到 `n - 1`）和一个无向边列表 `edges`。你需要判断这些边组合起来，能不能构成一棵合法的有效树（Valid Tree）。
- **树的数学铁律（充要条件）**：
  一个有 $n$ 个节点的无向图要成为一棵合法的树，必须同时满足以下两个硬性条件：
  1. 不能有环（无环图）。
  2. 必须是完全连通的（所有节点都在同一个连通分量里，不能有孤立的岛屿）。
  3. *(数学推论)*：满足前两点的无向图，其边数必然严格等于 $n - 1$ 条。

### 🛠️ 2. 降维打击：并查集（Union-Find）秒杀流
还记得前面盘过的并查集绝招吗？并查集天生有两个最强杀手锏：检测环和统计连通分量。

#### 💡 核心解题思路
1. **边界特权检查**：如果边的数量 `len(edges) != n - 1`，直接提前剪枝返回 `false`（不满足树的基本边数定律）。
2. **并查集初始化**：一共有 `n` 个节点，初始化 `parent` 数组，起初每个人各自独立。
3. **边遍历与判环**：
   - 遍历每一条边 `[u, v]`，调用 `find(u)` 和 `find(v)`。
   - 如果它们的根节点本来就相同，说明在连这条边之前，`u` 和 `v` 已经连通了，再连一根就会形成“环”，直接返回 `false`。
   - 如果根节点不同，调用 `union(u, v)` 把它们合并，顺便让总连通组件数 `-1`。
4. **终极裁决**：边遍历完后，如果全图没有触发环，且最终连通分量恰好为 1，说明大功告成，返回 `true`。

### 💻 3. Python3 工业级标准通关代码

```python
from typing import List


class Solution:

  def validTree(self, n: int, edges: List[List[int]]) -> bool:
    # 核心铁律：一棵有 n 个节点的树，其边数必须恒等于 n - 1
    if len(edges) != n - 1:
      return False

    # 初始化并查集
    parent = list(range(n))

    def find(i):
      if parent[i] == i:
        return i
      parent[i] = find(parent[i])  # 路径压缩
      return parent[i]

    def union(i, j):
      root_i, root_j = find(i), find(j)
      if root_i != root_j:
        parent[root_i] = root_j
        return True  # 成功合并
      return False  # 本来就在一个帮派里，说明有环！

    # 遍历所有边，动态查环与合并
    for u, v in edges:
      if not union(u, v):
        return False  # 只要发现成环，直接判死刑

    return True
```

### 4. 复杂度核验 (Complexity Analysis)
- **时间复杂度**：$O(N + E \cdot \alpha(N))$ —— 其中 $N$ 是节点数，$E$ 是边数。由于树的边数 $E = N - 1$，且并查集的路径压缩效率极高（$\alpha$ 为阿克曼函数的反函数，接近常数），整体时间复杂度为 $O(N)$ 线性级别。
- **空间复杂度**：$O(N)$ —— 只需要开辟大小为 $N$ 的 `parent` 数组来维护节点的帮派归属。

# LeetCode 695. Max Area of Island (岛屿的最大面积)

## 📝 题目描述 (Description)
给你一个大小为 `m x n` 的二进制矩阵 `grid`。
岛屿是由一些相邻的 `1` (代表土地) 构成的组合，这里的「相邻」要求两个 `1` 必须在**水平或者垂直方向上相邻**。你可以假设矩阵的四个边缘都被水包围着。
岛屿的面积是岛屿上值为 `1` 的单元格的数量。
返回 `grid` 中最大岛屿的面积。如果没有岛屿，则返回 `0`。

---

## 🎯 核心考点与物理直觉

- **与 LeetCode 200（岛屿数量）的血脉联系**：
  - 这两道题的底层骨架几乎一模一样！200 题求的是“岛屿的总个数”，而 695 题求的是“其中面积最大的那座岛屿”。
  - **核心逻辑一致**：通过双重循环遍历全图，一旦发现 `1` 就启动 `DFS`（深度优先搜索）顺藤摸瓜。在淹没岛屿的同时，把走过的格子数量累加起来，最后通过打擂台选出最大面积。

## 🛠️ 解题三步走框架

1. **全图扫描**：用双重 `for` 循环遍历矩阵的每一个格子。
2. **触发深度搜索**：当遇到 `grid[r][c] == 1` 时，代表发现了一座新岛屿，立刻调用递归函数 `dfs(r, c)`。
3. **淹没与面积累加**：
   - 递归进入时，先将当前格子置为 `0`（标记为已访问，防止无限死循环），当前格子贡献 `1` 的面积。
   - 分别向上下左右四个方向递归探索，把四周获取的面积累加并返回给上层。
   - 用全局变量或每次返回的值去更新 `max_area`。

## 💻 Python3 完美通关代码 (Solution)

```python
from typing import List


class Solution:

  def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
    if not grid or not grid[0]:
      return 0

    rows, cols = len(grid), len(grid[0])
    max_area = 0

    def dfs(r: int, c: int) -> int:
      # 递归终止条件：越界，或者遇到水域（0）
      if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] == 0:
        return 0

      # 核心微操：将当前陆地“淹没”（改为 0），防止重复访问
      grid[r][c] = 0

      # 当前格子贡献 1，并向上下左右四个方向递归探路累加面积
      current_area = 1
      current_area += dfs(r - 1, c)  # 上
      current_area += dfs(r + 1, c)  # 下
      current_area += dfs(r, c - 1)  # 左
      current_area += dfs(r, c + 1)  # 右

      return current_area

    # 1. 遍历全图寻找岛屿起点
    for r in range(rows):
      for c in range(cols):
        if grid[r][c] == 1:
          # 2. 启动 DFS 探索当前岛屿面积，并打擂台刷新最大值
          island_area = dfs(r, c)
          max_area = max(max_area, island_area)

    return max_area
```

### 四、 复杂度核验 (Complexity Analysis)
- **时间复杂度**：O(M * N) —— 其中 M 和 N 分别为网格的行数和列数。外层循环需要遍历整个网格的每一个格子。每个格子一旦被访问并修改为 0 之后，就不会再被重复处理，因此每个格子最多被访问一次。
- **空间复杂度**：O(M * N) —— 在最坏情况下（比如整个网格全都是陆地），DFS 的递归调用栈深度可能会达到网格中格子总数的量级。

### 🌊 解法二：BFS 广度优先搜索（队列迭代流）

#### 💡 核心直觉
如果说 DFS 是“顺着一条路死磕到底，撞到南墙再退回来”，那 BFS 就像是**“水波纹一样一层一层向外扩散”**。我们利用一个队列（Queue）来记录当前岛屿上的所有陆地格子，每次弹出一个格子，就把它的上下左右四个邻居捞进队列里，同时累加面积。

#### 💻 Python3 代码实现 (BFS)
```python
from collections import deque
from typing import List


class Solution:

  def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
    if not grid or not grid[0]:
      return 0

    rows, cols = len(grid), len(grid[0])
    max_area = 0

    for r in range(rows):
      for c in range(cols):
        if grid[r][c] == 1:
          # 发现新岛屿，启动 BFS 队列
          current_area = 0
          queue = deque([(r, c)])
          grid[r][c] = 0  # 进队列时立刻置 0，防止重复入队

          while queue:
            curr_r, curr_c = queue.popleft()
            current_area += 1

            # 遍历四个方向
            for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
              nr, nc = curr_r + dr, curr_c + dc
              if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                grid[nr][nc] = 0  # 标记已访问
                queue.append((nr, nc))

          max_area = max(max_area, current_area)

    return max_area

```

### 🌲 解法三：并查集（Union-Find / DSU）

#### 💡 核心直觉
把二维网格中的每一个格子映射成一个一维编号。一开始每个格子各自为政（父节点指向自己，初始面积大小为 1）。我们遍历全图，如果发现相邻的格子都是陆地，就调用 `union` 把它们合并到同一个集合中，并在合并时把小岛屿的面积累加到大岛屿头上。最后直接在所有集合的大小中取个 `max` 就能秒杀答案！

#### 💻 Python3 代码实现 (Union-Find)
```python
from typing import List


class Solution:

  def maxAreaOfIsland(self, grid: List[List[int]]) -> int:
    if not grid or not grid[0]:
      return 0

    rows, cols = len(grid), len(grid[0])
    parent = list(range(rows * cols))
    # 初始化每个集合的面积为 1（只有格子里是 1 的地方有效）
    size = [1 if grid[r][c] == 1 else 0 for r in range(rows) for c in range(cols)]
    max_area = 0

    def find(i):
      if parent[i] == i:
        return i
      parent[i] = find(parent[i])  # 路径压缩
      return parent[i]

    def union(i, j):
      root_i, root_j = find(i), find(j)
      if root_i != root_j:
        parent[root_i] = root_j
        # 将子集合的面积并入父集合
        size[root_j] += size[root_i]

    # 遍历全图，只检查“右边”和“下边”防止重复合并
    for r in range(rows):
      for c in range(cols):
        if grid[r][c] == 1:
          idx = r * cols + c
          max_area = max(max_area, size[idx])
          for dr, dc in [(0, 1), (1, 0)]:  # 右、下
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
              n_idx = nr * cols + nc
              union(idx, n_idx)
              max_area = max(max_area, size[find(idx)])

    return max_area
```

### 📊 三种解法对比

| 解法 | 核心机制 | 时间复杂度 | 空间复杂度 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **DFS** | 递归系统栈（淹没流） | O(M * N) | O(M * N) | 代码最简短，面试最常用 |
| **BFS** | 显式队列迭代 | O(M * N) | O(M * N) | 防止极深递归导致栈溢出 |
| **并查集** | 树状合并与路径压缩 | O(M * N * α) | O(M * N) | 适合动态加边或连通性统计 |
