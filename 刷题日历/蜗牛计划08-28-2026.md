# LeetCode 104. Maximum Depth of Binary Tree (二叉树的最大深度)

## 📝 题目描述 (Description)
给定一个二叉树的根节点 `root`，找出并返回其**最大深度**[cite: 4]。
二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数（叶子节点是指没有子节点的节点）[cite: 4]。

---

## 🛠️ 多种解法与代码实现 (Multiple Solutions)

### 方法一：递归流（自底向上 DFS / 甩手掌柜法）── 最经典、最优雅
#### 💡 核心直觉
把你自己当成大老板（根节点），你把左右副总叫来，让他们各自汇报左右子树的最大深度。你只需要挑出最大的一边，然后加上你自己的那一层（`+ 1`）即可[cite: 4]。

#### 💻 Python3 代码实现
```python
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right


class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    # 1. 递归出口：空节点深度为 0
    if not root:
      return 0

    # 2. 递归获取左右子树的最大深度
    left_depth = self.maxDepth(root.left)
    right_depth = self.maxDepth(root.right)

    # 3. 左右取最大值，并加上当前根节点所在的这一层
    return max(left_depth, right_depth) + 1
```

### 方法二：广度优先搜索流（BFS / 层序遍历计数）── 工业级队列迭代
#### 💡 核心直觉
使用队列（Queue）进行层序遍历。每一层扫过去时，用 `step` 计数器记录层数。整棵树被剥完几层，最大深度就是几。

#### 💻 Python3 代码实现
```python
from collections import deque


class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    if not root:
      return 0

    queue = deque([root])
    depth = 0

    while queue:
      level_size = len(queue)
      for _ in range(level_size):
        node = queue.popleft()
        if node.left:
          queue.append(node.left)
        if node.right:
          queue.append(node.right)
      # 每一层处理完，深度 +1
      depth += 1

    return depth
```

### 方法三：前序遍历迭代流（DFS 显式栈 + 状态追踪）
#### 💡 核心直觉
用显式栈模拟递归过程，在栈里同时存储节点和它当前对应的深度。边往下走边用全局变量或比对刷新最大深度。

#### 💻 Python3 代码实现
```python
class Solution:

  def maxDepth(self, root: Optional[TreeNode]) -> int:
    if not root:
      return 0

    stack = [(root, 1)]
    max_d = 0

    while stack:
      node, depth = stack.pop()
      if node:
        max_d = max(max_d, depth)
        if node.left:
          stack.append((node.left, depth + 1))
        if node.right:
          stack.append((node.right, depth + 1))

    return max_d
```

复杂度核验 (Complexity Analysis)
- 时间复杂度：$O(N)$ —— 其中 $N$ 是二叉树的节点总数。每一个节点在遍历过程中都恰好被访问一次。
- 空间复杂度：$O(H)$ —— 其中 $H$ 是树的高度。主要消耗在递归调用栈（或 BFS 队列）上。在最坏情况下（链状树），空间复杂度为 $O(N)$；在平衡二叉树中，空间复杂度为 $O(\log N)$。
