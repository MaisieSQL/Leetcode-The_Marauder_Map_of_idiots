# LeetCode 268. 丢失的数字 (Missing Number)

## 一、 题目描述
给定一个包含 `[0, n]` 中 `n` 个数的数组 `nums`，找出 `[0, n]` 这个范围内没有出现在数组中的那个数。

- **进阶**：你能否实现线性时间复杂度、仅使用额外常数空间的算法来完成此题？

## 二、 解题思路

### 方法一：数学求和法（高斯求和公式）
`[0, n]` 完整序列共有 `n + 1` 个连续整数，其理论总和为：
$$\text{expected\_sum} = \frac{n \times (n + 1)}{2}$$
由于数组中缺少了唯一一个目标数字，只需用理论总和减去数组实际元素之和 `sum(nums)`，差值即为缺失的数字。

### 方法二：位运算（异或运算 `^`）
异或运算满足交换律、结合律，且有：
- $a \oplus a = 0$
- $a \oplus 0 = a$

将 `0` 到 `n` 的所有整数与数组 `nums` 中的所有元素放在一起做异或：
- 出现两次的数字（既在 `[0, n]` 中又在 `nums` 中）会两两抵消为 `0`；
- 最终剩下的唯一结果就是缺失的那个数（同时天然避免了大数相加可能导致的溢出问题）。

## 三、 Python3 参考代码

### 1. 数学求和法
```python
class Solution:
    def missingNumber(self, nums: list[int]) -> int:
        n = len(nums)
        expected_sum = n * (n + 1) // 2
        return expected_sum - sum(nums)
```

四、 复杂度分析
- 时间复杂度：O(n)，其中 n 是数组 nums 的长度，只需遍历一次数组。
- 空间复杂度：O(1)，仅使用常数级别的额外变量。

# LeetCode 2013. 检测正方形 (Detect Squares)

## 一、 题目描述
给你一个在 X-Y 平面上的点构成的数据流。设计一个满足下述要求的算法：
- **添加** 一个在数据流中的新点 `point = [x, y]`。允许存在多个值相同的点，即多个点可以与当前数据流中的其他点重叠。
- **统计** 满足下述条件的正方形个数：给定一个查询点 `point = [px, py]`，选择数据流中的三个点，使得这三个点和查询点组成一个面积大于 `0` 的正方形，且正方形的四条边都平行于 X 轴和 Y 轴。

## 二、 解题思路

### 1. 统计点的出现次数
因为允许重复添加相同的点，我们可以用一个哈希表（如 `defaultdict(int)`）记录每个点 `(x, y)` 出现的次数。当某个正方形的顶点出现多次时，根据乘法原理，不同重复点之间可以组合出多种方案，因此需要把对应顶点的出现次数相乘。

### 2. 枚举对角顶点
已知查询点为 `P = (px, py)`：
- 如果我们把数据流中已有的某个点 `Q = (x, y)` 当作与 `P` **相对的对角顶点**，那么正方形另外两个顶点的坐标就唯一确定了：
  - `A = (px, y)`（与 `P` 同 `x`，与 `Q` 同 `y`）
  - `B = (x, py)`（与 `Q` 同 `x`，与 `P` 同 `y`）
- 满足构成**面积大于 0 且边平行于坐标轴的正方形**的条件是：
  - 横向距离 `dx = abs(x - px)` 等于纵向距离 `dy = abs(y - py)`；
  - 且边长不能为 `0`（即 `dx != 0`）。

### 3. 计算方案数
对于满足上述条件的每个对角点 `(x, y)`：
- 检查 `(px, y)`、`(x, py)`、`(x, y)` 是否都在数据流中。
- 若都在，则该对角点贡献的正方形数量为：
  `count[(px, y)] * count[(x, py)] * count[(x, y)]`
- 将所有合法对角点的贡献累加即可。

## 三、 Python3 参考代码

```python
import math
from collections import defaultdict


class DetectSquares:

    def __init__(self):
        self.collector = defaultdict(int)

    def add(self, point: list[int]) -> None:
        self.collector[tuple(point)] += 1

    def count(self, point: list[int]) -> int:
        px, py = point
        res = 0
        for x, y in self.collector:
            if (dx := abs(x - px)) == (dy := abs(y - py)) != 0:
                points = ((px, y), (x, py), (x, y))
                if all(p in self.collector for p in points):
                    res += math.prod(self.collector[p] for p in points)
        return res
```

四、 复杂度分析
- add 时间复杂度：O(1)，哈希表插入与计数更新均为常数时间。
- count 时间复杂度：O(N)，其中 N 为当前数据流中不同点的数量；每次查询遍历已记录的点并做 O(1) 哈希查找。
- 空间复杂度：O(N)，用于存储各个点的出现次数。

# LeetCode 7. 整数反转 (Reverse Integer)

## 一、 题目描述
给你一个 32 位的有符号整数 `x`，返回将 `x` 中的数字部分反转后的结果。
如果反转后整数超过 32 位的有符号整数的范围 `[-2^31, 2^31 - 1]`，就返回 `0`。

- **假设环境不允许存储 64 位整数（有符号或无符号）。**

## 二、 解题思路

### 1. 逐位提取与拼接
将数字按十进制从右往左一位一位“抽”出来，倒着拼成新数字：
- 设当前待处理正数为 `num`，反转累计值为 `rev = 0`。
- 每次通过 `digit = num % 10` 取出最右边的数字，通过 `num //= 10` 去掉最右边的数字。
- 将 `rev` 进位并拼接：`rev = rev * 10 + digit`。

### 2. 正负号处理
- 先记录符号 `sign = -1 if x < 0 else 1`，再令 `num = abs(x)` 按正数统一反转，最后乘回 `sign` 得到带符号结果 `ans`。

### 3. 32 位有符号整数溢出边界检查
- 32 位有符号整数合法区间为 `[-2147483648, 2147483647]`（即 `[-2^31, 2^31 - 1]`）。
- 若反转后的结果超出该范围，返回 `0`。

## 三、 Python3 参考代码

```python
class Solution:
    def reverse(self, x: int) -> int:
        min_int = -(2**31)
        max_int = 2**31 - 1

        sign = -1 if x < 0 else 1
        num = abs(x)
        rev = 0

        while num != 0:
            digit = num % 10
            num //= 10
            rev = rev * 10 + digit

        ans = sign * rev
        if ans < min_int or ans > max_int:
            return 0
        return ans
```

四、 复杂度分析
- 时间复杂度：O(log|x|)，十进制位数决定循环次数（32 位整数最多 10 位）。
- 空间复杂度：O(1)，仅使用常数级别的额外变量。

# LeetCode 2402. 会议室 III (Meeting Rooms III)

## 一、 题目描述
给你一个整数 `n` ，共有编号从 `0` 到 `n - 1` 的 `n` 间会议室。
给你一个二维整数数组 `meetings` ，其中 `meetings[i] = [start_i, end_i]` 表示一场会议将在 **半闭半开** 时间区间 `[start_i, end_i)` 举办。所有 `start_i` 的值都是 **互不相同** 的。

会议分配到会议室的方式如下：
1. 每场会议都会在未使用的编号 **最小** 的会议室举行。
2. 如果没有可用的会议室，会议将会 **延迟** ，直到存在空闲的会议室。被延迟的会议应该建在与原定时间 **相同** 的时间长度内。
3. 当会议室使用完毕时，该会议室将在 **不受延迟** 的时间里成为空闲状态。如果某个会议室在 `t` 时刻空出，那么在 `t` 时刻或之后举行的会议都可以利用这个空闲的会议室。

请你返回举办会议次数 **最多** 的会议室的编号。如果存在多个这样的会议室，请返回编号 **最小** 的那个。

## 二、 解题思路

相比 **Meeting Rooms II** 只关心“最多同时需要几间房”，**Meeting Rooms III** 不仅房间数量固定为 `n`（编号 `0` 到 `n - 1`），还要**按编号从小到大挑空房**、**处理会议顺延（保持时长不变）**，最后统计**每间房的开会次数**。

我们可以用**“会议按开始时间排序 + 双最小堆”**来高效模拟整个调度过程：

### 1. 会议按开始时间排序
因为所有 `start_i` 互不相同，先将 `meetings` 按 `start_i` 升序排序，确保按原定开始时间依次处理每场会议。

### 2. 维护两个小根堆与计数数组
- **`available`（空闲会议室堆）**：存放当前空闲的会议室编号 `room_id`，初始为 `[0, 1, ..., n - 1]`。堆顶永远是编号最小的空闲房间。
- **`used`（占用中会议室堆）**：存放 `(end_time, room_id)`，表示会议室 `room_id` 将在 `end_time` 时刻腾空。堆顶永远是最早释放的房间（若释放时间相同，则按 `room_id` 从小到大排序）。
- **`count`（使用次数数组）**：长度为 `n`，`count[r]` 记录编号为 `r` 的会议室举办的会议总数。

### 3. 处理每场会议 `[start, end]`
设会议时长为 `duration = end - start`：
1. **释放已结束的会议室**：在当前会议实际开始前，先把 `used` 中所有满足 `release_time <= start` 的记录弹出，将其 `room_id` 放回 `available`。
2. **分配会议室**：
   - **情况 A（有空闲房间，`available` 非空）**：弹出编号最小的房间 `room_id`，实际开始时间为 `start`，实际结束时间为 `start + duration`（即 `end`），将 `(end, room_id)` 压入 `used`，`count[room_id] += 1`。
   - **情况 B（无空闲房间，`available` 为空）**：必须等最早空出的房间！从 `used` 弹出 `(release_time, room_id)`。此时会议被迫延迟到 `release_time` 开始，因为**时长保持不变**，新的结束时间为 `new_end = release_time + duration`。将 `(new_end, room_id)` 压入 `used`，`count[room_id] += 1`。

### 4. 统计答案
遍历 `room_id` 从 `0` 到 `n - 1`，找出 `count[room_id]` 最大的那个编号；若次数相同，由于是从 `0` 到 `n - 1` 顺序扫描（仅在严格 `>` 时更新），自然保留编号最小的那个。

## 三、 Python3 参考代码

```python
import heapq


class Solution:

  def mostBooked(self, n: int, meetings: list[list[int]]) -> int:
    meetings.sort(key=lambda x: x[0])

    # 空闲房间编号小根堆
    available: list[int] = list(range(n))
    heapq.heapify(available)

    # 占用中房间小根堆：存储 (结束时间, 房间编号)
    used: list[tuple[int, int]] = []

    # 每间会议室举办的会议次数
    count = [0] * n

    for start, end in meetings:
      duration = end - start

      # 1. 腾出在 start 时刻及之前已经结束的会议室
      while used and used[0][0] <= start:
        _, room_id = heapq.heappop(used)
        heapq.heappush(available, room_id)

      # 2. 分配会议室
      if available:
        room_id = heapq.heappop(available)
        new_end = end
      else:
        release_time, room_id = heapq.heappop(used)
        new_end = release_time + duration

      heapq.heappush(used, (new_end, room_id))
      count[room_id] += 1

    # 3. 找开会次数最多的房间，次数相同取编号最小
    ans = 0
    for room_id in range(1, n):
      if count[room_id] > count[ans]:
        ans = room_id

    return ans
```

四、 复杂度分析
- 时间复杂度：O(M log M + M log N)，其中 M 是会议数量（len(meetings)），N 是会议室数量。排序耗时 O(M log M)；每场会议最多进出堆常数次，每次堆操作耗时 O(log N)，总计 O(M log N)。
- 空间复杂度：O(N)（不计排序自带的栈开销），available、used 和 count 最多各存储 N 个元素。

# LeetCode 136. 只出现一次的数字 (Single Number)

## 一、 题目描述
给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

## 二、 解题思路

### 核心解法：异或运算（Bitwise XOR，`^`）
异或运算具有以下性质：
- **归零律**：任何数与自身异或结果为 `0`，即 $x \oplus x = 0$。
- **恒等律**：任何数与 `0` 异或结果为其自身，即 $x \oplus 0 = x$。
- **交换律与结合律**：运算顺序不影响最终结果，即 $a \oplus b \oplus a = (a \oplus a) \oplus b = b$[cite: 3]。

由于数组中除了唯一的目标数字出现 `1` 次外，其余元素均出现 `2` 次，将数组中的所有元素依次进行异或运算，成对出现的数字会两两抵消为 `0`，最终留下的结果即为只出现一次的数字[cite: 3]。

## 三、 Python3 参考代码

```python
class Solution:
    def singleNumber(self, nums: list[int]) -> int:
        res = 0
        for num in nums:
            res ^= num
        return res
```

四、 复杂度分析
- 时间复杂度：O(n)，其中 n 是数组 nums 的长度，只需遍历一次数组。
- 空间复杂度：O(1)，仅使用常数级别的额外变量。

# LeetCode 54. 螺旋矩阵 (Spiral Matrix)

## 一、 题目描述
给你一个 $m \times n$ 矩阵 `matrix` ，请按照 **顺时针螺旋顺序** ，返回矩阵中的所有元素[cite: 3, 5]。

## 二、 解题思路

### 1. 四边界向内收缩模拟法
将螺旋遍历看作像“剥洋葱”一样逐层向内收缩的过程[cite: 3, 5]：
- 定义四个边界指针：
  - `top = 0`（当前未遍历最顶行）[cite: 3, 5]
  - `bottom = len(matrix) - 1`（当前未遍历最底行）[cite: 3, 5]
  - `left = 0`（当前未遍历最左列）[cite: 3, 5]
  - `right = len(matrix[0]) - 1`（当前未遍历最右列）[cite: 3, 5]
- 在循环中依次按顺时针扫完四条边，每走完一条边就把对应边界往里推一格，并在边界更新后立即检查是否已经交叉越界（`top > bottom` 或 `left > right`），一旦越界立刻终止[cite: 3, 5, 8]：
  1. **从左到右**遍历 `top` 行：`col` 从 `left` 到 `right`，随后 `top += 1`；若 `top > bottom` 则结束[cite: 3, 5, 8]。
  2. **从上到下**遍历 `right` 列：`row` 从 `top` 到 `bottom`，随后 `right -= 1`；若 `left > right` 则结束[cite: 3, 5, 8]。
  3. **从右到左**遍历 `bottom` 行：`col` 从 `right` 到 `left`，随后 `bottom -= 1`；若 `top > bottom` 则结束[cite: 3, 5, 8]。
  4. **从下到上**遍历 `left` 列：`row` 从 `bottom` 到 `top`，随后 `left += 1`；若 `left > right` 则结束[cite: 3, 5, 8]。

### 2. 为什么不用 DFS / BFS？
- **轨迹高度确定**：螺旋遍历需要严格按“右、下、左、上”的固定几何顺序推进，属于确定性路径模拟，而非无序连通性或最短路探索[cite: 3, 5]。
- **空间与控制更优**：边界指针法仅需常数个边界变量（辅助空间 $\mathcal{O}(1)$），无需维护额外的 `visited` 矩阵或递归调用栈[cite: 3, 5, 8]。

## 三、 Python3 参考代码

```python
class Solution:

  def spiralOrder(self, matrix: list[list[int]]) -> list[int]:
    if not matrix or not matrix[0]:
      return []

    res = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1

    while True:
      # 1. 从左到右遍历顶行
      for col in range(left, right + 1):
        res.append(matrix[top][col])
      top += 1
      if top > bottom:
        break

      # 2. 从上到下遍历右列
      for row in range(top, bottom + 1):
        res.append(matrix[row][right])
      right -= 1
      if left > right:
        break

      # 3. 从右到左遍历底行
      for col in range(right, left - 1, -1):
        res.append(matrix[bottom][col])
      bottom -= 1
      if top > bottom:
        break

      # 4. 从下到上遍历左列
      for row in range(bottom, top - 1, -1):
        res.append(matrix[row][left])
      left += 1
      if left > right:
        break

    return res
```

## 四、 复杂度分析
- **时间复杂度**：O(M * N)，其中 M 和 N 分别为矩阵的行数和列数，每个元素恰好被访问一次[cite: 3, 8]。
- **空间复杂度**：O(1)，仅使用常数级别的边界指针变量（不计返回结果数组 `res` 的空间）[cite: 3, 8]。
