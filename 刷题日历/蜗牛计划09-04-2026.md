# 1863. Sum of All Subset XOR Totals (找出所有子集的异或总和再求和)

- **难度**：Easy
- **标签**：位运算、数学、回溯、数组
- **LeetCode 链接**：[LeetCode 1863. Sum of All Subset XOR Totals](https://leetcode.com/problems/sum-of-all-subset-xor-totals/)

### 一、 题目描述

一个数组的 **异或总和** 定义为数组中所有元素按位 `XOR` 的结果；如果数组为 **空**，则异或总和为 `0`。

* 例如，数组 `[2, 5, 6]` 的异或总和为 `2 ^ 5 ^ 6 = 1`。

给你一个整数数组 `nums`，请你求出 `nums` 中 **每个子集** 的 **异或总和**，计算并返回这些值相加的 **总和**。

**注意**：
* 本题中的 **子集** 包含空集以及数组本身。
* 两个子集的元素若在原数组中的下标不同，即视为不同的子集。

### 二、 示例说明

#### 示例 1
* **输入**：`nums = [1, 3]`
* **输出**：`6`
* **解释**：
  * `[]` 的异或总和为 `0`
  * `[1]` 的异或总和为 `1`
  * `[3]` 的异或总和为 `3`
  * `[1, 3]` 的异或总和为 `1 ^ 3 = 2`
  * 所有子集异或值之和为：`0 + 1 + 3 + 2 = 6`

#### 示例 2
* **输入**：`nums = [5, 1, 6]`
* **输出**：`28`
* **解释**：
  * 共有 $2^3 = 8$ 个子集：
    * `[]` $\to 0$
    * `[5]` $\to 5$
    * `[1]` $\to 1$
    * `[6]` $\to 6$
    * `[5, 1]` $\to 5 \oplus 1 = 4$
    * `[5, 6]` $\to 5 \oplus 6 = 3$
    * `[1, 6]` $\to 1 \oplus 6 = 7$
    * `[5, 1, 6]` $\to 5 \oplus 1 \oplus 6 = 2$
  * 总和：`0 + 5 + 1 + 6 + 4 + 3 + 7 + 2 = 28`

#### 数据范围约束
* $1 \le \text{nums.length} \le 12$
* $1 \le \text{nums}[i] \le 20$

**“异或总和”（XOR Total）**并不是通用的标准数学名词，而是这道题目自己专门定义的一个概念：

> **“把一个集合（或数组）里的所有数字，统统用按位异或（$\oplus$ 或代码里的 `^`）连起来算出的最终结果。”**

### 一、 先看单个子集的“异或总和”怎么算

就像平时我们说“累加和”是把数字用加号连起来（$1 + 3 = 4$），这道题定义的“异或总和”就是**把数字全用异或符号连起来**：

* 如果子集是 `[5]`：
  * 里面就它一个，异或总和 = **$5$**。
* 如果子集是 `[5, 1]`：
  * 异或总和 = $5 \oplus 1$。
  * 二进制计算：`101 ^ 001 = 100`（十进制为 4），异或总和 = **$4$**。
* 如果子集是 `[5, 1, 6]`：
  * 异或总和 = $5 \oplus 1 \oplus 6$。
  * 先算 $5 \oplus 1 = 4$（`100`），再算 $4 \oplus 6$（`100 ^ 110 = 010`，十进制为 2），异或总和 = **$2$**。
* 如果是**空集 `[]`**：
  * 题目特殊规定：里面没有任何数，异或总和直接记为 **$0$**。

### 二、 题目到底要你求什么？

题目的名字叫 **Sum of All Subset XOR Totals**（所有子集异或总和的**求和**）。

它其实分了两步走：

1. **第一步（异或内部）**：把数组切出所有可能的子集，求出**每一个子集自己的“异或总和”**。
2. **第二步（普通加法外包）**：把这些算出来的“异或总和”，用**普通加法（$+$）**全部加在一起。

**以 `nums = [1, 3]` 为例**：

| 步骤 | 子集 | 该子集的“异或总和”（用 $\oplus$ 算） |
| :---: | :---: | :---: |
| 1 | `[]` | $0$ |
| 2 | `[1]` | $1$ |
| 3 | `[3]` | $3$ |
| 4 | `[1, 3]` | $1 \oplus 3 = 2$ |

最后，把右边这一列所有的“异或总和”做**正常的加法累加**：

$$\text{最终答案} = 0 + 1 + 3 + 2 = 6$$

> **一句话总结**：**子集内部算异或，子集之间算加法。**

### 三、 解法一：回溯法（暴搜所有子集）

题目数据范围极小（$n \le 12$），全部子集数量最多仅 $2^{12} = 4096$ 个，直接通过 DFS/回溯枚举每个数字“选”或“不选”即可。

#### 1. 递归逻辑
定义 `dfs(index, current_xor)`：
* 递归边界：当 `index == len(nums)` 时，说明处理完所有元素，直接返回 `current_xor`。
* 两种分支：
  * **不选当前元素**：`dfs(index + 1, current_xor)`
  * **选入当前元素**：`dfs(index + 1, current_xor ^ nums[index])`
* 将两个分支的结果累加。

#### 2. Python 3 实现

```python
class Solution:

  def subsetXORSum(self, nums: list[int]) -> int:
    def dfs(index: int, curr_xor: int) -> int:
      if index == len(nums):
        return curr_xor

      # 分支 1：不选 nums[index]
      without_curr = dfs(index + 1, curr_xor)
      # 分支 2：选入 nums[index]
      with_curr = dfs(index + 1, curr_xor ^ nums[index])

      return without_curr + with_curr

    return dfs(0, 0)
```

* **时间复杂度**：$O(2^n)$，生成整棵高度为 $n$ 的二叉递归树。
* **空间复杂度**：$O(n)$，递归调用栈深度。

以 `nums = [5, 1, 6]` 为例，`len(nums) = 3`。

整个 DFS 的本质就是一棵高度为 3 的完全二叉树。每一层代表对一个数字做决定：左走是不选（保留原值），右走是选入（异或该值）。

当递归走到最底部（`index == 3`）时，说明做完了所有 3 个数字的决定，此时的 `curr_xor` 恰好就是一个完整子集的异或总和，直接返回它；上层父节点把左右两路的结果加起来（`without_curr + with_curr`）。

### 一、 递归决策树全景

每个节点记录 `(index, curr_xor)`：

```text
                     dfs(0, 0)                  <- 面对 nums[0]=5
                    /         \
          不选 5  /             \ 选 5 (0 ^ 5 = 5)
                /                 \
          dfs(1, 0)              dfs(1, 5)        <- 面对 nums[1]=1
          /       \              /       \
     不选 /         \ 选 1   不选 /         \ 选 1
        /           \          /           \
    dfs(2,0)     dfs(2,1)   dfs(2,5)     dfs(2,4)  <- 面对 nums[2]=6
     /   \        /   \      /   \        /   \
  不选\ /选6   不选\ /选6 不选\ /选6   不选\ /选6
    (A)  (B)    (C)  (D)  (E)  (F)    (G)  (H)     <- 触底 index == 3
```

### 二、 8 个底端叶子节点的逐个触底过程

当 `index == 3` 时，触发 `if index == len(nums): return curr_xor`：

#### 左半边大分支（一开始不选 5 的 4 个子集）：
* **叶子 (A)**：`dfs(3, 0)` $\to$ 对应子集 `[]`，返回 **0**
* **叶子 (B)**：`dfs(3, 0 ^ 6 = 6)` $\to$ 对应子集 `[6]`，返回 **6**
  * 汇聚到父节点 `dfs(2, 0)`：返回 $0 + 6 = 6$
* **叶子 (C)**：`dfs(3, 1)` $\to$ 对应子集 `[1]`，返回 **1**
* **叶子 (D)**：`dfs(3, 1 ^ 6 = 7)` $\to$ 对应子集 `[1, 6]`，返回 **7**
  * 汇聚到父节点 `dfs(2, 1)`：返回 $1 + 7 = 8$
* 汇聚到祖父节点 `dfs(1, 0)`：返回 $6 + 8 = 14$

#### 右半边大分支（一开始选了 5 的 4 个子集）：
* **叶子 (E)**：`dfs(3, 5)` $\to$ 对应子集 `[5]`，返回 **5**
* **叶子 (F)**：`dfs(3, 5 ^ 6 = 3)` $\to$ 对应子集 `[5, 6]`，返回 **3**
  * 汇聚到父节点 `dfs(2, 5)`：返回 $5 + 3 = 8$
* **叶子 (G)**：`dfs(3, 4)` $\to$ 对应子集 `[5, 1]`，返回 **4**
* **叶子 (H)**：`dfs(3, 4 ^ 6 = 2)` $\to$ 对应子集 `[5, 1, 6]`，返回 **2**
  * 汇聚到父节点 `dfs(2, 4)`：返回 $4 + 2 = 6$
* 汇聚到祖父节点 `dfs(1, 5)`：返回 $8 + 6 = 14$

### 三、 最终在根节点求和

代码回到最初的入口 `dfs(0, 0)`：
* `without_curr`（左半树总和）= $14$
* `with_curr`（右半树总和）= $14$
* 返回 `without_curr + with_curr = 14 + 14 = 28`

递归的折返过程直接完成了普通加法的累加，最终结果为 **28**。


### 四、 解法二：数学按位统计法（$O(n)$ 最优解）

异或运算是按位完全独立的，我们无需关心每个子集算出来的整体数字是多少，只需单独观察第 $k$ 位（二进制位）在所有子集里贡献了多少次 $1$。

#### 1. 数学推导

设数组包含 $n$ 个数。考虑二进制的第 $k$ 位：

* 若原数组中**没有任何数字**的第 $k$ 位为 $1$，那么任何子集异或后该位永远为 $0$。
* 若原数组中**至少存在一个数字**的第 $k$ 位为 $1$：
  * 假设共有 $m$ 个数的第 $k$ 位为 $1$（$m \ge 1$），剩下的 $n - m$ 个数的第 $k$ 位为 $0$。
  * 只要从这 $m$ 个数中选出**奇数个**，子集异或结果的第 $k$ 位就会是 $1$。
  * 根据二项式定理组合恒等式：
    $$\binom{m}{1} + \binom{m}{3} + \binom{m}{5} + \dots = 2^{m - 1}$$
  * 从剩下 $n - m$ 个第 $k$ 位为 $0$ 的数字中，可以任意挑选子集，共有 $2^{n - m}$ 种方案。
  * 因此，第 $k$ 位异或结果为 $1$ 的子集总数为：
    $$2^{m - 1} \times 2^{n - m} = 2^{n - 1}$$

**惊人结论**：
只要数组里有任意数字包含第 $k$ 位，那么在所有 $2^n$ 个子集中，**恰好有一半（$2^{n-1}$ 个）的子集该位为 1，另一半为 0**！

因此，只要把数组中所有数做一次**按位或（OR）**运算，把所有出现过的二进制位收集起来，整体放大 $2^{n-1}$ 倍（即左移 $n-1$ 位），就是最终答案。

#### 2. Python 3 实现

```python
from functools import reduce
import operator


class Solution:

  def subsetXORSum(self, nums: list[int]) -> int:
    # 将所有数字按位或起来
    bitwise_or_all = reduce(operator.ior, nums)

    # 乘以 2^(n - 1)
    return bitwise_or_all << (len(nums) - 1)
```

时间复杂度：$O(n)$，只需单次遍历数组完成按位或运算。
空间复杂度：$O(1)$，仅需常数级别的辅助变量。

# 5. Longest Palindromic Substring (最长回文子串)

- **难度**：Medium
- **标签**：双指针、动态规划、字符串
- **LeetCode 链接**：[LeetCode 5. Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/)

### 一、 题目描述

给你一个字符串 `s`，找到 `s` 中最长的**回文子串**。

> **回文串**：向前读和向后读都一模一样的字符串（例如 `"aba"`、`"abba"`）。  
> **子串**：字符串中连续的一段字符序列。

#### 示例 1：
- **输入**：`s = "babad"`
- **输出**：`"bab"`
- **解释**：`"aba"` 同样是有效答案。

#### 示例 2：
- **输入**：`s = "cbbd"`
- **输出**：`"bb"`

#### 提示：
- $1 \le s.\text{length} \le 1000$
- `s` 仅由数字和英文字母组成。

### 二、 核心破局点：中心扩散法 (Center Expansion)

判断或寻找回文串有两种根本视角：
1. **两头向内收缩**：拿双指针分别指向串的首尾往中间走（适合判断单个已知字符串是否为回文）。
2. **中心向外扩散**：以某个字符或空隙为基准，同时向左右两边试探（适合在长串里动态寻找最长回文）。

在长度为 $n$ 的字符串中，任意子串都有且仅有一个“回文中心”：
* **奇数长度中心**：以某个单字符为中心，形如 `"aba"`（中心是 `b`）。总共有 $n$ 个单字符中心。
* **偶数长度中心**：以两个相邻字符的“缝隙”为中心，形如 `"abba"`（中心在两个 `b` 之间）。总共有 $n - 1$ 个缝隙中心。

整个字符串总共只有 **$2n - 1$ 个可能的回文中心**。我们只需遍历这 $2n - 1$ 个中心，分别往两侧扩散，记录能够扩散出的最大窗口边界即可。

### 三、 算法步骤

1. 维护两个全局变量：`start`（最长回文子串的起始下标）和 `max_len`（最大长度，初始为 0）。
2. 封装一个扩散辅助函数 `expand(left, right)`：
   * 在满足 `left >= 0`、`right < len(s)` 且两端字符严格相等（`s[left] == s[right]`）的前提下，两指针同步向外走：`left -= 1`, `right += 1`。
   * 退出循环时，说明遇到了字符不匹配或越界。此时最后一次合法的回文区间是开区间 `(left, right)`，实际合法闭区间为 `[left + 1, right - 1]`。
   * 计算当前回文长度：$\text{curr\_len} = (right - 1) - (left + 1) + 1 = right - left - 1$。
   * 若 `curr_len > max_len`，则刷新 `max_len`，并将 `start` 更新为 `left + 1`。
3. 遍历原串下标 $i \in [0, n - 1]$：
   * 检查以 $s[i]$ 为中心的奇数回文：`expand(i, i)`。
   * 检查以 $s[i]$ 和 $s[i+1]$ 之间为中心的偶数回文：`expand(i, i + 1)`。
4. 切片返回 `s[start : start + max_len]`。

### 四、 Python 3 标准实现（纯函数无副作用写法）

在实现时，推荐让辅助函数直接返回计算出的区间 `(left_bound, right_bound)`，外层负责对比刷新，逻辑清晰且避免变量逃逸问题：

```python
class Solution:

  def longestPalindrome(self, s: str) -> str:
    n = len(s)
    if n <= 1:
      return s

    start = 0
    max_len = 0

    # 辅助函数：从指定中心向外扩散，返回合法回文子串的 [闭区间起点, 长度]
    def expand_from_center(left: int, right: int) -> tuple[int, int]:
      while left >= 0 and right < n and s[left] == s[right]:
        left -= 1
        right += 1
      # 退出循环时 left 和 right 均已向外多迈了一步
      # 实际有效起始点为 left + 1，长度为 (right - 1) - (left + 1) + 1 = right - left - 1
      actual_start = left + 1
      curr_len = right - left - 1
      return actual_start, curr_len

    for i in range(n):
      # 1. 奇数长度中心扩散 (例如 "aba")
      start_odd, len_odd = expand_from_center(i, i)
      if len_odd > max_len:
        max_len = len_odd
        start = start_odd

      # 2. 偶数长度中心扩散 (例如 "abba")
      start_even, len_even = expand_from_center(i, i + 1)
      if len_even > max_len:
        max_len = len_even
        start = start_even

    return s[start : start + max_len]
```

### 五、 补充解法：区间动态规划 (DP)

如果从动态规划的角度思考：

* **状态定义**：`dp[i][j]` 表示子串 $s[i \dots j]$ 是否为回文（布尔值）。
* **转移方程**：
  $$dp[i][j] = (s[i] == s[j]) \land (j - i \le 2 \lor dp[i+1][j-1])$$
* **遍历顺序**：因为 $dp[i][j]$ 依赖左下方更短的区间 $dp[i+1][j-1]$，所以外层循环 $i$ 必须从大到小（从下往上），内层循环 $j$ 从 $i$ 到 $n-1$。

```python
class SolutionDP:

  def longestPalindrome(self, s: str) -> str:
    n = len(s)
    if n <= 1:
      return s

    dp = [[False] * n for _ in range(n)]
    start = 0
    max_len = 1

    for i in range(n - 1, -1, -1):
      dp[i][i] = True  # 单个字符天然是回文
      for j in range(i + 1, n):
        if s[i] == s[j]:
          # 长度为 2 或 3 时 (j - i <= 2)，两端相等即是回文
          if j - i <= 2:
            dp[i][j] = True
          else:
            dp[i][j] = dp[i + 1][j - 1]

        if dp[i][j] and (j - i + 1) > max_len:
          max_len = j - i + 1
          start = i

    return s[start : start + max_len]
```

### 六、 复杂度对比与选型

| 解法 | 时间复杂度 | 空间复杂度 | 面试推荐度 | 评价 |
| :--- | :---: | :---: | :---: | :--- |
| **中心扩散法** | $O(n^2)$ | **$O(1)$** | ⭐⭐⭐⭐⭐ (首选) | 空间常数级，代码简短，无任何额外内存开销。 |
| **区间动态规划** | $O(n^2)$ | $O(n^2)$ | ⭐⭐⭐ | 思想普适，适合作为区间 DP 的入门范例，但空间劣于中心扩散。 |
| **Manacher (马拉车)** | $O(n)$ | $O(n)$ | ⭐⭐ | 理论最优，但边界繁琐，通常不作为高频手撕必考项。 |

# 647. Palindromic Substrings (回文子串)

- **难度**：Medium
- **标签**：双指针、字符串、动态规划
- **LeetCode 链接**：[LeetCode 647. Palindromic Substrings](https://leetcode.com/problems/palindromic-substrings/)

### 一、 题目描述

给你一个字符串 `s` ，请你统计并返回这个字符串中 **回文子串** 的数目。

**回文字符串** 是正着读和倒过来读一样的字符串。

**子字符串** 是字符串中连续的字符序列。

### 二、 示例说明

#### 示例 1
* **输入**：`s = "abc"`
* **输出**：`3`
* **解释**：三个回文子串分别为 `"a"`, `"b"`, `"c"`。

#### 示例 2
* **输入**：`s = "aaa"`
* **输出**：`6`
* **解释**：六个回文子串分别为 `"a"`, `"a"`, `"a"`, `"aa"`, `"aa"`, `"aaa"`。
  * 注意：不同位置起止的相同字符子串，视作不同的回文子串。

#### 数据范围约束
* $1 \le \text{s.length} \le 1000$
* `s` 仅由小写英文字母组成。

### 三、 解题核心突破口：中心扩散法 (Expand Around Center)

回文字符串的本质是**轴对称**。与其暴力枚举每一个子串再花 $O(k)$ 去校验它是否对称（总体耗时 $O(n^3)$），不如**反客为主：从对称中心向外双向扩散**。

#### 1. 为什么中心一共有 $2n - 1$ 个？
长度为 $n$ 的字符串，回文串有两种对称结构：
* **奇数长度回文串**：对称中心是一个具体的**字符**，例如 `"aba"` 的中心是 `'b'`。共有 $n$ 个单字符中心。
* **偶数长度回文串**：对称中心是两个字符之间的**空隙**，例如 `"abba"` 的中心是两个 `'b'` 之间。共有 $n - 1$ 个两字符缝隙中心。

两者加起来，整个字符串总共只存在 $n + (n - 1) = 2n - 1$ 个对称中心。

#### 2. 扩散扩展的贪心性质
对于任意一个给定的中心点，设左右扩散指针为 `left` 和 `right`：
1. 只要 `s[left] == s[right]`，说明当前窗口 `s[left:right+1]` 构成了新的回文子串，答案计数器加一。
2. 随后向外推进：`left -= 1`, `right += 1`。
3. 一旦遇到 `s[left] != s[right]` 或指针越界，立刻终止扩散。因为内部已经不对称，再继续往外扩也绝不可能构成回文。

### 四、 Python 3 最优实现（中心扩散法）

```python
class Solution:

  def countSubstrings(self, s: str) -> int:
    n = len(s)
    ans = 0

    def expand_from_center(left: int, right: int) -> int:
      count = 0
      # 边界条件：双指针不越界，且两端字符严格相等
      while left >= 0 and right < n and s[left] == s[right]:
        count += 1
        left -= 1
        right += 1
      return count

    for i in range(n):
      # 1. 奇数长度中心扩散：以 s[i] 本身为中心
      ans += expand_from_center(i, i)
      # 2. 偶数长度中心扩散：以 s[i] 与 s[i + 1] 之间的空隙为中心
      ans += expand_from_center(i, i + 1)

    return ans
```

* **时间复杂度**：$O(n^2)$。枚举了 $2n - 1$ 个中心，每个中心向两端扩展最多 $O(n)$ 步。$n \le 1000$ 时，$n^2 \approx 10^6$，在 Python 中耗时约为数十毫秒，远在 1 秒超时线内。
* **空间复杂度**：$O(1)$。仅使用双指针和计数变量，不占用任何额外的堆栈或数组空间。

### 五、 示例 2 (`s = "aaa"`) 的单步 Dry Run

遍历 `i` 从 `0` 到 `2`：

| 循环下标 `i` | 扩散类型 | 初始指针 `(left, right)` | 匹配成功的回文串 | 本次贡献数量 |
| :---: | :---: | :---: | :--- | :---: |
| `i = 0` | 奇数中心 | `(0, 0)` | `s[0:1]` = `"a"` | 1 |
| `i = 0` | 偶数中心 | `(0, 1)` | `s[0:2]` = `"aa"` | 1 |
| `i = 1` | 奇数中心 | `(1, 1)` | `s[1:2]` = `"a"`，扩出 `s[0:3]` = `"aaa"` | 2 |
| `i = 1` | 偶数中心 | `(1, 2)` | `s[1:3]` = `"aa"` | 1 |
| `i = 2` | 奇数中心 | `(2, 2)` | `s[2:3]` = `"a"` | 1 |
| `i = 2` | 偶数中心 | `(2, 3)` | 越界，无匹配 | 0 |

**累计总和**：$1 + 1 + 2 + 1 + 1 + 0 = 6$。

### 六、 解法二：区间动态规划（对比参考）

虽然中心扩散法在空间上达到最优的 $O(1)$，但从算法体系来看，本题也是经典的区间型 DP：

#### 1. 状态定义
设布尔数组 `dp[i][j]` 表示子串 `s[i...j]` 是否为回文子串。

#### 2. 状态转移方程
* 若 `s[i] != s[j]`：两端不同，必不回文，`dp[i][j] = False`。
* 若 `s[i] == s[j]`：
  * 若子串长度小于等于 3（即 $j - i \le 2$），如 `"a"`, `"aa"`, `"aba"`，中间没有更小的子串或只有一个字符，直接成立：`dp[i][j] = True`。
  * 若子串长度大于 3，取决于去掉首尾后的内部子串：`dp[i][j] = dp[i + 1][j - 1]`。

#### 3. 遍历顺序
因为 `dp[i][j]` 依赖于其左下方的状态 `dp[i + 1][j - 1]`，所以外层循环必须**从下往上（`i` 逆序）**，内层循环**从左往右（`j` 顺序，且 $j \ge i$）**。

#### 4. 代码实现
```python
class Solution:

  def countSubstrings(self, s: str) -> int:
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    ans = 0

    # 逆序遍历 i，顺序遍历 j
    for i in range(n - 1, -1, -1):
      for j in range(i, n):
        if s[i] == s[j]:
          if j - i <= 2 or dp[i + 1][j - 1]:
            dp[i][j] = True
            ans += 1

    return ans
```

* **时间复杂度**：$O(n^2)$
* **空间复杂度**：$O(n^2)$，需要维护 $n \times n$ 的布尔矩阵。

回文串的区间 DP（动态规划）是非常标准的二维区间状态机。掌握一套状态定义与填表顺序，就能横扫一整套回文变体题。

### 一、 回文 DP 的母模板（LC 647 的 DP 实现）

#### 1. 状态定义
定义 `dp[i][j]` 为子串 $s[i \dots j]$ 是否为回文串（布尔值）。

#### 2. 状态转移方程
子串 $s[i \dots j]$ 想要是回文，必须满足两个条件：
* 首尾字符相等：`s[i] == s[j]`。
* 剥去首尾之后的内部子串也是回文：`dp[i+1][j-1] == True`；如果长度为 1 或 2（即 $j - i \le 2$），两端相等则必是回文，不需要查内层。

$$dp[i][j] = (s[i] == s[j]) \land (j - i \le 2 \lor dp[i+1][j-1])$$

#### 3. 关键填表顺序
计算 $dp[i][j]$ 依赖左下方的 $dp[i+1][j-1]$，因此行号 $i$ 必须倒序（从大到小），列号 $j$ 正序（从 $i$ 到 $n-1$）。

```python
class Solution647:

  def countSubstrings(self, s: str) -> int:
    n = len(s)
    dp = [[False] * n for _ in range(n)]
    ans = 0

    # i 从底向上，j 从左向右
    for i in range(n - 1, -1, -1):
      for j in range(i, n):
        if s[i] == s[j] and (j - i <= 2 or dp[i + 1][j - 1]):
          dp[i][j] = True
          ans += 1

    return ans
```

### 二、 核心回文 DP 题单及状态演变

以下几道经典题共享完全相同的区间规划视角：

| 题号 & 题名 | DP 状态定义 | 转移方程核心 | 难度 |
| :--- | :--- | :--- | :---: |
| **5. Longest Palindromic Substring**<br>(最长回文子串) | `dp[i][j]`：布尔值，表示 $s[i \dots j]$ 是否回文 | 遇到 `dp[i][j] == True`，更新 `max_len = j - i + 1`，记录起始下标 | **Medium** |
| **516. Longest Palindromic Subsequence**<br>(最长回文子序列，注意可不连续) | `dp[i][j]`：整数，表示 $s[i \dots j]$ 范围内最长回文子序列的长度 | 若 `s[i] == s[j]`：$dp[i+1][j-1] + 2$<br>若不等：$\max(dp[i+1][j], dp[i][j-1])$ | **Medium** |
| **131. Palindrome Partitioning**<br>(分割回文串) | 用母模板先 $O(n^2)$ 预处理出 `dp[i][j]` 查表数组 | 回溯切分时，用 $O(1)$ 检查 `dp[start][end]`，避免重复验证回文 | **Medium** |
| **132. Palindrome Partitioning II**<br>(分割回文串 II - 最少分割次数) | 先求回文表 `is_pal[i][j]`，再定义一维 `f[i]` 为前缀 $s[0 \dots i]$ 的最少分割数 | $f[i] = \min_{j}(f[j-1] + 1)$，前提是 $s[j \dots i]$ 为回文 | **Hard** |

### 三、 典型变体详析

#### 1. LC 516. 最长回文子序列（从“连续子串”到“非连续子序列”）
回文子串要求连续，而子序列可以跳过字符。这道题将布尔状态扩展为数值状态。

```python
class Solution516:

  def longestPalindromeSubseq(self, s: str) -> int:
    n = len(s)
    # dp[i][j] 表示 s[i..j] 内的最长回文子序列长度
    dp = [[0] * n for _ in range(n)]

    # 单个字符本身构成长度为 1 的回文
    for i in range(n):
      dp[i][i] = 1

    for i in range(n - 1, -1, -1):
      for j in range(i + 1, n):
        if s[i] == s[j]:
          # 两端匹配，向内收缩 + 2
          dp[i][j] = dp[i + 1][j - 1] + 2
        else:
          # 两端不匹配，分别放弃左端或右端取最优
          dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])

    return dp[0][n - 1]
```

#### 2. LC 132. 分割回文串 II（双重 DP 组合拳）

题目要求把字符串切成全部都是回文串的最少刀数。直接回溯会超时，需利用回文 DP 进行二阶降维加速：

```python
class Solution132:

  def minCut(self, s: str) -> int:
    n = len(s)
    # 第一步：用母模板预处理出所有区间的回文属性
    is_pal = [[False] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):
      for j in range(i, n):
        if s[i] == s[j] and (j - i <= 2 or is_pal[i + 1][j - 1]):
          is_pal[i][j] = True

    # 第二步：一维线性 DP，dp[i] 表示 s[0..i] 的最小切分次数
    dp = [0] * n
    for i in range(n):
      if is_pal[0][i]:
        dp[i] = 0  # 整个前缀自身就是回文，切 0 刀
      else:
        # 枚举最后一个回文子串的分割点 j
        dp[i] = min(dp[j - 1] + 1 for j in range(1, i + 1) if is_pal[j][i])

    return dp[n - 1]

```

### 四、 中心扩散法 vs 区间 DP 的选型原则

| 场景 | 推荐策略 | 核心原因 |
| :--- | :--- | :--- |
| **仅求单次最长/回文计数** (LC 5, LC 647) | **中心扩散法** | 空间仅需 $O(1)$，常数极小，且无需额外开辟 $O(n^2)$ 数组。 |
| **需要频繁查询区间是否回文** (LC 131, LC 132) | **区间 DP 预处理** | $O(n^2)$ 一次建表后，后续任意区间回文判定仅需 $O(1)$。 |
| **求解非连续子序列** (LC 516) | **区间 DP** | 中心扩散法无法处理字符跳过，必须依赖状态转移保留子结构。 |

# 2392. Build a Matrix With Conditions (给定条件下构造矩阵)

- **难度**：Hard
- **标签**：图、拓扑排序、矩阵、BFS、有向无环图 (DAG)
- **LeetCode 链接**：[LeetCode 2392. Build a Matrix With Conditions](https://leetcode.com/problems/build-a-matrix-with-conditions/)

### 一、 题目描述

给你一个正整数 $k$，表示你要在一个大小为 $k \times k$ 的网格矩阵中填入数字 $1$ 到 $k$。

必须严格满足以下条件：
1. 数字 $1$ 到 $k$ 在矩阵中**恰好各出现一次**。
2. 矩阵中未填入上述数字的其余格子**全部填 $0$**。
3. 同时满足两个二维约束列表：
   * **`rowConditions[i] = [above, below]`**：数字 `above` 所在的**行号**必须严格小于 `below` 所在的行号（即 `above` 必须在 `below` 的**上方**）。
   * **`colConditions[i] = [left, right]`**：数字 `left` 所在的**列号**必须严格小于 `right` 所在的列号（即 `left` 必须在 `right` 的**左侧**）。

**返回值**：
* 返回任意一个满足所有上述条件的 $k \times k$ 矩阵。
* 若两组条件内部存在死锁冲突（成环），无法同时满足，则直接返回**空数组 `[]`**。

#### 示例 1：
- **输入**：$k = 3$, `rowConditions = [[1, 2], [3, 2]]`, `colConditions = [[2, 1], [3, 2]]`
- **输出**：
```text
  [
    [3, 0, 0],
    [0, 0, 1],
    [0, 2, 0]
  ]
```

**解释**：
* 行条件中：$1$ 和 $3$ 都在 $2$ 上方。行顺序可以是 `[3, 1, 2]`（$3$ 在第 0 行，$1$ 在第 1 行，$2$ 在第 2 行）。
* 列条件中：$3$ 在 $2$ 左侧，$2$ 在 $1$ 左侧。列顺序只能是 `[3, 2, 1]`（$3$ 在第 0 列，$2$ 在第 1 列，$1$ 在第 2 列）。
* 将每个数字定位到对应的 `(row, col)`，得到合法矩阵。

### 二、 核心解题破局点：行列正交与降维拓扑排序

这道题表面包裹着“$k \times k$ 矩阵”的外壳，很多初学者会联想到回溯放置或网格搜索，但其实它 **100% 是一道图论拓扑排序题**。

#### 1. 行与列完全独立（正交解耦）
* `rowConditions` 只约束数字在 **Y 轴（行）** 上的垂直先后次序，与数字放哪一列完全无关。
* `colConditions` 只约束数字在 **X 轴（列）** 上的水平先后次序，与数字放哪一行完全无关。
* 我们可以把问题拆解成两个完全独立的**一维依赖排序任务**：
  * **任务 A**：给 $1 \sim k$ 从上到下排一个合法的行序列表。
  * **任务 B**：给 $1 \sim k$ 从左到右排一个合法的列序列表。

#### 2. 条件本质即“有向边”
* 条件 `[u, v]` 本质就是一条从节点 $u$ 指向节点 $v$ 的有向边（$u \to v$），含义为：$u$ 必须排在 $v$ 之前。
* 满足全部条件等价于求该有向图的一个**拓扑排序（Topological Sort）**。
* 发生依赖冲突等价于图中有向边**出现了环（Cycle）**。

### 三、 算法流程详解（Kahn 算法）

我们使用基于 **入度表 + BFS** 的经典 Kahn 算法分别计算行序与列序：

1. **构造图与统计入度**：
   * 建立邻接表 `graph`（`u -> [v1, v2, ...]`）。
   * 建立入度数组 `in_degree`（`in_degree[v]` 表示卡在 $v$ 前面的依赖总数）。
2. **队列 BFS 推进**：
   * 将所有没有前置依赖（`in_degree == 0`）的节点全部装入双端队列 `queue`。
   * 每次弹出队头节点 `curr`，追加到拓扑结果数组 `order` 中。
   * 遍历 `curr` 的所有出边邻居 `neighbor`，将其入度减 1。若其入度降为 0，说明其所有前置约束均已解除，将其推入队列。
3. **环检测判定**：
   * 队列为空后，检查拓扑排序结果 `order` 的长度。
   * 若 `len(order) < k`，说明图中存在环（节点互相卡死导致入度无法清零），立即判定无解，返回 `[]`。
4. **拼装结果矩阵**：
   * 执行 `row_order = topo_sort(rowConditions)`。
   * 执行 `col_order = topo_sort(colConditions)`。
   * 任意一个返回为空，整题返回 `[]`。
   * 用哈希表记录每个数字在列排序中的下标：`col_pos = {num: col_idx}`。
   * 开辟 $k \times k$ 全零矩阵，遍历 `row_order` 中的每个 `(row_idx, num)`，将 `num` 填入 `matrix[row_idx][col_pos[num]]`。

### 四、 Python 3 标准实现

```python
from collections import defaultdict, deque


class Solution:

  def buildMatrix(
      self,
      k: int,
      rowConditions: list[list[int]],
      colConditions: list[list[int]],
  ) -> list[list[int]]:

    # 1. 抽取通用的 Kahn 拓扑排序函数
    def topo_sort(edges: list[list[int]]) -> list[int]:
      graph = defaultdict(list)
      in_degree = [0] * (k + 1)

      for u, v in edges:
        graph[u].append(v)
        in_degree[v] += 1

      # 初始入度为 0 的所有节点入队（数字编号为 1 到 k）
      queue = deque([node for node in range(1, k + 1) if in_degree[node] == 0])
      order = []

      while queue:
        curr = queue.popleft()
        order.append(curr)

        for neighbor in graph[curr]:
          in_degree[neighbor] -= 1
          if in_degree[neighbor] == 0:
            queue.append(neighbor)

      # 若排序节点数不足 k，说明图中有环
      return order if len(order) == k else []

    # 2. 分别独立对行条件与列条件执行拓扑排序
    row_order = topo_sort(rowConditions)
    col_order = topo_sort(colConditions)

    # 只要任意一个维度成环冲突，直接无解
    if not row_order or not col_order:
      return []

    # 3. 记录每个数字在列中的定位映射：num -> col_index
    col_pos = {num: idx for idx, num in enumerate(col_order)}

    # 4. 初始化 k x k 矩阵并完成填数
    matrix = [[0] * k for _ in range(k)]
    for row_idx, num in enumerate(row_order):
      col_idx = col_pos[num]
      matrix[row_idx][col_idx] = num

    return matrix
```

### 五、 复杂度分析

- **时间复杂度**：$O(k^2 + R + C)$
  - 设 $R = \text{len}(\text{rowConditions})$，$C = \text{len}(\text{colConditions})$。
  - 行拓扑排序耗时 $O(k + R)$。
  - 列拓扑排序耗时 $O(k + C)$。
  - 矩阵初始化开销为 $O(k^2)$，填放数字为 $O(k)$。
  - 整体时间复杂度为 $O(k^2 + R + C)$。题目中 $k \le 400$，计算量远低于运算上限，极度快速。
- **空间复杂度**：$O(k^2 + R + C)$
  - 邻接表和入度统计占 $O(k + R + C)$ 空间。
  - 构造并返回的答案矩阵需要 $O(k^2)$ 空间。

# 图论核心：Kahn 算法（入度表 + BFS 拓扑排序）精要总结

Kahn 算法（Kahn's Algorithm）是求解 **有向无环图（DAG）拓扑排序** 最直观、工程落地最广泛的算法。其本质就是**“动态维护入度表进行的广度优先搜索（BFS）”**。

### 一、 算法核心机制与心法

* **物理直觉**：任务清单里，哪个任务当前没有任何前置卡点（入度为 0），就立刻先做哪个。做完后，把由它引出的所有约束（出边）从系统里撕掉，释放后续任务，直到全部做完。
* **数据结构铁三角**：
  1. `in_degree`（入度数组）：记录每个节点当前还剩几个前置依赖。
  2. `graph`（出边邻接表）：记录当前节点完成后，会解锁哪些后续邻居（$u \to v$）。
  3. `queue`（BFS 队列）：暂存所有当前已经就绪（`in_degree == 0`）的节点。
* **环检测（Cycle Detection）原理**：
  * 若图中有环，环内的节点永远存在前置依赖，入度永远不可能归零，也就永远无法入队。
  * **结论**：算法结束时，若收集到的拓扑节点总数 $< V$（图的总顶点数），则图中有环，必然无解。

### 二、 Python 3 标准母模板

在 LeetCode 与工业界实现中，统一采用这套 20 行极简骨架：

```python
from collections import defaultdict, deque


def kahn_topo_sort(num_nodes: int, edges: list[list[int]]) -> list[int]:
  graph = defaultdict(list)
  in_degree = [0] * num_nodes

  # 1. 建图 + 统计入度 (注意根据题意判断依赖方向是 u -> v 还是 v -> u)
  for u, v in edges:
    graph[u].append(v)
    in_degree[v] += 1

  # 2. 将所有初始入度为 0 的无依赖节点全部入队
  queue = deque([node for node in range(num_nodes) if in_degree[node] == 0])
  topo_order = []

  # 3. BFS 推进：出队、消边、解锁新节点
  while queue:
    curr = queue.popleft()
    topo_order.append(curr)

    for neighbor in graph[curr]:
      in_degree[neighbor] -= 1
      if in_degree[neighbor] == 0:
        queue.append(neighbor)

  # 4. 判环：输出长度不足则存在环
  return topo_order if len(topo_order) == num_nodes else []
```

- **时间复杂度**：$O(V + E)$，遍历所有顶点与边各常数次。
- **空间复杂度**：$O(V + E)$，邻接表与入度数组开销。

### 三、 经典题单：LeetCode 上的 Kahn 算法家族

Kahn 算法在面试中主要呈现为四类马甲：

#### 1. 经典基准题（模板完全照搬）
* **207. Course Schedule (课程表 I)**
  * **难度**：Medium
  * **题意**：判断能否修完所有课程。
  * **解法**：直接运行母模板，返回 `len(topo_order) == numCourses`。
* **210. Course Schedule II (课程表 II)**
  * **难度**：Medium
  * **题意**：返回任意一条合法的修课顺序；若存在死锁则返回空数组 `[]`。
  * **解法**：直接返回母模板的 `topo_order`。

#### 2. 自行构图题（从隐式信息中提取有向边）
* **269. Alien Dictionary (火星词典)**
  * **难度**：Hard
  * **题意**：给定按外星文字典序排好的单词列表，推断所有外星字母的字母表顺序。
  * **解法**：遍历相邻两个单词，找到第一个不同的字符对 `(c1, c2)`，提取出一条有向边 `c1 -> c2`。对所有字符跑 Kahn 算法。
* **802. Find Eventual Safe States (找到最终的安全状态)**
  * **难度**：Medium
  * **题意**：找到所有无论怎么走最终都会走向终点（无环）的节点。
  * **解法**：**反向建图 + Kahn 算法**。将所有有向边反向，原图中出度为 0 的终点变成入度为 0 的起点，从安全终点反向拓扑推进。

#### 3. “洋葱剥皮”拓扑题（无向图树形消融）
* **310. Minimum Height Trees (找到最小高度树的根节点)**
  * **难度**：Medium
  * **题意**：在一棵包含 $n$ 个节点的无向树中，找出哪些节点作为根节点时，树的高度最小。
  * **解法**：树的中心节点最多只有 1 到 2 个。无向图的叶子节点度数为 1（`degree == 1`）。将所有叶子入队，每轮像剥洋葱一样剥除一层外层叶子并更新邻居度数，直到剩下最后 1~2 个核心节点。

#### 4. 降维解耦与多层拓扑（高阶应用）
* **2392. Build a Matrix With Conditions (给定条件下构造矩阵)**
  * **难度**：Hard
  * **题意**：在 $k \times k$ 矩阵中按偏序放置 $1 \sim k$。
  * **解法**：**行列正交解耦**。垂直方向跑一次 Kahn，水平方向跑一次 Kahn，将两次拓扑序映射为 `(row, col)` 填表。
* **1203. Sort Items by Groups Respecting Dependencies (项目管理)**
  * **难度**：Hard
  * **题意**：项目存在先后依赖，且每个项目归属于某个组（Group），同一个组的项目必须连续完成。
  * **解法**：**双层 Kahn 算法**。先对“组（Group）”建图跑一次拓扑排序，再对“每个组内部的项目（Item）”跑拓扑排序，两层拼接出最终方案。

### 四、 题目特征与快速识别表

| 题目特征 | 识别信号 | 对应解法 |
| :--- | :--- | :--- |
| **先决条件 / 先修关系** | 出现 "prerequisites", "before", "dependencies" | 显式构建有向边，直接跑 Kahn 模板 |
| **字母/符号字典序推导** | 出现 "sorted lexicographically" | 相邻元素找首个不同点建边，再跑 Kahn |
| **网格矩阵偏序摆放** | 行列限制互不影响 | 行列解耦，独立运行两次一维 Kahn |
| **寻找树的中心节点** | 寻找最小高度、最长路径中点 | 无向图叶子入队（`degree == 1`），反向层序剥皮 |
| **两级依赖嵌套** | 分组打包 + 组内先后 | 双层 Kahn 算法（组级别 + 项目级别） |
