# 70. Climbing Stairs (爬楼梯)

- **难度**：Easy
- **标签**：动态规划、记忆化搜索、数学（斐波那契数列）
- **LeetCode 链接**：[LeetCode 70. Climbing Stairs](https://leetcode.com/problems/climbing-stairs/)

### 一、 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶？

**示例 1：**
* **输入**：`n = 2`
* **输出**：`2`
* **解释**：有两种方法可以爬到楼顶：
  1. 1 阶 + 1 阶
  2. 2 阶

**示例 2：**
* **输入**：`n = 3`
* **输出**：`3`
* **解释**：有三种方法可以爬到楼顶：
  1. 1 阶 + 1 阶 + 1 阶
  2. 1 阶 + 2 阶
  3. 2 阶 + 1 阶

**提示：**
* `1 <= n <= 45`

### 二、 核心解题切入点

**“到达当前台阶的最后一步，只能是从哪里跨过来的？”**

要到达第 $i$ 阶楼梯，因为每次只能走 1 阶或 2 阶，所以**最后一步只有两种可能**：
1. 从第 $i - 1$ 阶跨 **1** 阶上来；
2. 从第 $i - 2$ 阶跨 **2** 阶上来。

根据加法原理，到达第 $i$ 阶的所有走法总数，等于到达第 $i - 1$ 阶的方法数加上到达第 $i - 2$ 阶的方法数。

这正是标准的 **斐波那契数列（Fibonacci Sequence）** 递推模型。

### 三、 动态规划四步走

1. **状态定义**：
   * 定义 `dp[i]` 表示爬到第 $i$ 阶楼梯的不同方法总数。
2. **状态转移方程**：
   * $dp[i] = dp[i - 1] + dp[i - 2]$ （$i \ge 3$）
3. **初始边界条件**：
   * `dp[1] = 1`（爬到第 1 阶只有 1 种方法：走 1 步）
   * `dp[2] = 2`（爬到第 2 阶有 2 种方法：`1+1` 或直接 `2`）
4. **空间优化（滚动变量）**：
   * 计算 `dp[i]` 时，只需要用到它前两个位置的值 `dp[i-1]` 和 `dp[i-2]`。
   * 完全没必要开一个大小为 $n$ 的数组，用两个变量 `prev1` 和 `prev2` 滚动向前推进即可，将空间复杂度从 $O(n)$ 压缩到 $O(1)$。

### 四、 Python 3 最优解实现

#### 解法一：滚动变量空间优化版（面试推荐）

```python
class Solution:

  def climbStairs(self, n: int) -> int:
    # 边界情况快速返回
    if n <= 2:
      return n

    # prev2 代表 dp[i-2]，初始为 dp[1] = 1
    # prev1 代表 dp[i-1]，初始为 dp[2] = 2
    prev2, prev1 = 1, 2

    # 从第 3 阶开始逐步推导到第 n 阶
    for _ in range(3, n + 1):
      curr = prev1 + prev2
      # 变量滚动向前
      prev2 = prev1
      prev1 = curr

    return prev1
```

#### 解法二：标准数组 DP 版（直观便于理解）

```python
class Solution:

  def climbStairs(self, n: int) -> int:
    if n <= 2:
      return n

    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2

    for i in range(3, n + 1):
      dp[i] = dp[i - 1] + dp[i - 2]

    return dp[n]
```

五、 复杂度分析时间复杂度：$O(n)$。从 $3$ 遍历到 $n$，执行 $n - 2$ 次常数级加法与变量赋值。空间复杂度：滚动变量版：$O(1)$，仅维护 prev1, prev2, curr 三个常量级整数变量。数组 DP 版：$O(n)$，需要维护一个长度为 $n + 1$ 的一维状态数组。
