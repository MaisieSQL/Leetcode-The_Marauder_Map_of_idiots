## 994. Rotting Oranges (腐烂的橘子)
**Medium**  

### 题目描述
在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三种值之一：
* 值 `0` 代表空单元格；
* 值 `1` 代表新鲜橘子；
* 值 `2` 代表腐烂的橘子。

每分钟，任何与腐烂的橘子（在 4 个方向上）相邻的新鲜橘子都会腐烂。

返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`。

### 解题思路与解析

这道题是典型的**多源 BFS（广度优先搜索）**应用场景：
1. **为什么是多源？** 
   网格中可能一开始就存在多个腐烂的橘子 (`2`)。它们在第 0 分钟时是同时向四周发起感染的，而不是一个接一个先后扩散的。
2. **核心步骤**：
   * **第一步（统计与入队）**：遍历整个矩阵，把所有初始状态为 `2`（腐烂）的橘子坐标全部加入 BFS 队列中，同时统计一共有多少个新鲜橘子 (`fresh_count`)。如果一开始就没有新鲜橘子，直接返回 `0`。
   * **第二步（层序扩散）**：每一轮 `while` 循环代表**过去 1 分钟**。我们处理当前队列中的所有腐烂橘子，向它们的上下左右四个方向扩散。如果遇到新鲜橘子 (`1`)，就将其变成腐烂 (`2`)，新鲜橘子总数减 1，并把新腐烂的橘子压入队列。
   * **第三步（结果判定）**：当队列耗尽或者新鲜橘子被传染光后，检查 `fresh_count` 是否为 0。如果为 0，返回累计的分钟数；如果不为 0，说明有些新鲜橘子永远无法被感染（被墙或空格子隔断），返回 `-1`。

### 代码实现 (Python)

```python
from collections import deque

class Solution(object):
    def orangesRotting(self, grid):
        """
        :type grid: List[List[int]]
        :rtype: int
        """
        if not grid or not grid[0]:
            return 0
            
        Rows, Cols = len(grid), len(grid[0])
        queue = deque()
        fresh_count = 0
        
        # 1. 扫描网格：收集所有初始腐烂的橘子，并统计新鲜橘子总数
        for r in range(Rows):
            for c in range(Cols):
                if grid[r][c] == 2:
                    queue.append((r, c))
                elif grid[r][c] == 1:
                    fresh_count += 1
                    
        # 如果一开始就没有新鲜橘子，直接返回 0 分钟
        if fresh_count == 0:
            return 0
            
        minutes = 0
        directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        
        # 2. 多源 BFS 层序扩散
        while queue and fresh_count > 0:
            minutes += 1
            # 记录当前这一分钟内需要扩散的腐烂橘子数量
            for _ in range(len(queue)):
                r, c = queue.popleft()
                
                for dr, dc in directions:
                    nr, nc = r + dr, c + dc
                    # 检查边界，并看是否能感染相邻的新鲜橘子
                    if 0 <= nr < Rows and 0 <= nc < Cols and grid[nr][nc] == 1:
                        grid[nr][nc] = 2  # 感染
                        fresh_count -= 1   # 新鲜橘子少一个
                        queue.append((nr, nc))
                        
        # 3. 检查是否全部感染
        return minutes if fresh_count == 0 else -1
```

## 复杂度分析

* **时间复杂度**：$O(M \times N)$，其中 $M$ 和 $N$ 分别为网格的行数和列数。每个格子最多被访问和入队一次。
* **空间复杂度**：$O(M \times N)$，在最坏情况下，所有橘子同时腐烂并入队，队列需要占用相应的存储空间。
