### 🧠 极速扫题心法：一眼看穿 4 大流派

为了让你今天能风卷残云般扫平它们，咱们把这 9 道题按**底层核心心法**归为 4 类，代码模板高度复用：

#### 1️⃣ 流派一：前缀/后缀和 + “净胜分差” 1D DP（核心母题：III、II、VIII）
* **LC 1406 (Stone Game III)**：每次拿 $1 \sim 3$ 堆。之前你已经掌握了最神级的 `suffix - min(next1, next2, next3)` 滚动变量写法（$O(1)$ 空间）！
* **LC 1140 (Stone Game II)**：和 III 几乎一模一样，只是每次拿的数量从固定的 $1 \sim 3$ 变成了动态的 $1 \le X \le 2M$。
  * 状态定义为 `dfs(i, M)`：从第 `i` 堆开始、当前参数为 `M` 时能拿到的**最大绝对得分**。
  * 转移公式同样是 `suffix[i] - min(dfs(i + x, max(M, x)))`（遍历 $1 \le x \le 2M$）。
* **LC 1872 (Stone Game VIII)**：每次拿走前 $x$ 堆（$x \ge 2$）并把总和放回最左边。**物理洞察**：放回的新石子依然在最左边，下次拿必然还会包含它！所以每次操作本质上就是**选一个前缀和 `prefix[x]` 得分**。倒序维护后缀最大净胜分即可，代码不到 10 行！

#### 2️⃣ 流派二：左右两头拿的“区间 DP”（核心母题：I、VII、V）
* **LC 877 (Stone Game I)** & **LC 1690 (Stone Game VII)**：
  * 都是只能从数组**最左端 `i` 或最右端 `j`** 拿石子。
  * 状态 `dp[i][j]` 表示在区间 `[i, j]` 上当前玩家能比对手多拿的**最大净胜分**。
  * 转移：`dp[i][j] = max(拿左边得分 - dp[i+1][j], 拿右边得分 - dp[i][j-1])`（I 的得分是 `piles[i]`，VII 的得分是剩余区间和 `sum(i+1..j)`）。
* **LC 1563 (Stone Game V)**：Alice 把数组劈成两半，Bob 扔掉总和较大的那一半，Alice 得较小那一半的分（单人得分最大化，没有对手轮流拿，纯区间 DP 枚举分割点 `k`）。

#### 3️⃣ 流派三：特立独行的“贪心排序”（LC 1686. Stone Game VI）
* 唯一一道**可以且必须排序**的石子游戏！
* 同一颗石子 `i`，Alice 拿值 $a_i$，Bob 拿值 $b_i$。如果我拿了它，我赚 $a_i$ 且让对手少赚 $b_i$，一里一外净拉开差距 $a_i + b_i$！所以直接按 `a[i] + b[i]` 从大到小排序，两人轮流贪心抢最大的即可。

#### 4️⃣ 流派四：博弈状态机 & 纯数学脑筋急转弯（LC 1510. IV & LC 2029. IX）
* **LC 1510 (Stone Game IV)**：剩 `i` 颗石子，每次拿平方数 $k^2$。只要存在哪怕一种拿法能把**必败态（`dp[i - k*k] == False`）**留给对手，当前 `dp[i]` 就是 `True`（必胜态）。
* **LC 2029 (Stone Game IX)**：只关心石子价值模 3 的余数（0、1、2 的个数），0 相当于“跳过回合/反转先后手”，分 `count[0]` 是偶数还是奇数讨论即可。
