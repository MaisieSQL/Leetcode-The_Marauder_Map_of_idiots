# LeetCode 680. 验证回文串 II (Valid Palindrome II) ── 完整解析与通关源码

## 一、 题目大意与核心直觉

给你一个字符串 `s`，最多可以**删除其中的一个字符**。请你判断它是否能成为回文字符串。如果能，返回 `true`；否则，返回 `false`。

* **普通回文串回顾**：通常我们用相向双指针（`left` 和 `right`）分别从字符串的两端向中间靠拢，要求对应位置的字符必须完全一致。
* **本题的容错机制**：这道题破天荒地允许你**犯错一次（即跳过/删掉一个字符）**。这意味着当双指针在中间撞见不相等的字符时，我们不能直接判错，而是拥有一次“分叉尝试”的机会。

## 二、 核心解题思路：相向双指针 + 容错分叉

1. 初始化双指针：`left = 0`，`right = len(s) - 1`。
2. 循环向中间逼近：
   * 如果 `s[left] == s[right]`，万事大吉，两指针同时向中间收缩（`left += 1, right -= 1`）。
   * **一旦遇到 `s[left] != s[right]`（发生冲突）**：
     * 说明必须通过删除一个字符来化解矛盾。此时有两种可能：
       1. **删掉左边字符**：检查子串 `s[left+1 ... right]` 是否为严格回文串。
       2. **删掉右边字符**：检查子串 `s[left ... right-1]` 是否为严格回文串。
     * 只要这两种选择中**有任意一种能够顺利通过**，就说明原字符串通过删除一个字符可以变回文，直接返回 `true`；如果两条路都走不通，则返回 `false`。

## 三、 Python3 完美通关代码 (Solution)

```python
class Solution:
    def validPalindrome(self, s: str) -> bool:
        def checkPalindrome(i: int, j: int) -> bool:
            # 内部辅助函数：检查子串 s[i...j] 是否为严格回文串
            while i < j:
                if s[i] != s[j]:
                    return False
                i += 1
                j -= 1
            return True

        left, right = 0, len(s) - 1
        while left < right:
            if s[left] == s[right]:
                left += 1
                right -= 1
            else:
                # 遇到冲突，分叉尝试：跳过左边字符 OR 跳过右边字符
                return checkPalindrome(left + 1, right) or checkPalindrome(left, right - 1)
                
        return True
```

### 四、 复杂度核验 (Complexity Analysis)

* **时间复杂度**：$\mathcal{O}(N)$
  * 主循环中的双指针最多遍历字符串一遍。
  * 如果发生冲突，内部的辅助函数 `checkPalindrome` 会对剩余子串进行一次扫描。由于题目只允许删一个字符，内部扫描顶多执行一次。总体时间复杂度依然保持线性的 $\mathcal{O}(N)$。
* **空间复杂度**：$\mathcal{O}(1)$
  * 整个算法只使用了常数个指针变量（`left`、`right`），没有借助额外的存储空间。
