## LeetCode 144. 二叉树的前序遍历 - 详细解析与题解

### 题目描述
给你二叉树的根节点 `root`，返回它节点值的 **前序遍历**（Preorder Traversal）。
* **前序遍历规则**：按照 **根节点 $\rightarrow$ 左子树 $\rightarrow$ 右子树** 的顺序访问节点。

### 方法一：递归法 (Recursion) —— 最直观的官方标准解法

#### 1. 核心思路
前序遍历的定义本身具有天然的递归性：
1. 先访问当前根节点（把值加入结果集）。
2. 递归调用函数遍历左子树。
3. 递归调用函数遍历右子树。
当遇到空节点（`None`）时，递归终止并返回。

#### 2. 代码实现 (Python)
```python
class Solution:
    def preorderTraversal(self, root: TreeNode) -> list[int]:
        res = []
        
        def dfs(node):
            # 终止条件：如果节点为空，直接返回
            if not node:
                return
            
            # 1. 根：访问当前节点
            res.append(node.val)
            # 2. 左：递归遍历左子树
            dfs(node.left)
            # 3. 右：递归遍历右子树
            dfs(node.right)
            
        dfs(root)
        return res
```

### 方法二：迭代法 / 显式栈 (Iteration with Stack) —— 硬核底层模拟

#### 1. 核心思路
递归的本质是操作系统在内存中维护了一个“系统调用栈”。我们可以用一个显式的列表 `stack` 来模拟这个栈：
* 前序遍历的访问顺序是“根 $\rightarrow$ 左 $\rightarrow$ 右”。
* 因为栈是**先进后出 (LIFO)** 的：
  * 如果我们想让**左子树**先被弹出来处理，就必须**先把右子树压入栈，再把左子树压入栈**。
* 每次从栈顶弹出当前节点，记录其值，然后重复上述压栈过程。

#### 2. 代码实现 (Python)
```python
class Solution:
    def preorderTraversal(self, root: TreeNode) -> list[int]:
        if not root:
            return []
            
        res = []
        stack = [root]  # 初始化栈，放入根节点
        
        while stack:
            # 1. 弹出当前栈顶节点（相当于访问“根”）
            node = stack.pop()
            res.append(node.val)
            
            # 2. 先压入右子树（确保左子树先出栈）
            if node.right:
                stack.append(node.right)
                
            # 3. 再压入左子树
            if node.left:
                stack.append(node.left)
                
        return res
```

### 两种方法对比

| 维度 | 方法一：递归法 (Recursion) | 方法二：迭代法 (Iteration with Stack) |
| :--- | :--- | :--- |
| **底层原理** | 依赖系统调用栈 (Call Stack) | 依赖程序员自己维护的显式栈 (`stack` 列表) |
| **代码简洁度** | 极简，逻辑与前序定义完全对齐 | 稍显繁琐，需要处理栈的进出顺序 |
| **空间复杂度** | $O(H)$ （$H$ 为树的高度，最坏链状时为 $O(N)$） | $O(H)$ （同样需要用栈存储路径上的节点） |
| **时间复杂度** | $O(N)$ （每个节点恰好被访问一次） | $O(N)$ （每个节点恰好被压入和弹出一次） |
| **安全性** | 树太深（如链状达 $10^5$ 层）时，可能导致**栈溢出 (Stack Overflow)** | 安全，不受系统递归深度限制 |
| **适用场景** | 面试首选，绝大多数常规情况下的最优解 | 面试官明确要求“不用递归”或树极深时的安全解法 |

用栈的这种迭代法，它既不是纯粹的“一层一层走（广度优先 BFS）”，也不是死板的“一杆子捅到底（纯递归 DFS）”，而是利用栈的 LIFO（后进先出）特性，在“向右拐”和“向左拐”之间做精准的控制。

为了让你看清它每一步到底是怎么跑的，我们用你给的这棵树来进行一次 **Dry Run（手动模拟运行）**！

### 总结：它到底是“怎么走”的？
通过这个 Dry Run，你会发现它的足迹是这样的：
1. **先死死沿着左边一路向下切入**（`1 -> 2 -> 4`），把左边的根和左孩子全处理了。
2. 当左边到底（比如 `4` 没孩子了），因为栈里还压着刚才路过时顺手塞进去的右边兄弟（比如 `5` 的右边、`3` 节点等），它会**自动回溯到上一个分叉口，去处理那些被暂存的右边分支**。

所以它本质上依然是 **DFS（深度优先搜索）** 的前序遍历轨迹，只是聪明地用一个栈把“还没来得及看的右边亲戚”先记在小本本上，等左边逛完了，回过头再去挨个访问！

## LeetCode 94. 二叉树的中序遍历 - 详细解析与题解

### 题目描述
给你二叉树的根节点 `root`，返回它节点值的 **中序遍历**（Inorder Traversal）。
* **中序遍历规则**：按照 **左子树 $\rightarrow$ 根节点 $\rightarrow$ 右子树** 的顺序访问节点。

### 方法一：递归法 (Recursion) —— 最直观的标准解法

#### 1. 核心思路
中序遍历的定义同样具有天然的递归性：
1. 先递归遍历左子树。
2. 访问当前根节点（把值加入结果集）。
3. 最后递归遍历右子树。
当遇到空节点（`None`）时，递归终止并返回。

#### 2. 代码实现 (Python)
```python
class Solution:
    def inorderTraversal(self, root: TreeNode) -> list[int]:
        res = []
        
        def dfs(node):
            if not node:
                return
            # 1. 左：先递归遍历左子树
            dfs(node.left)
            # 2. 根：访问当前节点
            res.append(node.val)
            # 3. 右：最后递归遍历右子树
            dfs(node.right)
            
        dfs(root)
        return res
```

### 方法二：迭代法 / 显式栈 (Iteration with Stack) —— 模拟指针一路向左

#### 1. 核心思路
中序遍历用迭代法写时，思路和前序遍历不太一样：

* 因为中序要求“先一直往左走，直到没有左孩子，然后才访问当前节点，最后转向右子树”。
* 我们需要用一个指针 `curr` 配合显式 `stack`：
  * **一路向左**：把沿途经过的所有左节点连续不断地压入栈中，直到 `curr` 变为 `None`。
  * **弹出访问**：从栈顶弹出一个节点（此时它代表当前子树的最左/最底部的未访问节点），将其加入结果集。
  * **转向右子树**：将指针指向这个弹出节点的右子树，重复上述过程。

#### 2. 代码实现 (Python)
```python
class Solution:
    def inorderTraversal(self, root: TreeNode) -> list[int]:
        res = []
        stack = []
        curr = root
        
        while curr or stack:
            # 1. 一路向左，把所有左子树节点压入栈
            while curr:
                stack.append(curr)
                curr = curr.left
                
            # 2. 当前左边到底了，弹出栈顶节点并访问
            curr = stack.pop()
            res.append(curr.val)
            
            # 3. 开始转向处理右子树
            curr = curr.right
            
        return res
```

### 两种方法对比

| 维度 | 方法一：递归法 (Recursion) | 方法二：迭代法 (Iteration with Stack) |
| :--- | :--- | :--- |
| **底层原理** | 依赖系统调用栈 (Call Stack) | 依赖程序员自己维护的显式栈 (`stack`) 与 `curr` 指针 |
| **代码简洁度** | 极简，逻辑与中序定义完全对齐 | 需要用 `while` 嵌套配合指针一路向左 |
| **空间复杂度** | $O(H)$ （$H$ 为树的高度） | $O(H)$ （栈中最多存储一条路径上的节点） |
| **时间复杂度** | $O(N)$ （每个节点恰好被访问一次） | $O(N)$ （每个节点恰好被入栈和出栈一次） |
| **安全性** | 树极深时可能导致系统栈溢出 | 安全，不受系统递归深度限制 |
| **适用场景** | 面试首选，清晰易读 | 面试官要求非递归实现时的标准写法 |

  * `curr = curr.right`：`9` 的右子树为空 $\rightarrow$ `curr = None`。

此时 `curr` 为 `None`，`stack` 为空，主循环结束！

### 最终输出结果：
`[4, 2, 6, 5, 7, 1, 3, 8, 9]` —— **完美吻合你给的 Output！**

通过这个 Dry Run 你可以发现，中序遍历的迭代法精髓就在于：**“用内层 `while` 像切菜一样把一整条左边界全撸进栈里，弹出一个处理一个，然后把视线移到它的右边去”**。
